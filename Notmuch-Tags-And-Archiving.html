10.5 Change tags and archive state ¶

Emacsvox compares displayed tags before and after an interactive change and reports actual additions and removals. Adding an existing tag or removing an absent tag reports “Tags unchanged”. Errors and cancelled commands do not produce success feedback.

These Show commands receive result-aware feedback:

+

Run notmuch-show-add-tag on the current message.

-

Run notmuch-show-remove-tag.

*

Run notmuch-show-tag-all across the thread.

a

Run notmuch-show-archive-message-then-next-or-next-thread.

A

Run notmuch-show-archive-thread-then-next.

Archive feedback distinguishes a real change, unchanged archive tags, and an unset notmuch-archive-tags. Movement wrappers combine the result instead of duplicating the feedback of nested tag or archive commands.
