8.11.4 Adjust an integration’s speech settings ¶

C-e S opens focused settings directly where available. Alternatively use C-e H j or C-e H . j. In that integration menu, s invokes a local Agent Shell speech-level chooser or EAT/comint autospeak control, c opens the source integration’s settings, and a chooses among Shell/comint and installed Agent Shell, EAT, Org, Notmuch, and EWW. Cancelling returns to the same entry.

The selected integration determines where a change applies and what its Save action retains. For example, a terminal-local setting is not automatically saved as the default for future terminals. The summaries below identify those boundaries; the application chapters give the complete workflows.

  1. Shell/comint and EAT

    Shell/comint’s focused menu toggles automatic speech with s and background monitoring with b. Background reading needs autospeak enabled. Both values belong to the captured buffer for its lifetime; there is no Save action. Arrows announce values and RET activates. q returns to the entry, or closes a direct focused menu. Search at C-e H / finds comint and monitoring. Choosing Shell/comint from another buffer explains the required context and leaves its controls unavailable.

    EAT’s s toggles foreground speech, b content-free background cues/counts, p prompt feedback, and d automatic detail. Background monitoring is independent of foreground autospeak and never reads background content. Changes are local to the terminal, including from frozen review. w saves all four displayed defaults; terminals with overrides keep them. A opens advanced Customize and q returns. All controls are searchable. Choice lists start on the current value; arrows browse, RET applies, and q cancels. See EAT Terminal Access for prompt integration and safety boundaries.

  2. Agent Shell, Org, and EWW

    Agent Shell’s menu covers temporary session speech, global feedback defaults, and reading limits. w saves displayed globals, excluding the session override. See Agent Shell.

    Org’s c chooses cell, header, or combined table-editing feedback and w saves that global default. Column headers come from the first row, row headers from the first column, and local overrides take precedence. t opens Org table options and A advanced Emacsvox Org settings in Customize, returning with q. This editing feedback is separate from the shared table reader described in Browsing Structure.

    EWW’s s controls section-navigation autospeak and i suppresses images on subsequent rendering. It also updates the shared SHR image default while preserving local overrides; it does not reload the page. w saves the two Emacsvox defaults and A opens advanced settings.

  3. Notmuch and shared choice-list navigation

    Notmuch has the same focused menu in Hello, Search, Show, and Tree. c chooses adaptive, count-only, cue-only, or silent successful completion; failures remain audible. f~/~b set field character/UTF-8 byte limits and t~/~B total limits. Shift-left/right steps by 100, RET accepts a positive integer or none for that limit only. w saves those four limits and completion policy: five values, not every mail setting.

    Org and Notmuch choice lists start on the current global value. Arrows browse without applying, RET applies/returns, and q cancels. ? plus a choice key explains effect/scope; q returns to that browsed choice.

    Notmuch’s s~/~m open ordered search/message fields and i~/~I their status maps. These Customize editors preserve custom formatters and use their own Apply/Save/Reset. p opens Presentation Options: enabled mail-message-status-cues owns standard cues, while maps still suppress spoken status tags. A exposes advanced options such as separators. q returns; opening or returning does not save. Notmuch Mail explains privacy and full inspection. Integrations without focused entries remain accessible through major-mode settings and advanced Customize.
