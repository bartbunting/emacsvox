4.8 Exercise answers ¶

Use these answers to check your approach, not as a script you must memorise. Equivalent commands are useful when their scope and result are the same. In Info, l retraces the link from an exercise to its answer.

4.8.1 Answers: lesson 1 ¶

1A. With the unmodified example, M-< C-n C-n C-n reaches the Check line. C-e l reads it without moving, so two repetitions leave the editing position unchanged. A different number of inserted lines changes the count; search is more dependable when you no longer know the exact layout.

1B. Use C-e b, then C-e s. C-e m identifies the buffer and mode; C-e l reads the line at point. Stopping speech does not delete text, move to another buffer, or disable later speech commands.

4.8.2 Answers: lesson 2 ¶

2A. M-< C-s green RET places point after green. M-DEL removes that word; typing blue supplies the replacement. Read the whole line to catch spacing or punctuation mistakes. Restore it with a search for blue followed by the same replacement procedure. Alternatively, use undo-only and inspect after each step, as in the lesson. Deletion and insertion may need separate undos. Stop at the original line rather than assuming a fixed undo count.

2B. Before RET, the letters extend the search query. No document edit has occurred. Accept a successful search, then insert the text at point.

4.8.3 Answers: lesson 3 ¶

3A. Switch to the notes by name, use M-> to reach their end, add a newline and a short sentence, then switch back by name. Neither switch closes the other buffer. C-e m and line reading distinguish them.

3B. C-h k C-e s describes the effective binding. With the default maps, the command is tts-stop. C-h w tts-stop RET reports its keys in the current context. Help describes the binding; it does not invoke it as the requested action. If you need the keys available in the practice document, return there before using C-h w. A Help buffer has its own local bindings.

4.8.4 Answers: lesson 4 ¶

4A. From Monday’s cell, enter with C-e C-t C-r, press Down for Tuesday, then TAB twice to reach Status. RET reads Planned. q restores normal Org editing. While table reading is active, these operations do not realign the source, add rows, or evaluate formulas.

4B. TAB on the heading changes visibility. Return to it and cycle open, or use C-u C-u C-u TAB to expose the whole document. The hidden items never left the buffer. Text undo would affect edits, not provide the intended folding operation.

4.8.5 Answers: lesson 5 ¶

5A. Search accepts a result by selecting its menu control. The separate activation step is what can open an editor or change a value. Reading Help and leaving without activation does not change the punctuation policy.

5B. Closing keeps the chosen live adjustment. Restore the recorded policy in the buffer’s punctuation menu: r for Automatic, or p and the recorded explicit choice. Text undo does not restore speech settings. Uppercase S would save a default, so it is deliberately absent from this exercise.

4.8.6 Answers: lesson 6 ¶

6A. Keep the practice draft on leaving its editor, return to the document, and use C-e H p d to resume that specific draft. Inspect it, then leave with Discard. Use the editor and menu return commands, or select the practice buffer by name once the menus are closed. Do not discard another draft to make the chooser empty.

6B. Preview auditions working values. Keep draft retains unsaved work in this Emacs session. Save to collection writes the destination without selecting an inactive palette. Activate chooses the palette for this session. Use at Startup changes its selection in a saved Presentation Profile; it is not the same as saving the palette. The required exercise uses Preview and Keep draft, then discards. The optional exercise additionally creates and saves a palette and optionally activates it before restoring the original selection. Neither exercise needs Use at Startup.
