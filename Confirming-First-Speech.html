5.3 Confirming First Speech ¶

A successful isolated start speaks a versioned introduction ending with:

I am completely operational, and all my circuits are functioning perfectly!

The preceding overview key and version number can change. The sentence above is the stable first-speech checkpoint. A startup auditory icon may also play, but it depends on optional audio support and is not part of acceptance.

Before changing personal configuration, make these checks in the isolated session:

  1. Type M-x tts-speak-version RET. The live speech adapter should speak its version response.
  2. Type C-h v tts-program RET. The displayed current value should name omnivox.
  3. Use C-n and C-p to move over lines and confirm ordinary spoken navigation. Type M-x emacsvox-describe-emacsvox RET for the Emacsvox overview. See Basic Usage., for the tested starter commands.

Only after these checks pass is the isolated first-use proof complete.
