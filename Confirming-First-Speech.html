2.4 Confirming First Speech ¶

You will know the isolated start succeeded when Omnivox acknowledges the initial engine inventory, routing policy, and logical voices, and Emacsvox speaks:

Emacsvox is ready.

An earlier introduction, overview key, version number, and startup auditory icon may also be heard. Those can change; the sentence above is the stable first-speech checkpoint because it normally occurs after initial routing is acknowledged and therefore uses the restored engine policy. If routing does not finish within five seconds, Emacsvox speaks the checkpoint through the capability-ready fallback so a routing error cannot suppress it indefinitely.

You now have a working Emacsvox session. Try these checks before connecting it to your personal configuration:

  1. Type M-x tts-speak-version RET. The live speech adapter should speak its version response.
  2. Type C-h v tts-program RET. The displayed current value should name omnivox.
  3. Use C-n and C-p to move over lines and confirm ordinary spoken navigation. Type M-x emacsvox-describe-emacsvox RET for the Emacsvox overview. See Basic Usage, for the tested starter commands.

When these checks pass, continue to Basic Usage for a short guided first session, or use Persistent Startup to connect Emacsvox to your normal Emacs configuration.
