3.4.2 Setting TTS Characteristics. ¶

Emacsvox user commands can set different characteristics of the speech output such as speech rate and punctuations mode.

Emacsvox provides settings that affect how text attributes such as capitalization and indentation are conveyed. Each feature has a master switch and a separately selected presentation, so enabling the feature does not force one fixed sound. These settings can be made locally in a given buffer or be applied to all buffers by preceding these commands with C-u.

C-e d r ¶

tts-set-rate

Set speaking RATE for the TTS. Interactive PREFIX arg means set the global default value, and then set the current local value to the result.

C-e d f ¶

tts-set-character-scale

Set scale FACTOR for speech rate. Speech rate is scaled by this factor when speaking characters. Interactive PREFIX arg means set the global default value, and then set the current local value to the result.

C-e d DIGIT ¶

tts-set-predefined-rate

Set speech rate to one of nine predefined levels using digit keys 0 through 9. Interactive PREFIX arg says to set the rate globally.

C-e d p ¶

tts-set-punctuations

Set punctuation mode to MODE. Possible values are some, all, or none. Interactive PREFIX arg means set the global default value, and then set the current local value to the result.

C-e d s ¶

tts-toggle-split-caps

Toggle split caps mode. Split caps mode is useful when reading Hungarian notation in program source code. Interactive PREFIX arg means toggle the global default value, and then set the current local value to the result.

C-e d c ¶

tts-toggle-caps

Toggle capitalization indication. Interactive PREFIX arg means toggle the global default value, then set the current local value to the result.

C-e d C ¶

emacsvox-set-capitalization-presentation

Choose spoken, tone, spoken-tone, custom, or none, and preview representative text. custom publishes facts for personal Aural Presentation rules without adding built-in output. A current Omnivox server applies the selected capitalization presentation to isolated letters as well as queued words; older speech servers retain their engine-specific isolated-letter behavior.

In addition, Emacsvox can convey the indentation of lines as they are spoken — This is relevant when programming and is the default when working with program source.

C-e d i ¶

emacsvox-toggle-audio-indentation

Toggle state of Emacsvox audio indentation. Interactive PREFIX arg means toggle the global default value, and then set the current local value to the result.

C-e d I ¶

emacsvox-set-indentation-presentation

Choose spoken column, duration-coded tone, rising-pitch tone, either tone combined with speech, custom, or none. The command previews a four-column indentation sample. Indentation tones complete before the line is spoken so they do not mask its first phoneme.
