5.8.2 Adjust Rate And Spoken Detail ¶

Start with rate and punctuation, then adjust other feedback when the distinction helps the task. Familiar prose may suit faster speech; exact code inspection may need full punctuation. Direct commands affect the current buffer unless their Help specifies a global prefix form.

C-e d r

Enter a rate with tts-set-rate. The menu alternative is Rate in C-e H s.

C-e d DIGIT

Choose one of ten predefined rates with 0 through 9.

C-e d p

Choose some, all, or none with tts-set-punctuations. A supporting host also offers named profiles, described below.

C-e d s

Toggle splitting of mixed-capital identifiers into words.

C-e d c / C-e d C

Toggle capitalisation indication with the lowercase key. The uppercase key chooses and previews spoken, tone, combined, personal-rule, or no indication. C-e H s c opens the Capitalization menu.

C-e d i / C-e d I

Toggle indentation feedback with the lowercase key, or open its menu with the uppercase key. C-e H s i reaches the same menu through settings.

C-e d T

Choose and preview Alongside speech (default) or Before speech for indentation tones. The current buffer changes; a prefix also updates the default. Save emacsvox-indentation-tone-timing through Customize for restart. Timing does not choose a spoken/tonal presentation or enable indentation. Backends without overlay support play tones before speech for either setting.

  1. Use The Indentation Menu

    Open C-e H s i or C-e d I. Select spoken columns with s, pitch tones with p, or duration tones with d; uppercase P~/~D combines speech and tones. b places tones before speech and a alongside. Timing choices are unavailable for presentations without built-in tones.

    g switches Current buffer and Global defaults. Global defaults leave existing local choices intact. A prefix starts the menu in global scope; e toggles indentation feedback in the displayed scope.

    Up/down selects a control and left/right changes sections. Shift-left/right on Volume changes by five, bounded to 0–100. Other items give guidance rather than changing volume. RET activates an item. These bindings apply inside the menu, not in prompts or the source buffer.

    v or Volume accepts an exact value; -~/~+ remain shortcuts. Volume affects all main-stream Omnivox tones even in buffer scope. Adjustments speak the percentage and interrupt obsolete main speech, so repeated keys announce the latest value rather than queueing old values.

    Changes apply immediately. SPC previews four-column indentation even when feedback is off. q leaves changes in effect. In global scope, S saves indentation defaults and tone volume; closing without saving keeps defaults changed only for this session. M-x emacsvox-set-indentation-presentation remains a direct alternative.

    The following punctuation sections are reference material for changing individual pronunciations. They are not prerequisites for ordinary reading. Reusable palettes/profiles, engine-specific tuning, and the wider output model belong to Aural Presentation. Specialist character-rate and chunking controls are also available through live Help and the generated reference.

  2. Edit Punctuation Pronunciations

    A punctuation level decides how much punctuation is spoken; the pronunciation editor changes how particular characters are read. Open it with C-e H s p e or M-x omnivox-punctuation.

    This interface needs the bundled local launcher and the host’s punctuation-editor capability. Older hosts report that an update is required; remote and native-direct configuration editing are not provided here. It displays saved host settings and an unsaved draft separately. Running speech can still use an earlier configuration.

    Rows identify Unicode characters, pronunciations, and default/override origin. The initial level is some.

    l

    Choose none, some, or all, each with independent overrides; supporting hosts also offer named profiles.

    RET

    Speak a name, preserve the character, or restore its shipped default.

    a

    Add a character not already listed.

    d

    Restore the selected character’s default in this level.

    s

    Save drafts on the host without restarting speech or altering unrelated configuration.

    r

    Restart this session’s main and notification workers with saved settings after confirmation; save or discard drafts first.

    g

    Reread the saved file, asking before discarding edits.

    q

    Return while retaining the draft; reopening the editor resumes it. C-e H p d also resumes retained drafts.

    ?

    Read Help, including the selected host configuration path.

    Preserve character leaves pronunciation and pauses to the engine; it does not promise silence. Org normally uses some. To name apostrophes, set both APOSTROPHE U+0027 and RIGHT SINGLE QUOTATION MARK U+2019 to speak “apostrophe” in some. That includes contractions. Omnivox 1.15.0 names straight, curly, and modifier apostrophes at all without a configuration file.

    1. Save And Activate Changes

      Saving rejects a file or target changed since review and retains the draft for reconciliation. Other configuration is preserved. A named-profile-capable host writes Omnivox configuration version 4, unreadable by 1.16.0 and earlier. The older built-in-only editor writes version 3, requiring 1.15.0 or newer. Do not save a shared file with a format another selected executable cannot read. Capability and configuration-format checks matter even when the main installation uses a newer supported release.

      The editor’s s saves pronunciation data; its r activates through worker restart. By contrast, S in the parent Punctuation menu saves the selected level/profile through Customize, not the host editor’s draft.

    2. Work With Named Profiles

      With host support, N creates a profile inheriting none, some, or all. Use a lowercase ID such as prose or proofreading. l switches levels and profiles; X removes the selected profile from the draft. Profiles inherit base-level edits and override individual characters. s saves all drafts without changing speech; r loads the same definitions into both workers.

      tts-set-punctuations offers profiles whose definitions agree in current workers. Explicit selection applies to the buffer. A preference in tts-punctuation-mode-policy-alist can use (text-mode profile "prose" some), retaining some as fallback for older hosts, missing profiles, or inconsistent worker definitions. Status identifies fallback use. tts-reset-punctuation-mode restores mode policy. Explicitly choosing a built-in level overrides a profile. Character inspection is independent, and there is no built-in most level.
