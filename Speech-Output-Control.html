3.6.2 Adjust Rate, Punctuation, Capitals, And Indentation ¶

Use these controls to match speech to the current material. A faster rate may suit familiar prose; full punctuation can help when inspecting code or exact text. Capitalization and indentation each have an on/off control and a separate choice of spoken or tonal presentation.

The commands affect the current buffer unless their interactive help describes a global prefix form. Use C-h k on a key before changing the global default.

C-e d r ¶

tts-set-rate

Enter a speech rate for the current buffer.

C-e d f ¶

tts-set-character-scale

Set the rate multiplier used when speaking individual characters.

C-e d DIGIT ¶

tts-set-predefined-rate

Choose one of ten predefined rates with 0 through 9.

C-e d p ¶

tts-set-punctuations

Choose some, all, or none punctuation.

C-e d s ¶

tts-toggle-split-caps

Toggle splitting of mixed-capital identifiers into separate words.

C-e d c ¶

tts-toggle-caps

Toggle capitalization indication.

C-e d C ¶

emacsvox-set-capitalization-presentation

Choose speech, a tone, both, a custom Aural rule, or no added indication. The command previews representative text before you finish.

Indentation feedback is especially useful in source code and other structured text. You can switch it off independently or choose how indentation is presented.

C-e d i ¶

emacsvox-toggle-audio-indentation

Toggle indentation feedback.

C-e d I ¶

emacsvox-set-indentation-presentation

Choose a spoken column, one of the tone styles, speech and tone together, a custom Aural rule, or no added indication. The command previews an indented sample before you finish.
