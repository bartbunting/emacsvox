3.6.2 Adjust Rate And Spoken Detail ¶

Use these controls to match speech to the current material. A faster rate may suit familiar prose; full punctuation can help when inspecting code or exact text. Start with rate and punctuation, then change capitalization or indentation feedback only when the distinction would help your current task.

The commands affect the current buffer unless their interactive help describes a global prefix form. Use C-h k on a key before changing the global default.

C-e d r

Enter a speech rate for the current buffer with tts-set-rate.

C-e d DIGIT

Choose one of ten predefined rates with 0 through 9.

C-e d p

Choose some, all, or none punctuation with tts-set-punctuations.

C-e d s

Toggle splitting of mixed-capital identifiers into separate words.

C-e d c / C-e d C

Toggle capitalization indication with the lowercase key. Use the uppercase key to preview and choose whether capitals use speech, a tone, both, a custom rule, or no added indication.

C-e d i / C-e d I

Toggle indentation feedback with the lowercase key. Use the uppercase key to preview spoken-column and tonal choices.

Character-rate scaling, text chunking, engine-specific controls, and reusable presentation profiles are intentionally outside this starter chapter. Use live help for the current speech keymap and see Aural Presentation: Speech, Voices, And Sound when you want a complete presentation setup rather than a temporary buffer change.
