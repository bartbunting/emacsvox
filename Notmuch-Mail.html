10 Notmuch Mail ¶

Notmuch provides the mail index and Emacs interface. Install compatible command-line and Emacs components, then configure the mail store and database using the Notmuch Emacs manual. Emacsvox does not fetch or send mail, create the database, or replace Notmuch’s commands. It adds structured speech to Hello, Search, and Show; Tree has more limited support, described below.

Follow this chapter to search, read, and manage mail with speech, then adjust which information is spoken automatically. The generated emacsvox-notmuch section in the Emacsvox Reference Manual provides the complete command and option reference.
