4 Learn the audio desktop ¶

This tutorial takes you from reading a short document to exploring its structure and making a deliberate speech adjustment. Work through the lessons in order the first time. Each builds on the same practice document; the exercises ask you to use what you have learned without repeating every step. Answers are collected at the end so you can try before consulting them.

Start with a speaking Emacsvox session prepared through Installation, including its settings-menu dependency. No mail account, agent service, downloaded voice, or terminal package is needed. The first five lessons work with text and the Org mode supplied with Emacs. The final lesson uses an already available voice. If your backend cannot preview an adjustment, keep the working voice and follow the reported limitation rather than installing another engine to complete the exercise.

The required exercises do not save speech settings. One clearly marked optional exercise creates a personal palette; you can finish the tutorial without doing it. Do not practise in a document, draft, or configuration that you need to preserve.

If key notation is new to you, read Read the key instructions before starting. It explains modifiers, separate steps, capital letters and command names. The short reminders below use that notation.

Keys are the defaults. C-n means hold Control and press n. In C-e l, press Control-e, release it, then press lowercase l. M- normally means Alt or Option, RET means Enter, and SPC means Space. Capital letters matter. Use M-x, type the command name, and press RET when a command is given by name. Using this manual explains finding a topic and returning from it.
