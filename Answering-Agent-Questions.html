11.2 Answer an agent’s question ¶

Some providers ask you to complete a structured form rather than answer in ordinary prompt text. Agent Shell’s form support is experimental and off by default. To try it, set agent-shell-elicitation--experimental-feature-enabled to non-nil after loading Agent Shell and start a new session so the agent learns that forms are supported. This upstream experimental setting may change.

When a form arrives, Emacsvox announces that an answer is needed and reads the question. Automatic question feedback follows the session’s speech level; quiet suppresses it. Explicit reading and actions still speak.

Use TAB and S-TAB to move between controls in the shell or viewport. Emacsvox reads the field name, whether it is required, and its current value or selection state. Press RET to select an option, toggle a checkbox, or edit a text or number field. Changes are confirmed after they take effect. When an option has a preview, ? opens or closes it; opening it reads its contents. The preview key applies only to controls that offer a preview.

Choose Submit to send the answers or Decline to decline the question. Missing required answers are reported without announcing successful submission. C-c C-c interrupts the running request, including any pending form. To return to the latest question, use M-x agent-shell-elicitation-jump-to-latest-form. The next-field and previous-field commands are also available through M-x.
