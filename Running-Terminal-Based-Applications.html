12 Term Terminal Access ¶

Emacsvox speech-enables the built-in Emacs Term terminal emulator through the module named emacsvox-eterm. The module name is inherited; users do not install a separate Eterm package.

For a new full-terminal workflow, prefer Speech Access To EAT. EAT has the richer current guide for bounded screen output, terminal-side completion, scrollback, alternate screens, and asynchronous rendering. Use built-in Term when avoiding an additional package matters or an application specifically works better there. For ordinary line-oriented shell commands, M-x shell is usually simpler than either terminal emulator.
