13 Term Terminal Access ¶

Term is the terminal emulator built into Emacs. Its Emacsvox integration is named emacsvox-eterm for historical reasons; no separate Eterm package is required. Use Term when avoiding an extra package matters or a particular application works better there.

For a new full-terminal workflow, EAT Terminal Access provides the richer current model for bounded output, terminal completion, scrollback, alternate screens, and asynchronous rendering. For ordinary line-oriented commands, M-x shell is another option. These environments have different input and review keys; do not transfer a key sequence merely because both are terminals.
