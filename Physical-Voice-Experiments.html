6.7.1 Experiment With An Installed Voice ¶

In Browse installed voices, select a physical voice and press t. This opens an experiment with that exact engine and voice, adapter-default speech characteristics, the current base speech rate, and neutral audio effects. Opening, adjusting and comparing write no settings.

The field navigation, adjustments and comparison controls are the same as in Edit a Named Voice. In an experiment, w first asks where to use the result; it cannot save a voice without a palette destination.

To compare pitch on an installed voice:

  1. From Home choose Browse installed voices, select an available engine, and press RET. Select a physical voice and press P. You can use B to compare it with another available voice, using the same sentence.
  2. Press t on the physical voice to open an experiment. Move to Average Pitch, enter 3, and listen. Then enter 7 and listen again. If the engine cannot change pitch, the unsupported setting remains visible.
  3. Press B for the labelled original and edited comparison. Here “original” means the experiment’s captured starting voice, not the immediately preceding edit. u undoes an edit; d restores the adapter default for the current adjustment.
  4. To finish without saving, press q and choose to discard the experiment. To keep it, use the following walkthrough instead.

For a physical experiment, w chooses a destination palette and named voice. The default keeps Physical voice and adjustments — this choice. You can instead keep only the physical voice, only the adjustments for a selected row, or explicitly change shared settings for all inheriting choices. A physical voice can replace a selected row, become preferred, or be appended as a fallback. Row-level adjustments replace that row’s tuning with the experiment’s values and adapter defaults. This prevents unrelated destination shared settings from changing the experiment’s base sound. Use ‘i’ in the row’s individual adjustment panel for any field you want to inherit afterward.

Other rows and shared settings are retained during a row-level keep. Replacing only the physical voice asks whether to keep or reset an existing row’s custom settings. Shared adjustment keeps affect inherited fields; custom row settings still override them. An existing destination draft offers to add the chosen changes or resume without adding. Other edits and pending save recovery remain. The destination opens in the same editor; preview plays the proposed saved combination, which may differ from the experiment because of the chosen scope and destination fallback order. Choosing a destination has not saved anything yet.
