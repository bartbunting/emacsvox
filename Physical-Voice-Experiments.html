8.9.4 Experiment With An Installed Voice ¶

t on a physical voice opens an experiment with that exact engine/voice, adapter-default characteristics, current base rate, and neutral audio effects. Opening, adjusting, and comparing save nothing. Controls match Edit a Named Voice, but w must first choose a palette destination.

To compare pitch:

  1. Open C-e H v b, select an available engine, and press v. Select a physical voice and press P; B can compare with another available voice using the same sentence.
  2. Press t, set Average Pitch to 3, listen, then set 7 and listen again. An unsupported pitch control remains identified.
  3. B compares the captured starting voice with the edited one, not the immediately previous change. u undoes; d restores adapter default.
  4. Finish with q and discard, or keep the experiment using the next walkthrough.

w chooses a destination palette and entry. The default keeps Physical voice and adjustments — this choice. Alternatives keep only the physical voice, only one row’s adjustments, or shared settings for inheriting choices. Physical voices can replace a row, become preferred, or append as fallback. A row-level keep replaces that row’s tuning with the experiment’s values and defaults, preventing unrelated destination shared tuning from changing the base sound. Use i afterward for fields intended to inherit.

Other rows/shared settings survive a row-level keep. Replacing only the physical voice asks whether to keep/reset its tuning. Shared adjustment keeps affect inherited fields; custom rows override them. An existing destination draft can accept the changes or resume untouched, retaining other work and pending save recovery. The destination preview uses the proposed combination, which can differ because of scope/fallback order. Choosing it has not saved.
