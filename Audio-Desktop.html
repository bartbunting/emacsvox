7 Work With The Audio Desktop ¶

Emacs uses buffers for documents, application views, search results, and other work. Each buffer has modes that understand its content. Emacsvox uses that information to present text and state changes through speech, voices, sounds, and structured navigation. Together, these form the audio desktop: the same Emacs environment, experienced through its commands and auditory feedback rather than through a separate graphical desktop.

A useful habit is to press C-e m to hear the current buffer and mode, then C-h m to discover the commands available there. This approach works in files, Web pages, mail, shells, and other Emacs applications.
