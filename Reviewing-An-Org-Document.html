9.2.2 Review structure and correct text ¶

Start in the Org document, not in an Info example. Use C-e m to check the selected buffer. If the note was reopened with content folded, first press M-<, then C-u C-u C-u TAB: Control-u three times, followed by Tab. This shows all content without rewriting it. See Global and local cycling in the Org manual.

At the first heading, C-c C-n moves to the next visible heading and C-c C-p to the previous one. In the example, these let you review Questions and Decisions without reading every paragraph. Emacsvox announces the heading you reach. Use C-e l to repeat it and C-n to begin reading its body.

On a heading, TAB cycles that subtree’s visibility. Listen to the state feedback before moving into it. This is different from Tab in a table or at a completion prompt. The show-all sequence above provides a known starting view if the current folds become confusing. Motion documents the other heading commands, while Browsing Structure explains the speech detail for Org headings.

For a focused text correction in the example:

  1. Press M-<, then C-s, type ready and press RET to finish the search. Search moves point; the subsequent typing will occur there, not in a separate search box. Press C-e l to confirm the sentence.
  2. Point is immediately after ready. Press M-b to move to its beginning, then M-d to remove that word. Type prepared. The surrounding text should now read The draft is prepared for review..
  3. Read the whole line again before saving. If the edit is wrong, press C-g in the document to deactivate any selection, then run M-x undo-only RET and inspect the line. Repeat undo-only only as far as needed; removing the old word and inserting the new one can be separate steps. Unlike ordinary C-/, undo-only does not redo an earlier undo merely because you paused to read between corrections. See Recover a text edit before saving for the full recovery procedure.
  4. Press C-x C-s only when the text is correct. Switch to another buffer and back with C-x b to continue working; leaving the note does not require closing its buffer.

If a search fails, check the text and the starting position. RET ends the search at its current position; C-g can remove a failing suffix before aborting the search, so listen for whether it is still active. Finish or cancel search before issuing editing commands. Keep the desired note selected when saving: a browser page, Help buffer and document do not share Save semantics.

An edit made after a successful save needs another save to replace that file’s contents. Undo also changes the buffer; it does not by itself restore the file on disk. For a separate review version, use Save a separate working copy rather than renaming the buffer and assuming that changed its destination.
