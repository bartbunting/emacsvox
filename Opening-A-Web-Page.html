9.5.1 Open a page and establish your place ¶

  1. Run M-x eww RET. At its next prompt, enter a web address, for example https://www.gnu.org/software/emacs/, and press RET. Text that EWW does not recognise as an address is sent to its configured search service; do not enter private document text as a practice search.
  2. Wait for loading and rendering to finish before navigating the page. An opening cue means the command started, not that the server returned the expected article. Read the page title and any error or login message. Emacsvox normally names the buffer after the page title, so do not assume the buffer is called *eww*. Press C-e m to identify it.
  3. Press M-< and use C-n or C-e l to read. Keep the browser buffer’s name in mind when switching to notes or Help. C-x b returns to that existing buffer; running eww again starts another browsing operation.

To request a separate browser buffer instead of reusing the default one, start with C-u M-x eww RET. This is an intentional use of the prefix argument explained in Read the key instructions. It lets you keep the earlier page available while opening another. A title can change after navigation; check the new buffer name before using it in a later switch.
