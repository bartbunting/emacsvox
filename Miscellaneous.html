3.6.3 Stop, Silence, Restart, Or Identify Speech ¶

Stopping speech ends the current output without disabling future feedback. Quiet mode is useful when you temporarily want to keep working without speech. Restart the server after correcting a backend problem or changing the selected synthesizer.

C-e s ¶

tts-stop

Stop speech now.

C-e d q ¶

tts-toggle-quiet

Toggle speech in the current buffer. Press C-u first to toggle it globally.

C-e C-s ¶

tts-restart

Stop and restart the selected speech server.

To hear which speech adapter is running, use:

C-e d V ¶

tts-speak-version

Speak the selected adapter and its version information.

Use C-h m or the generated keymap reference for server selection, repeated-pattern cleanup, text splitting, language selection, and direct engine controls. Those specialist settings are intentionally outside this starter guide.
