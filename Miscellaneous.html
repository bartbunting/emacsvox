3.6.3 Miscellaneous Speech Commands ¶

Speech can be stopped explicitly using command tts-stop. In normal navigation, replaceable speech supersedes older work in the same replacement domain while ordered and urgent output is preserved. The speech server can be stopped and restarted for cases where the user wants to switch to a different server — or in the rare case to nuke a runaway speech server.

C-e s ¶

tts-stop

Stop speech now.

C-e d q ¶

tts-toggle-quiet

Toggle state of the speech device between being quiet and talkative. Useful if you want to continue using an Emacs session that has emacsvox loaded but wish to make the speech shut up. Optional argument PREFIX specifies whether speech is turned off in the current buffer or in all buffers.

C-e C-s ¶

tts-restart

Use this to stop the currently running speech server and restart it. Useful if you want to switch to another synthesizer while emacsvox is running. Also useful for emergency stopping of speech.

Finally, here are the remaining commands available via the TTS related keymap C-e d.

C-e d a ¶

tts-add-cleanup-pattern

Add this pattern to the list of repeating patterns that are cleaned up. Optional interactive prefix arg deletes this pattern if previously added. Cleaning up repeated patterns results in emacsvox speaking the pattern followed by a repeat count instead of speaking all the characters making up the pattern. Thus, by adding the repeating pattern ‘.’ (this is already added by default) emacsvox will say “aw fifteen dot” when speaking the string “……………” instead of “period period period period”.

C-e d d ¶

tts-select-server

Select a speech server interactively. This will be the server that is used when you next call either M-x tts-initialize or C-e C-s. Argument PROGRAM specifies the speech server program.

C-e d SPACE ¶

tts-toggle-splitting-on-white-space

Toggle splitting of speech on white space. This affects the internal state of emacsvox that decides if we split text purely by clause boundaries, or also include whitespace. By default, emacsvox sends a clause at a time to the speech device. This produces fluent speech for normal use. However in modes such as ‘shell-mode’ and some programming language modes, clause markers appear infrequently, and this can result in large amounts of text being sent to the speech device at once, making the system unresponsive when asked to stop talking. Splitting on white space makes emacsvox’s stop command responsive. However, when splitting on white space, the speech sounds choppy since the synthesizer is getting a word at a time.

C-e d RETURN ¶

tts-set-chunk-separator-syntax

Interactively set how text is split in chunks. See the Emacs documentation on syntax tables for details on how characters are classified into various syntactic classes. Argument S specifies the syntax class.

C-e d V ¶

tts-speak-version

Use this to find out which version of the TTS firmware you are running.

C-e d z ¶

emacsvox-zap-tts

Send this command to the TTS engine directly.
