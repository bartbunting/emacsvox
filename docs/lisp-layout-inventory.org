#+title: Lisp layout allocation review
#+date: 2026-10-18
#+startup: overview

This is the migration review snapshot for all 330 tracked Lisp sources at
the infrastructure checkpoint. The build inventory remains =lisp/Makefile=;
no tool reads this report. The [[file:lisp-layout-plan.org][migration plan]] records ownership decisions,
path-sensitive corrections and verification.

The tables record old/new paths, literal feature declarations and dependencies
found by reading complete Lisp forms without evaluating them. Requirements
inside delayed forms are included; this is not a complete dynamic dependency
graph. Existing hooks, advice and registration calls retain their order.
The exceptional feature declarations in advice, Chess, COMINT and SoX remain
unchanged, including the existing COMINT/Wizards relationship.

Ordinary modules retain their compilation status. The template, autoload
generator and three optional Muggles sources retain their separate status.
Generated loaddefs are not tracked source. Dedicated tests follow module
basenames where available; shared and installed-tree coverage supplements them.
