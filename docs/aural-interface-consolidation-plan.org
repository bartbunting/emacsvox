* Acceptance cases fixed before implementation

| Case | Required result |
| =a → b → c → acss-default= | Nearest whole entry wins; the row names its defining palette. |
| Edit inherited bolden in =a= | Create a complete entry and correctly owned local choices in =a=; ancestors remain unchanged. |
| Reset that entry | The inherited row remains visible and can be edited again. |
| Copy =a= independently | Copy effective definitions and ordered choices; keep per-choice tuning; new parent is the standard root. |
| New Voice in an empty personal palette | Open one complete editable draft; no definition-only rejection after collecting values. |
| =bolden= and =voice-bolden= requests | Same named entry and choices; terminal personality decoding does not recurse. |
| Registered nonstandard personality | Exact declared identity remains usable and visible; no arbitrary prefix guessing. |
| Generated =voice-from-acss= handle | Issued identity resolves to copied raw ACSS independently of the palette; maths and sampler speech retain their style. |
| Generated preset followed by a style adjustment | Replace the previous base, then apply the adjustment; retain raw-record partial composition and nil/zero distinctions. |
| Palette entry or stable personality named =acss= or =acss-*= | Reject the declaration before mutation, even before such a handle is issued; an unissued lookalike remains unknown. |
| Generated handle after adapter cache reset | Recreate from retained raw ACSS and use existing registration for both lanes; do not parse the name. |
| Persisted generated-handle reference | Report it before saving/importing/conversion; reusable saved voices carry complete definitions or stable references. |
| Unknown named voice | Authoring rejects it; unexpected runtime use preserves content and supplies a diagnostic. |
| Ordinary unstyled speech, explicit ACSS and inaudible | Preserve established semantics independently of named-voice lookup. |
| Current =bart= conversion | Keep identity, stored representations, ordered local choices, tuning and profile references; enumerate added standard inheritance. |
| Save an inactive palette | Save without selecting is available; Save and Apply reports session selection separately from startup selection. |
| Select a palette for startup | Change the intended profile field; preserve unrelated saved profile fields and current divergences. |
| Export/import | Portable export declares omitted local choices; local copies retain complete choices; replacement requires explicit selection. |
| Navigation in a non-first column | Read the new selected cell; full-row speech remains a separate action. |
| Delayed or failed application | Saved state stays distinguishable from playback/application; old callbacks cannot clear newer edits. |

** TODO 3. Complete palette and voice operations — High

the built-in root prepares a personal child draft; browsing and previewing write

data services. Parent changes exclude invalid targets and report affected entries.

Copy Palette makes an independent effective copy. Do not add another “linked
