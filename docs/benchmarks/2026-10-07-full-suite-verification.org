#+TITLE: Full Emacsvox suite verification
#+DATE: 2026-10-07

* Result

The complete =make -k test= target passes with the configured Emacs 31.0.90.
The unit run contains 4,032 tests: 3,992 pass in batch and 40 skip because they
need a graphical display, a native service, or an optional package. All 40
were run separately in their required environments and passed.

Verification included the Agent Shell changes and used isolated Emacs processes.

* Issues fixed

- Seven documentation assertions still expected markup from before the Org
  conversion. They now check the current Org code and key notation and the
  generated Texinfo links. Live key/command checks remain in place. The
  missing-command failure now passes one formatted argument to =ert-fail=.
- Speech preparation fault injection depended on whether native-call
  trampolines had already been installed by another test. Preparing the
  required primitive interceptors before mocking them makes the faults
  reproducible. It also prevents trampoline compilation from running while
  its subprocess transport is mocked. All 21 preparation tests pass.
- An EAT screen redraw could speak its trailing prompt when the terminal
  delivered the redraw in multiple chunks. Collection now remains suppressed
  until that burst settles. A regression checks every split point in clear
  and reset sequences and verifies that subsequent ordinary output speaks.
  Source and compiled checks also exercise real graphical terminal output.
- Recursive configuration expanded =MAKEFLAGS= as shell arguments. With
  =make -k=, the child Make interpreted =k= as a target. Configuration now
  uses Make's inherited flags. A dry-run regression verifies recursive
  keep-going configuration without changing generated files.

Agent Shell integration used the verified 0.86.1 dependency tree. Compiled EAT
checks explicitly loaded all four EAT implementation modules from current
byte-code in fresh Emacs processes. Graphical tests used private Xvfb displays.
Mu4e was loaded from the installed system package, which is absent from the
ordinary =-Q= test load path.

The first native probe used an old Omnivox 1.15.0 binary and correctly rejected
missing engine-setting and punctuation-profile capabilities. Running =make dev=
in the existing Omnivox checkout produced a complete 1.16.0 development payload;
all four native checks passed with that payload, isolated configurations, and
null audio. Omnivox source and the live speech runtime were not changed.

These checks establish behavior and speech submissions, not audible playback.
Native Windows installer lifecycle checks require a Windows test host; this
run covers their Linux packaging fixtures. No additional Emacs-version matrix
or release publication was performed.
