The implementation follows [[file:adr/0018-unified-voice-palette-model.org][ADR 0018]] after the corrections below. The focused

This reviews the implementation through the Medium table/manual slice and the

* Findings corrected

1. Reset and other simple palette mutations used the old whole-settings writer.
   A newer saved profile could be replaced by stale live settings while resetting
   a voice. Mutations now merge only changed palettes into the saved document,
   reject a changed saved destination, and check the file fingerprint before
   writing. Failed persistence leaves the live registry intact.
2. Reset named the immediate parent even when a grandparent supplied the voice.
   The confirmation now names the actual defining palette.
3. Reset did not recheck the inherited entry after confirmation. A changed
   ancestor could silently change the reviewed result. The full inherited entry
   and its owner are now checked again before mutation.
4. Deleting the active palette could persist deletion before discovering that
   the baseline lacked a voice required by current rules. The replacement
   selection is now validated in the staged registry before writing.
5. Whole-palette deletion did not protect unfinished voice drafts. It now uses
   the existing pending-edit guard, rechecks uses after confirmation, and only
   discards clean editor contexts after successful deletion.
6. Use at Startup could accept a palette missing a custom voice required by the
   saved rules. It now checks saved palette ancestry, personal rules and the
   saved options selected by the profile. Unsaved personal changes and session
   or buffer rules remain outside that check. Loaded integration declarations
   retain runtime reference semantics. Rejection changes neither file nor
   selected profile.

Six regression cases fail against the preceding implementation and pass with
these corrections. Additional cases cover a changed saved destination, saved
option contents diverging from live contents, and exclusion of session rules.
Palette action descriptions also say “for this session” instead of “override.”
