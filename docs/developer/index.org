* Developer And Maintainer Guide
:PROPERTIES:
:TEXINFO_NODE_NAME: Developer Guide
:DESCRIPTION: Develop, test, and maintain Emacsvox integrations and protocols.
:END:

This guide is for people changing Emacsvox source, integrations, speech-server
protocols, build machinery, or release staging.  It is included at the end of
the published manual so that an installed Info manual and an offline checkout
remain complete, but it is not part of the ordinary installation and use path.

Before making a governed change, read ~AGENTS.md~ and every accepted record in
~docs/adr/~.  Use the Emacs selected by ~local.mk~ for repository checks.  The
generated @@texinfo:@ref{Top,Emacsvox Reference Manual,,emacsvox-reference,Emacsvox Reference Manual}@@
is the exact inventory of Lisp commands, options, and keymaps; the chapters
that follow explain contracts and procedures that cannot be generated from
those interfaces.
