* Scope and baseline

This is an internal review record, outside the published manual. The audit
started from a clean =master= worktree at =51cd10af2=, including the latest
managed-Muggles changes. No application code, personal configuration or running
Emacs session was changed. No commit, push, publication or release was made.

Read =AGENTS.md=, the complete editorial guide and all 29 ADRs. Read all 19
included user chapters and the four included developer files in full. Reviewed
README, current NEWS, installation and setup routes, the test guide, Debian
package instructions, server component guides and sound-pack notes. Archived
release notes, announcements, design contracts and review reports were assessed
for purpose, references and historical value; they were not all revalidated as
current operating instructions.

The implementation comparison covered command definitions, menu entries,
keymaps, defaults, loading and dependencies for settings discovery, reading,
indentation, capitalization, spelling, interaction, voice and sound workflows,
tables, Agent Shell, EAT, Notmuch and managed Muggles. Focused tests exercise
scope, explicit saving, cancellation and return paths. Isolated regeneration
checks the complete generated public command, option and key reference against
current Lisp. This does not claim a behavioural test of every public command
or every optional integration.
