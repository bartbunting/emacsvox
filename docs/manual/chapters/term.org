* Term Terminal Access
:PROPERTIES:
:TEXINFO_NODE_NAME: Running Terminal Based Applications
:ALT_TITLE: Running Terminal Based Applications
:DESCRIPTION: Use Term with speech and screen review.
:END:

#+cindex: Term mode
#+cindex: terminal applications
#+cindex: Eterm, Emacsvox module name

Term is the terminal emulator built into Emacs. Its Emacsvox integration is
named =emacsvox-eterm= for historical reasons; no separate Eterm package is
required. Use Term when avoiding an extra package matters or a particular
application works better there.

For a new full-terminal workflow, [[*Speech Access To EAT][EAT Terminal Access]] provides the richer
current model for bounded output, terminal completion, scrollback, alternate
screens, and asynchronous rendering. For ordinary line-oriented commands,
~M-x shell~ is another option. These environments have different input and
review keys; do not transfer a key sequence merely because both are terminals.

** Starting Term
:PROPERTIES:
:TEXINFO_NODE_NAME: Starting Term
:END:

#+findex: term

Run ~M-x term RET~. At =Run program:=, accept the proposed shell or enter
another executable and press ~RET~. Emacsvox makes the selected Term window
fill the frame when =term= or =ansi-term= starts. This changes window layout,
not the existence of buffers previously shown in other windows.

Term emulates the terminal, the child program handles input and completion,
and Emacsvox presents the rendered buffer. See [[info:emacs#Term Mode][Term Mode]] in /The GNU
Emacs Manual/ for the emulator and [[info:emacsvox-reference#emacsvox-eterm][emacsvox-eterm]] in the /Emacsvox Reference
Manual/ for the complete integration reference.

** Character And Line Input Modes
:PROPERTIES:
:TEXINFO_NODE_NAME: Term Input Modes
:ALT_TITLE: Term Input Modes
:END:

#+cindex: character mode, Term
#+cindex: line mode, Term
#+findex: term-char-mode
#+findex: term-line-mode

Term starts in character mode. Choose according to who should receive the keys:

#+attr_texinfo: :indic asis :compact t
- Character mode ::

  Most keys are sent immediately to the terminal program. This suits
  full-screen or key-driven applications. ~C-c C-j~ enters line mode.
  Normal Emacs prefixes may belong to the child, so use ~C-c C-h m~ for
  mode help and ~C-c M-x~ to run an Emacs command.
- Line mode ::

  Ordinary Emacs editing commands edit pending input; ~RET~ sends it to
  the program. Emacs Help keys such as ~C-h m~ work directly.
  ~C-c C-k~ returns to character mode.

An interactive switch announces =Terminal line mode= or
=Terminal character mode=. In either mode, ~C-t~ introduces Term's Emacsvox
review commands. Send a literal ~C-t~ to the child in character mode with
~C-t C-t~.

Use the input-mode escape before trying ordinary Emacs settings or Help keys
that the child might otherwise receive. In line mode, ~C-e H~ opens the
Emacsvox settings menu. Its general settings do not replace Term's own
buffer-local automatic-speech control below. Likewise, ~q~ closes an Emacsvox
menu or dedicated review only while that interface owns the keys; it is not
a general command to leave a running terminal application.

** Automatic Speech Feedback
:PROPERTIES:
:TEXINFO_NODE_NAME: Term Speech Feedback
:ALT_TITLE: Term Speech Feedback
:END:

#+cindex: automatic speech, Term
#+vindex: emacsvox-eterm-autospeak
#+findex: emacsvox-toggle-eterm-autospeak

=emacsvox-eterm-autospeak= controls automatic feedback in the current buffer
and defaults to enabled. ~C-t C-q~ toggles it. The older spelling
=eterm-autospeak= is not an Emacsvox variable.

A Term buffer must be displayed in a live window for automatic output speech.
A hidden buffer can keep running silently. This displayed-window condition is
not EAT's selected-buffer and keyboard-focus policy.

In line mode, speech reads newly inserted output as a range rather than
interrupting it for every character. In character mode, rendered cursor and
screen changes determine whether a character, word, movement, or reached line
is presented. New terminal activity can stop earlier speech.

This integration does not provide EAT's bounded screen transactions,
completion model, or alternate-screen policy. When a redraw is ambiguous or
an announcement too brief, use the explicit review commands.

** Reviewing The Term Screen
:PROPERTIES:
:TEXINFO_NODE_NAME: Reviewing The Term Screen
:END:

#+cindex: review pointer, Term
#+cindex: review mode, Term

The review pointer is independent of the terminal cursor. Moving it does not
send keys or move the child application. It reviews the Term buffer, not the
immutable snapshot used by EAT's frozen review. The normal prefix is ~C-t~:

#+attr_texinfo: :indic kbd :compact t
- C-t . ::

  Place the review pointer at the terminal cursor and announce its coordinates.
- C-t p ::
- C-t n ::

  Move to the previous or next line and speak it. ~C-t <up>~ and
  ~C-t <down>~ are equivalent.
- C-t <left> ::
- C-t <right> ::

  Move by a character and speak the destination.
- C-t M-b ::
- C-t M-f ::

  Move backward or forward by a word and speak it.
- C-t l ::
- C-t w ::
- C-t c ::

  Read the line, word, or character at the review pointer without moving.
- C-t SPC ::

  Read from the pointer to the current end of the Term buffer.
- C-t s ::

  Ask for text, search forward from the pointer, and read the matching line.

In character mode, ~C-t q~ enters dedicated review. Ordinary keys then stay
in review rather than reaching the child. Use ~p~, ~n~, arrows, ~M-b~,
~M-f~, ~l~, ~w~, ~c~, and ~s~ without the prefix. ~q~ returns to character
mode. To copy text, set one endpoint with ~m~, move the pointer, then press
~y~ to copy the region to the kill ring.

Named rectangular regions and focus/filter windows are advanced,
coordinate-based facilities. Consult the live mode Help and generated
reference before using them; remember the character-mode Help prefix when
ordinary Emacs keys would otherwise reach the child.

** Help And Recovery
:PROPERTIES:
:TEXINFO_NODE_NAME: Term Help And Recovery
:ALT_TITLE: Term Help And Recovery
:END:

For visible but silent output, inspect =emacsvox-eterm-autospeak= in the
current buffer and ensure that buffer is displayed. Toggle with ~C-t C-q~
when necessary, then test new output. An automatic-speech setting does not
prove that the program has produced a new readable screen change.

If an Emacs command goes to the child, check the input mode. In character
mode use ~C-c C-h m~, ~C-c M-x~, or switch to line mode with ~C-c C-j~.
If dedicated review owns the keys, ~q~ returns to character mode first.

When review has moved away from current output, ~C-t .~ resynchronises the
pointer. Leave dedicated review with ~q~ before using the normal prefix.
For a full-screen redraw that Term cannot present reliably, try the workflow
in [[*Speech Access To EAT][EAT Terminal Access]] and use that emulator's explicit review commands.
