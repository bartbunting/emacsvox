* Work With The Audio Desktop
:PROPERTIES:
:TEXINFO_NODE_NAME: Audio Desktop
:ALT_TITLE: Audio Desktop
:DESCRIPTION: Work with buffers, modes, structure, and search.
:END:

#+cindex: Audio Desktop

Emacs uses buffers for documents, application views, search results, and other
work. Each buffer has modes that understand its content. Emacsvox uses that
information to present text and state changes through speech, voices, sounds,
and structured navigation. Together, these form the /audio desktop/: the same
Emacs environment, experienced through its commands and auditory feedback
rather than through a separate graphical desktop.

A useful habit is to press ~C-e m~ to hear the current buffer and mode, then
~C-h m~ to discover the commands available there. This approach works in
files, Web pages, mail, shells, and other Emacs applications.

** Buffers Hold Your Work
:PROPERTIES:
:TEXINFO_NODE_NAME: Desktop Objects
:ALT_TITLE: Desktop Objects
:DESCRIPTION: Understand and move between Emacs buffers.
:END:

#+cindex: buffers

A buffer holds the content or application view you are working with. It might
contain a file, an Info manual, a Dired listing, a Web page, mail search
results, a shell session, or Help text. Some buffers visit files; others exist
only within the Emacs session.

The mode line identifies the selected buffer and its major mode. Press
~C-e m~ to hear it. These are the main ways to change buffers:

#+attr_texinfo: :indic kbd :compact t
- C-x b ::

  Switch to another buffer by name.  Completion lets you narrow the choices
  instead of remembering the complete name.

- C-x C-b ::

  Open a buffer list.  In that list, use ~C-h m~ to learn its navigation,
  selection, saving, and cleanup commands.

- C-x k ::

  Close a buffer that you no longer need.  Emacs asks before discarding
  unsaved file changes.

Switching buffers does not close the one you left. You can work on a document,
consult Help or a reference, visit a shell, and return to the document without
reopening it.

*** Cycle Between Buffers of the Same Kind
:PROPERTIES:
:TEXINFO_NODE: no
:END:

#+cindex: buffer cycling
#+kindex: C-e n
#+kindex: C-e p
#+kindex: C-e .
#+kindex: C-e ,

When several buffers use the same major mode, you can cycle among them
without recalling their names. This is useful for comparing Org notes,
visiting several Dired directories, or moving between source files.

Press ~C-e n~ to select the next buffer with the same major
mode, or ~C-e p~ to select the previous one.  For example, from
an Org buffer these commands visit other Org buffers, skipping all buffers
that do not use the same major mode.  Buffers are grouped by major mode, not
by project or directory.

After the first command, you only need the final letter: ~n~
continues forward and ~p~ moves backward.  You can change
direction at any time, and cycling wraps around when you reach the end.  For
example, ~C-e n n p~ moves forward twice, then returns to the
buffer you just left.

To navigate without the major-mode filter, use ~C-e .~ for
next buffer or ~C-e ,~ for previous buffer.  You can then repeat
with just ~.~ or ~,~, in the same way as
~n~ and ~p~.  You can also switch between these
controls while cycling.

The temporary buffer-selection controls also include ~b~ to
select a buffer by name, ~f~ to open a file,
~k~ to kill a buffer, and ~o~ to change windows.

Press ~C-g~ when finished to return to normal editing.  A key
outside the temporary buffer-selection controls also ends cycling and
performs its normal action.  To choose a particular buffer by name, use
~C-x b~.

** Let Modes Give Each Buffer Its Tools
:PROPERTIES:
:TEXINFO_NODE_NAME: Object Oriented Desktop
:ALT_TITLE: Object Oriented Desktop
:DESCRIPTION: Let major and minor modes interpret each kind of content.
:END:

#+cindex: major modes

#+cindex: minor modes

Each buffer has one major mode responsible for its principal editing or
application commands. Programming-language modes work with source code,
Dired with directories, EWW with Web pages, and Org with structured notes.
Minor modes add optional behaviour without replacing the major mode.

The active mode determines which structures Emacs can navigate. In prose you
might move by sentence; in Org by heading; in a list by item. Emacsvox speaks
the result and can announce relevant state changes. To discover the mode's
commands, press ~C-h m~, then ~C-h k~ followed by a key for more detail.
[[*Find Help While You Work][Using Online Help]] explains these help commands.

** Hear And Navigate The Current Context
:PROPERTIES:
:TEXINFO_NODE_NAME: Context-Sensitive Interaction
:ALT_TITLE: Context-Sensitive Interaction
:DESCRIPTION: Use aural structure, mode commands, buffers, and search.
:END:

#+cindex: Context-Sensitive Interaction

Because Emacsvox has access to Emacs modes and application state, it can
announce the kind of object you have reached rather than treating everything
as undifferentiated text. Use the active mode's navigation for the structure
you are working with, and request more spoken detail as needed.

*** Hear Structure Without Extra Words
:PROPERTIES:
:TEXINFO_NODE: no
:END:

#+cindex: audio formatting

Voice changes can distinguish headings, comments, strings, links, warnings,
and other meaningful text.  Short sounds and tones can mark events or state
changes without interrupting the spoken content.  Ordinary text remains
available through the usual reading commands.

The exact result depends on the mode, the Emacsvox integration, and your Aural
Presentation settings.  [[*Aural Presentation: Speech, Voices, And Sound][Aural Presentation]] explains how the
parts fit together, including the established Voice Lock compatibility layer;
~C-e E~ explains the presentation chosen for the object at point.

*** Move By The Structure Of The Content
:PROPERTIES:
:TEXINFO_NODE: no
:END:

#+cindex: structured navigation

Prefer the navigation supplied by the active mode when it matches your task.
For example, Info moves among nodes and menu entries, Org and Outline move
among headings, Dired moves among files, programming modes understand
definitions and diagnostics, and EWW exposes links and document structure.

The mode's Help, available through ~C-h m~, describes its navigation
commands, including those supplied by installed packages and your
customisations. [[*Browsing Structure][Browsing Structure]] points to guides for common kinds of structured
content.

*** Move Between Tasks Without Losing Your Place
:PROPERTIES:
:TEXINFO_NODE: no
:END:

#+cindex: desktop navigation

Buffers keep different tasks available in one Emacs session.  Use
~C-x b~ to return to a known buffer or ~C-x C-b~ to browse the
current set.  Emacs windows can show more than one buffer at a time; if the
selected window is unclear, ~C-e C-w~ describes the arrangement.

Applications often create several related buffers, such as a search result and
an individual message.  Their mode help explains the commands for moving among
those views.  Treat each buffer as a place you can revisit, rather than as a
dialog that must be completed before doing anything else.

*** Search Wherever You Are
:PROPERTIES:
:TEXINFO_NODE: no
:END:

#+cindex: searching

#+cindex: finding

In most text buffers, ~C-s~ searches forward incrementally and
~C-r~ searches backward.  Type more text to narrow the match, repeat the
search key to move to another match, and press ~C-g~ to cancel.  This same
basic search is available in documents, Help, source code, and many application
results.

Also look for the mode's semantic search and filtering commands.  A mail
application can search message fields, Dired can narrow files, and a browser
can move directly among links or headings.  Use the general search when text
is what matters and the mode-specific command when the kind of object matters.
