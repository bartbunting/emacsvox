* Work With The Audio Desktop
:PROPERTIES:
:TEXINFO_NODE_NAME: Audio Desktop
:ALT_TITLE: Work with the audio desktop
:DESCRIPTION: Keep work in buffers and windows, navigate structure, and find text.
:END:

#+cindex: Audio Desktop

Emacs uses buffers for documents, application views, search results, and other
work. Each buffer has modes that understand its content. Emacsvox uses that
information to present text and state changes through speech, voices, sounds,
and structured navigation. Together, these form the /audio desktop/: the same
Emacs environment, experienced through its commands and auditory feedback
rather than through a separate graphical desktop.

A useful habit is to press ~C-e m~ to hear the current buffer and mode, then
~C-h m~ to discover the commands available there. This approach works in
files, Web pages, mail, shells, and other Emacs applications.

** Buffers Hold Your Work
:PROPERTIES:
:TEXINFO_NODE_NAME: Desktop Objects
:ALT_TITLE: Buffers hold your work
:DESCRIPTION: Understand and move between Emacs buffers.
:END:

#+cindex: buffers

A buffer holds the content or application view you are working with. It might
contain a file, an Info manual, a Dired listing, a Web page, mail search
results, a shell session, or Help text. Some buffers visit files; others exist
only within the Emacs session.

The mode line identifies the selected buffer and its major mode. Press
~C-e m~ to hear it. These are the main ways to change buffers:

#+attr_texinfo: :indic kbd :compact t
- C-x b ::

  Switch to another buffer by name.  Completion lets you narrow the choices
  instead of remembering the complete name.

- C-x C-b ::

  Open a buffer list.  In that list, use ~C-h m~ to learn its navigation,
  selection, saving, and cleanup commands.

- C-x k ::

  Close a buffer that you no longer need.  Emacs asks before discarding
  unsaved file changes.

Switching buffers does not close the one you left. You can work on a document,
consult Help or a reference, visit a shell, and return to the document without
reopening it.

*** Cycle Between Buffers of the Same Kind
:PROPERTIES:
:TEXINFO_NODE: no
:END:

#+cindex: buffer cycling
#+kindex: C-e n
#+kindex: C-e p
#+kindex: C-e .
#+kindex: C-e ,

When several buffers use the same major mode, you can cycle among them
without recalling their names. This is useful for comparing Org notes,
visiting several Dired directories, or moving between source files.

Press ~C-e n~ to select the next buffer with the same major
mode, or ~C-e p~ to select the previous one.  For example, from
an Org buffer these commands visit other Org buffers, skipping all buffers
that do not use the same major mode.  Buffers are grouped by major mode, not
by project or directory.

After the first command, you only need the final letter: ~n~
continues forward and ~p~ moves backward.  You can change
direction at any time, and cycling wraps around when you reach the end.  For
example, ~C-e n n p~ moves forward twice, then returns to the
buffer you just left.

To navigate without the major-mode filter, use ~C-e .~ for
next buffer or ~C-e ,~ for previous buffer.  You can then repeat
with just ~.~ or ~,~, in the same way as
~n~ and ~p~.  You can also switch between these
controls while cycling.

The temporary buffer-selection controls also include ~b~ to
select a buffer by name, ~f~ to open a file,
~k~ to kill a buffer, and ~o~ to change windows.

Press ~C-g~ when finished to return to normal editing.  A key
outside the temporary buffer-selection controls also ends cycling and
performs its normal action.  To choose a particular buffer by name, use
~C-x b~.

** Work with windows without losing your place
:PROPERTIES:
:TEXINFO_NODE_NAME: Working With Windows
:DESCRIPTION: Keep several views available while knowing where commands and edits will act.
:END:

#+cindex: windows, working through speech
#+cindex: buffer versus window

A buffer contains your work; a window is a view of a buffer. Emacs calls its
outer application window a /frame/. A frame can contain several Emacs windows,
but only one is selected for ordinary commands. You can work with those views
by name and spoken context without needing to picture their arrangement.

Switching buffers with ~C-x b~ changes the selected window's contents.
Selecting another window with ~C-x o~ moves to that view instead. The final
character is lowercase o, for "other", not the digit zero. Emacsvox announces
the selected buffer and mode; ~C-e m~ repeats that context and ~C-e l~ checks
the current line. ~C-e C-w~ describes the window arrangement.

Two windows can show the same buffer at different positions. They are not
independent document copies: edits in either change the same text, and the
buffer has one mark. For two independent documents, select different buffers.
The GNU Emacs Manual's [[info:emacs#Windows][Multiple windows]] section explains this model in detail.

*** Keep a reference and a draft in separate windows
:PROPERTIES:
:TEXINFO_NODE_NAME: Reference And Draft Windows
:DESCRIPTION: Consult a reference, copy a passage and return to the intended draft.
:END:

Begin with an editable draft selected and a reference buffer already open.
Finish prompts and leave settings editors first. For a safe first attempt,
use the source and notes buffers from [[*Copy a passage into another buffer][Copy a passage into another buffer]].
Keep their names available so that you can recover by buffer name at any time.

1. In the draft, press ~C-x 4 b~, enter the reference buffer's name, and press
   ~RET~. The digit 4 is a separate keypress. Emacs displays and selects the
   reference in another window, creating or reusing a view according to its
   display configuration. ~C-x 4 f~ does the equivalent for a file pathname.
2. Check the selected buffer with ~C-e m~ and read a line or paragraph. Use
   short inspections when you intend to retain point. Tracked reading with
   ~C-e i~ moves the reference's reading position as explained in
   [[*Read from point, stop, and start again][Read from point, stop, and start again]].
3. Press ~C-x o~ to select the next window and identify it before typing.
   With two ordinary windows this usually alternates between reference and
   draft. With more windows, repeat until the intended draft is selected;
   do not assume the next view must be the draft.
4. To transfer text, return to the reference, select and check a short passage,
   then copy with ~M-w~. Use ~C-x o~ to return to the draft, confirm its buffer
   and insertion point, and press ~C-y~. The reference text remains unchanged.
   Follow [[*Copy a passage into another buffer][Copy a passage into another buffer]] for kill-ring and newline checks.
5. Return to the reference with ~C-x o~. Its position is where you last left
   it, including movement made while selecting or reading. Inspect it rather
   than assuming copying restored an earlier reading position.

If window selection becomes confusing, ~C-x b~ and a known buffer name is
always a useful recovery route from ordinary work. It can replace the current
view rather than restore the old layout; the buffer's text remains available.

Some speech commands intentionally change the layout. ~C-e h~ selects and
reads Help using a windowful-reading helper, which removes other windows.
Whole-buffer and region reading can use that helper for a large request too.
A lost split therefore does not necessarily mean the reference was closed.
Reopen the desired view with ~C-x 4 b~. For a short inspection without that
helper, use line or paragraph reading as described under
[[*Read a short passage without moving point][Read a short passage without moving point]].

For the general display and selection commands, see [[info:emacs#Pop Up Window][Displaying in another window]]
and [[info:emacs#Other Window][Using other windows]] in the GNU Emacs Manual. Emacsvox adds speech to the
selection; it does not make the ordinary display rules identical in every setup.

*** Close a window without closing the document
:PROPERTIES:
:TEXINFO_NODE_NAME: Closing Windows Safely
:DESCRIPTION: Simplify the layout without killing buffers or discarding unsaved text.
:END:

Finish active prompts, then select the view you want to remove and check its
buffer with ~C-e m~. Press ~C-x 0~: Control-x, then the digit zero. This
removes the selected window, not its buffer or file. Select the buffer again
with ~C-x b~ when you need it.

To keep only the selected view in the frame, use ~C-x 1~ instead. The other
buffers remain available and unsaved text remains unsaved. These layout
commands are neither file saving nor undo. If Emacs cannot remove the last
ordinary window or a specially managed view, follow its explanation rather
than closing Emacs to force the layout change.

~C-x k~ has a different purpose: it kills a buffer, with any applicable
unsaved-work prompt. ~C-x 4 0~ kills the buffer as well as its window; it is
not a longer spelling of ~C-x 0~. Likewise, ~q~ belongs to the current mode:
in a plain document it usually inserts a letter, while Help, Info and Dired
have their own return commands.

See [[info:emacs#Change Window][Deleting and rearranging windows]] in the GNU Emacs Manual for the full
set of layout operations. Keep [[*Buffers Hold Your Work][Buffers hold your work]] as the reference for
buffer selection and closing work itself.

** Let Modes Give Each Buffer Its Tools
:PROPERTIES:
:TEXINFO_NODE_NAME: Object Oriented Desktop
:ALT_TITLE: Let modes give each buffer its tools
:DESCRIPTION: Let major and minor modes interpret each kind of content.
:END:

#+cindex: major modes

#+cindex: minor modes

Each buffer has one major mode responsible for its principal editing or
application commands. Programming-language modes work with source code,
Dired with directories, EWW with Web pages, and Org with structured notes.
Minor modes add optional behaviour without replacing the major mode.

The active mode determines which structures Emacs can navigate. In prose you
might move by sentence; in Org by heading; in a list by item. Emacsvox speaks
the result and can announce relevant state changes. To discover the mode's
commands, press ~C-h m~, then ~C-h k~ followed by a key for more detail.
[[*Find Help While You Work][Using Online Help]] explains these help commands.

** Hear And Navigate The Current Context
:PROPERTIES:
:TEXINFO_NODE_NAME: Context-Sensitive Interaction
:ALT_TITLE: Hear and navigate the current context
:DESCRIPTION: Use aural structure, mode commands, buffers, and search.
:END:

#+cindex: Context-Sensitive Interaction

Because Emacsvox has access to Emacs modes and application state, it can
announce the kind of object you have reached rather than treating everything
as undifferentiated text. Use the active mode's navigation for the structure
you are working with, and request more spoken detail as needed.

*** Hear Structure Without Extra Words
:PROPERTIES:
:TEXINFO_NODE: no
:END:

#+cindex: audio formatting

Voice changes can distinguish headings, comments, strings, links, warnings,
and other meaningful text.  Short sounds and tones can mark events or state
changes without interrupting the spoken content.  Ordinary text remains
available through the usual reading commands.

The exact result depends on the mode, the Emacsvox integration, and your Aural
Presentation settings.  [[*Aural Presentation: Speech, Voices, And Sound][Aural Presentation]] explains how the
parts fit together, including the established Voice Lock compatibility layer;
~C-e E~ explains the presentation chosen for the object at point.

*** Move By The Structure Of The Content
:PROPERTIES:
:TEXINFO_NODE: no
:END:

#+cindex: structured navigation

Prefer the navigation supplied by the active mode when it matches your task.
For example, Info moves among nodes and menu entries, Org and Outline move
among headings, Dired moves among files, programming modes understand
definitions and diagnostics, and EWW exposes links and document structure.

The mode's Help, available through ~C-h m~, describes its navigation
commands, including those supplied by installed packages and your
customisations. [[*Browsing Structure][Browsing Structure]] points to guides for common kinds of structured
content.

*** Move Between Tasks Without Losing Your Place
:PROPERTIES:
:TEXINFO_NODE: no
:END:

#+cindex: desktop navigation

Use ~C-x b~ to return to a known buffer or ~C-x C-b~ to browse the current
set. For a reference and draft displayed together, follow
[[*Keep a reference and a draft in separate windows][Keep a reference and a draft in separate windows]]. Select the intended view
and inspect its buffer before editing; ~C-e C-w~ describes the arrangement.

Applications often create several related buffers, such as a search result and
an individual message.  Their mode help explains the commands for moving among
those views.  Treat each buffer as a place you can revisit, rather than as a
dialog that must be completed before doing anything else.

*** Search Wherever You Are
:PROPERTIES:
:TEXINFO_NODE: no
:END:

#+cindex: searching

#+cindex: finding

In most text buffers, ~C-s~ searches forward and ~C-r~ backwards. Type the
query, repeat the key for another match, and finish with ~RET~ before typing
an edit. In a failing search, ~C-g~ first backs out of the failed part; a
second cancellation may be needed to leave it. This search works in documents,
Help, source code and many application results. [[*Find and replace text carefully][Find and replace text carefully]]
explains match positions and scoped replacement; [[info:emacs#Incremental Search][Incremental search]] in the
GNU Emacs Manual provides the full search reference.

Also look for the mode's semantic search and filtering commands.  A mail
application can search message fields, Dired can narrow files, and a browser
can move directly among links or headings.  Use the general search when text
is what matters and the mode-specific command when the kind of object matters.
