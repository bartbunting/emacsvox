* Work With The Audio Desktop
:PROPERTIES:
:TEXINFO_NODE_NAME: Audio Desktop
:ALT_TITLE: Audio Desktop
:DESCRIPTION: Work with buffers, modes, structure, and search.
:END:

#+cindex: Audio Desktop

The /audio desktop/ is the Emacsvox working environment.  It is not a
separate program or a spoken copy of a graphical desktop.  Emacs keeps each
document, application, and result in a buffer; its modes understand the kind
of information in that buffer; and Emacsvox presents that context through
speech, voice changes, sounds, and structured navigation.

You can begin without learning a new desktop model.  Open a file or application
normally, use @@texinfo:@kbd{C-e m}@@ to hear the current buffer and mode, and press
@@texinfo:@kbd{C-h m}@@ to discover what that buffer can do.  The rest of this chapter
explains why the same approach works for text, Web pages, mail, shells, source
code, and many other tasks.

** Buffers Hold Your Work
:PROPERTIES:
:TEXINFO_NODE_NAME: Desktop Objects
:ALT_TITLE: Desktop Objects
:DESCRIPTION: Understand and move between Emacs buffers.
:END:

#+cindex: buffers

A buffer is Emacs's working view of one piece of information.  A buffer might
contain a file you are editing, an Info manual, a directory listing, a Web
page, a mail search, a shell session, or a temporary Help result.  Some buffers
are connected to files; many useful application buffers are not.

The mode line identifies the selected buffer and its major mode.  Press
@@texinfo:@kbd{C-e m}@@ whenever you want to hear it.  Common buffer commands include:

#+attr_texinfo: :indic kbd :compact t
- C-x b ::

  Switch to another buffer by name.  Completion lets you narrow the choices
  instead of remembering the complete name.

- C-x C-b ::

  Open a buffer list.  In that list, use @@texinfo:@kbd{C-h m}@@ to learn its navigation,
  selection, saving, and cleanup commands.

- C-x k ::

  Close a buffer that you no longer need.  Emacs asks before discarding
  unsaved file changes.

Moving to another buffer changes the selected work object without closing the
one you left.  This makes it practical to keep a document, its reference
material, a shell, and related application results available together.

*** Cycle Between Buffers of the Same Kind
:PROPERTIES:
:TEXINFO_NODE: no
:END:

#+cindex: buffer cycling
#+kindex: C-e n
#+kindex: C-e p
#+kindex: C-e .
#+kindex: C-e ,

When several buffers contain the same kind of work, cycling lets you move
among them without remembering their names or opening a buffer list.  This is
useful when comparing Org notes, reviewing several directories in Dired, or
moving between source files.

Press @@texinfo:@kbd{C-e n}@@ to select the next buffer with the same major
mode, or @@texinfo:@kbd{C-e p}@@ to select the previous one.  For example, from
an Org buffer these commands visit other Org buffers, skipping all buffers
that do not use the same major mode.  Buffers are grouped by major mode, not
by project or directory.

After the first command, you only need the final letter: @@texinfo:@kbd{n}@@
continues forward and @@texinfo:@kbd{p}@@ moves backward.  You can change
direction at any time, and cycling wraps around when you reach the end.  For
example, @@texinfo:@kbd{C-e n n p}@@ moves forward twice, then returns to the
buffer you just left.

To navigate without the major-mode filter, use @@texinfo:@kbd{C-e .}@@ for
next buffer or @@texinfo:@kbd{C-e ,}@@ for previous buffer.  You can then repeat
with just @@texinfo:@kbd{.}@@ or @@texinfo:@kbd{,}@@, in the same way as
@@texinfo:@kbd{n}@@ and @@texinfo:@kbd{p}@@.  You can also switch between these
controls while cycling.

The temporary buffer-selection controls also include @@texinfo:@kbd{b}@@ to
select a buffer by name, @@texinfo:@kbd{f}@@ to open a file,
@@texinfo:@kbd{k}@@ to kill a buffer, and @@texinfo:@kbd{o}@@ to change windows.

Press @@texinfo:@kbd{C-g}@@ when finished to return to normal editing.  A key
outside the temporary buffer-selection controls also ends cycling and
performs its normal action.  To choose a particular buffer by name, use
@@texinfo:@kbd{C-x b}@@.

** Let Modes Give Each Buffer Its Tools
:PROPERTIES:
:TEXINFO_NODE_NAME: Object Oriented Desktop
:ALT_TITLE: Object Oriented Desktop
:DESCRIPTION: Let major and minor modes interpret each kind of content.
:END:

#+cindex: major modes

#+cindex: minor modes

Every buffer has one major mode that provides its main editing or application
behavior.  A source buffer uses a programming-language mode, Dired uses a mode
for directories, EWW uses one for Web pages, and Org uses one for structured
notes and documents.  Minor modes add optional behavior alongside the major
mode.

This context is what makes Emacs efficient: a movement command can move by a
sentence in prose, a heading in an outline, an item in a list, or another
meaningful unit supplied by the active mode.  Emacsvox speaks the result of the
operation and can use the same context to announce state changes.

You do not need to predict which commands every mode provides.  Press
@@texinfo:@kbd{C-h m}@@ in the buffer you are using, then @@texinfo:@kbd{C-h k}@@ followed by a key
when you want a fuller explanation.  @@texinfo:@xref{Using Online Help}@@ provides a
short practical guide to these discovery commands.

** Hear And Navigate The Current Context
:PROPERTIES:
:TEXINFO_NODE_NAME: Context-Sensitive Interaction
:ALT_TITLE: Context-Sensitive Interaction
:DESCRIPTION: Use aural structure, mode commands, buffers, and search.
:END:

#+cindex: Context-Sensitive Interaction

Emacsvox uses information already exposed by Emacs and the active application.
That produces more useful feedback than reading every visible character in the
same way.  You can hear what an object means, move using its structure, and ask
for detail only when you need it.

*** Hear Structure Without Extra Words
:PROPERTIES:
:TEXINFO_NODE: no
:END:

#+cindex: audio formatting

Voice changes can distinguish headings, comments, strings, links, warnings,
and other meaningful text.  Short sounds and tones can mark events or state
changes without interrupting the spoken content.  Ordinary text remains
available through the usual reading commands.

The exact result depends on the mode, the Emacsvox integration, and your Aural
Presentation settings.  @@texinfo:@xref{Aural Presentation}@@ explains how the
parts fit together, including the established Voice Lock compatibility layer;
@@texinfo:@kbd{C-e E}@@ explains the presentation chosen for the object at point.

*** Move By The Structure Of The Content
:PROPERTIES:
:TEXINFO_NODE: no
:END:

#+cindex: structured navigation

Prefer the navigation supplied by the active mode when it matches your task.
For example, Info moves among nodes and menu entries, Org and Outline move
among headings, Dired moves among files, programming modes understand
definitions and diagnostics, and EWW exposes links and document structure.

Begin with @@texinfo:@kbd{C-h m}@@.  It describes the commands available in the
running buffer, including personal customizations and installed packages.
@@texinfo:@xref{Browsing Structure}@@ points to maintained guides for several common
types of content.

*** Move Between Tasks Without Losing Your Place
:PROPERTIES:
:TEXINFO_NODE: no
:END:

#+cindex: desktop navigation

Buffers keep different tasks available in one Emacs session.  Use
@@texinfo:@kbd{C-x b}@@ to return to a known buffer or @@texinfo:@kbd{C-x C-b}@@ to browse the
current set.  Emacs windows can show more than one buffer at a time; if the
selected window is unclear, @@texinfo:@kbd{C-e C-w}@@ describes the arrangement.

Applications often create several related buffers, such as a search result and
an individual message.  Their mode help explains the commands for moving among
those views.  Treat each buffer as a place you can revisit, rather than as a
dialog that must be completed before doing anything else.

*** Search Wherever You Are
:PROPERTIES:
:TEXINFO_NODE: no
:END:

#+cindex: searching

#+cindex: finding

In most text buffers, @@texinfo:@kbd{C-s}@@ searches forward incrementally and
@@texinfo:@kbd{C-r}@@ searches backward.  Type more text to narrow the match, repeat the
search key to move to another match, and press @@texinfo:@kbd{C-g}@@ to cancel.  This same
basic search is available in documents, Help, source code, and many application
results.

Also look for the mode's semantic search and filtering commands.  A mail
application can search message fields, Dired can narrow files, and a browser
can move directly among links or headings.  Use the general search when text
is what matters and the mode-specific command when the kind of object matters.
