You can read the early chapters in sequence or use this manual to answer a
question while working. [[*Find a task][Find a task]] links everyday goals to their detailed
instructions. [[*Terms used in this manual][Terms used in this manual]] explains names such as palette,
profile, scope, and draft without requiring you to study the whole settings
system first.

Key notation follows Emacs conventions: ~C-~ means Control, ~M-~ means Meta
(usually Alt or Option), and ~RET~ means Return or Enter. In ~C-e H~, press
Control-e, release it, then type capital H. In a longer sequence, enter each
following key separately. Uppercase and lowercase keys are different.

** Choose a reading route
:PROPERTIES:
:TEXINFO_NODE: no
:END:

If Emacs is new to you, follow [[info:emacsvox#Installation][Installation]] to obtain speech, then
work through Emacs's tutorial with ~C-h t~. Return to [[info:emacsvox#Basic Usage][Basic Usage]] for
speech commands. [[info:emacsvox#Using Online Help][Using Online Help]] and [[info:emacsvox#Audio Desktop][Audio Desktop]] explain how to find
commands and move among tasks. You need not configure voices or additional
engines before learning to read and edit.

If you already use Emacs, start with [[info:emacsvox#Basic Usage][Basic Usage]] once speech works.
Keep your usual editing and mode commands. Then read
[[info:emacsvox#Aural Presentation][Aural Presentation]] for the relationship between application meaning,
voices, sounds, and settings, and choose an application guide for your work.

For one question, go directly to [[*Find a task][Find a task]], use Info's index, or search
the manual text. [[info:emacsvox#Speech Backends][Speech Backends]] contains alternative installation and backend
configuration procedures; it is not required reading between your first
speaking session and everyday editing. The final Developer Guide is for
changing and maintaining Emacsvox, not for ordinary use.

** Find an answer in Info and return
:PROPERTIES:
:TEXINFO_NODE: no
:END:

Info is Emacs's manual reader. A /node/ is one navigable topic, which can have
its own menu of subtopics. These instructions apply to the Info buffer, not
to Emacsvox's settings menus.

Try this lookup without changing your configuration:

1. From a working buffer, press ~C-h i~ to open Info, ~d~ for its directory,
   then ~m~. Enter =Emacsvox= and press ~RET~ to open this manual.
2. Press ~i~, enter =ordinary reading voice=, and press ~RET~. The index
   takes you to the voice-task links. Read with your ordinary speech commands.
3. Use ~TAB~ to reach /Change my ordinary reading voice/ and press ~RET~.
   You are now at the named-voice instructions. Reading them changes nothing;
   leave the editing commands for when you deliberately want to make a change.
4. Press lowercase ~l~ to return to the task links. Another ~l~ returns to
   the topic you were reading before the index lookup. This follows your
   visiting history rather than the chapter order.
5. Press ~q~ to leave Info. From an Aural interface's contextual manual link,
   ~q~ returns to that interface. If you opened other windows or switched
   buffers during the exercise, ~C-x b~ also lets you select your original
   working buffer by name.

If the directory has no Emacsvox entry, the manual is not yet discoverable by
that Emacs session; follow [[info:emacsvox#Installation][Installation]] rather than guessing a file path.
In an Aural editor, ~C-c C-i~ opens its relevant manual topic, and ~i~ in
that editor's Help opens the same topic.

The following Info commands are useful during later lookups:

#+attr_texinfo: :indic kbd :compact t
- i :: Look up a subject in the manual's indexes. Use ordinary words, a
  command name, or a key sequence. ~,~ visits further matching entries.
- s :: Search the manual text, including other nodes. Enter the words and
  press ~RET~; ~s RET~ continues the same search.
- TAB, S-TAB :: Move among links. ~RET~ follows the selected link.
- m :: Choose a subtopic from the current node's menu by name, with completion.
- u :: Go to the containing topic. This is different from ~l~, which goes
  back to the topic you last visited.
- g :: Go to a node by its identifier. For example, enter =Finding Tasks=
  to return directly to the task finder.

For the full reader tutorial and search behaviour, see the [[info:info#Top][Info manual]].
If a key behaves differently in your session, ~C-h k~ followed by that key
explains its effective binding without invoking it.

** Recognise the document you are reading
:PROPERTIES:
:TEXINFO_NODE: no
:END:

This user manual explains tasks, feedback, and recovery. The generated
/Emacsvox Reference Manual/ lists commands, options, and keymaps from source.
The heritage manual preserves historical Emacspeak material; it is not a
current setup guide. A linked application's own manual remains authoritative
for that application's general operations.

Some stable Info identifiers predate their displayed headings. For example,
=Aural Home= now identifies /Getting started with settings menus/. This keeps
old links and bookmarks valid; it does not make the retired Home menu entry
part of the learning route.

In HTML, use the contents, headings, and task links, then your browser's Back
command to return from a link. The Info keys above are not browser commands.
The published website and the manual installed with your checkout can describe
different revisions; use documentation matching the Emacsvox you are running
and live Help to check its commands.
