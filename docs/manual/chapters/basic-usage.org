* Basic Usage
:PROPERTIES:
:TEXINFO_NODE_NAME: Basic Usage
:ALT_TITLE: Basic Usage
:DESCRIPTION: Learn the essentials in a speaking Emacsvox session.
:END:

Once Emacsvox is speaking, you can read, edit, and navigate with ordinary
Emacs commands. Emacsvox announces their results, while explicit speech
commands let you examine text without moving. Start with the short practice
session below, then use the rest of this chapter for everyday speech controls.
[[*Work With The Audio Desktop][Audio Desktop]] explains how these habits carry over to other Emacs applications.

** Key Notation And Emacs Words
:PROPERTIES:
:TEXINFO_NODE: no
:END:

Emacs documentation uses ~C-~ for Control and ~M-~ for Meta, usually the
Alt or Option key. To enter ~C-n~, hold Control and press ~n~. For
~C-e l~, press ~C-e~, release the keys, then press ~l~. Each
part of a sequence is a separate keystroke.

~M-x~ lets you run a command by name, and ~RET~ means Return or Enter. A
/buffer/ holds text or an application view; /point/ is the position affected
by movement and editing. These terms are used throughout the manual.

If you are new to Emacs, ~C-h t~ opens its interactive tutorial. You can
follow it with Emacsvox and return here to learn the speech commands.

** Your First Few Minutes
:PROPERTIES:
:TEXINFO_NODE: no
:END:

Try these commands in the speaking session started during installation:

1. Press ~C-n~ to move down one line and ~C-p~ to move back up. Emacsvox
   speaks the line you reach.

1. Press ~C-e l~ to hear the current line without moving point.

1. Press ~C-e s~ to stop speech immediately. Later commands still speak.

1. Press ~C-h k~, followed by any key, to find out what it does.

1. Press ~C-h m~ to discover the modes and commands available in the
   current buffer.

1. Press ~C-h C-e~ to open the Emacsvox overview.

These commands let you explore without memorising a long key list. The keys
in this manual are defaults: use ~C-h k~ if a key behaves differently in
your session. The generated
[[info:emacsvox-reference#Emacsvox Keymaps][Emacsvox Keymaps]] in the /Emacsvox Reference Manual/ lists all default
bindings; live help reflects your installed packages and customisations.

** Emacsvox Overview
:PROPERTIES:
:TEXINFO_NODE_NAME: Overview
:ALT_TITLE: How Emacsvox Helps
:DESCRIPTION: Understand the main kinds of Emacsvox feedback.
:END:

Emacsvox speaks text as you move through it and announces useful results of
commands. Applications can also present information in meaningful units:
messages, search results, tables, source code, and Web pages each have their
own structure.

Not all feedback has to be spoken as words. Voice changes can distinguish
headings, links, comments, and other kinds of text; auditory icons and tones
can mark events or state changes. Pronunciation dictionaries can correct
names and technical terms globally or for a particular mode or file. Notice
these distinctions during normal reading before changing their settings.

You can compare structural voices in [[*Hear Structure With Voice Lock][Hear Structure With Voice Lock]]. For a fuller
explanation of speech, sounds, and pronunciation choices, see
[[*Aural Presentation: Speech, Voices, And Sound][Aural Presentation]].

** Using Emacs Buffers
:PROPERTIES:
:TEXINFO_NODE_NAME: Working
:ALT_TITLE: Using Emacs Buffers
:DESCRIPTION: Understand feedback while editing and completing text.
:END:

Much of the feedback you need while editing happens automatically. Depending
on your echo settings, Emacsvox can speak individual characters as you type
or a word when you finish it. Completion announces candidates, the inserted
completion, and the currently selected item. Prompts and error messages are
also spoken.

Other information is available on request. The everyday commands fall into
three useful groups:

- Reading commands speak a character, word, line, region, or larger part of a
  buffer without requiring you to move. Their names usually begin with
  =emacsvox-speak-= and their default keys use ~C-e~.[fn::The prefix is
  inherited from Emacspeak, where C-e was mnemonic for the project name.]

- Speech-system commands adjust settings such as rate, punctuation, and echo.
  Their names usually begin with =tts-= and many use ~C-e d~.[fn::The
  letter d originally referred to DECtalk; the prefix now contains
  engine-independent controls.]

- Help commands explain the active modes, available keys, and integrations
  in the buffer where you are working.

Buffers remain available as you move between tasks. For example, ~C-e n~
and ~C-e p~ cycle among buffers with the same major mode; repeat with
~n~ or ~p~. [[*Buffers Hold Your Work][Audio Desktop]] explains buffer selection and the other
navigation controls in context.

Many speaking commands accept a prefix argument to limit speech to the
text before or after point.  Use ~C-h k~ on a command before relying
on those variants, because their exact argument behavior is documented
with the command.

*** Hear Phonetic Names After A Pause
:PROPERTIES:
:TEXINFO_NODE: no
:END:

#+findex: emacsvox-delayed-phonetic-mode
#+vindex: emacsvox-delayed-phonetic-delay

Use ~M-x emacsvox-delayed-phonetic-mode~ to toggle delayed
phonetic descriptions. When enabled, moving by character speaks the letter
normally; pausing then speaks its phonetic name, such as "alpha" for "a".
These are the same English letter names used by ~C-e c~.

The mode starts enabled. Customize =emacsvox-delayed-phonetic-delay= to change
the default one-second delay to another positive number of seconds. You can
save the mode's enabled or disabled setting through Customize as well.

Further input, including the first key of a prefix sequence, cancels the pending
description. New speech, stopping speech, changing the source text or leaving
its buffer or window also prevents a stale description. Each pause produces at
most one description. Typing, deletion, punctuation and explicit phonetic
reading do not trigger delayed descriptions.

** Adjust Speech While You Work

:END:

Speech settings let you choose how much feedback to hear while you work.
Typing echo, rate, punctuation, and other controls can be adjusted
independently. Most commands in this section affect the current buffer; when a
command also has a global prefix form, its help explains the difference.
Use ~C-h k~ before applying a prefix argument to an unfamiliar setting.

*** Choose Typing Echo
:PROPERTIES:
:TEXINFO_NODE_NAME: Controlling Echo
:ALT_TITLE: Choose Typing Echo
:DESCRIPTION: Choose character, word, and line feedback while typing.
:END:

#+cindex: line echo

#+cindex: character echo

Character echo speaks each character you type.  Word echo speaks a word when
you finish it, and optional line echo speaks a completed line.  Toggle each
kind independently to suit the buffer: character feedback may help in a
form where accuracy matters, while word echo is often more fluent for prose.

The commands below affect the current buffer.  Press ~C-u~ first to
change the corresponding default and apply it to the current buffer.

*** Adjust Rate And Spoken Detail
:PROPERTIES:
:TEXINFO_NODE_NAME: Speech Output Control
:ALT_TITLE: Adjust Rate And Spoken Detail
:DESCRIPTION: Adjust rate and how textual detail is presented.
:END:

Use these controls to match speech to the current material.  A faster rate may
suit familiar prose; full punctuation can help when inspecting code or exact
text.  Start with rate and punctuation, then change capitalization or
indentation feedback only when the distinction would help your current task.

The commands affect the current buffer unless their interactive help describes
a global prefix form.  Use ~C-h k~ on a key before changing the global
default.

#+attr_texinfo: :indic kbd :compact t
- C-e d r ::

  Enter a speech rate for the current buffer with =tts-set-rate=.
- C-e d DIGIT ::

  Choose one of ten predefined rates with ~0~ through ~9~.
- C-e d p ::

  Choose =some=, =all=, or =none= punctuation with =tts-set-punctuations=.
- C-e d s ::

  Toggle splitting of mixed-capital identifiers into separate words.
- C-e d c / C-e d C ::

  Toggle capitalization indication with the lowercase key.  Use the uppercase
  key to preview and choose whether capitals use speech, a tone, both, a custom
  rule, or no added indication.
- C-e d i / C-e d I ::

  Toggle indentation feedback with the lowercase key. The uppercase key
  opens the Indentation menu, described after this command list.
- C-e d T ::

  Choose and preview whether indentation tones play /Alongside speech/ (the
  default) or /Before speech/.  This changes the current buffer; use a prefix
  argument to also change the default for other buffers.  To save your choice
  across sessions, customize ~emacsvox-indentation-tone-timing~.  Timing does
  not change your spoken-column or tonal presentation choice, or enable
  indentation feedback.  Backends without overlay support play tones before
  speech for either setting.

**** Use The Indentation Menu
:PROPERTIES:
:TEXINFO_NODE: no
:END:

The Indentation menu controls how columns, tones, and speech represent
indentation. It also provides scope, volume, preview, and saving controls.

Toggle indentation feedback with the lowercase key.  The uppercase key opens
the Indentation menu. Choose spoken columns with ~s~, pitch tones with ~p~,
or duration tones with ~d~. Capital ~P~ and ~D~ combine speech and tones.
Choose ~b~ for tones before speech or ~a~ for tones alongside speech.
Timing choices are unavailable for presentations without built-in tones.

Press ~g~ to switch between /Current buffer/ and /Global defaults/. Global
defaults affect buffers without their own choices; existing local settings
stay in place. A prefix argument opens the menu in Global defaults scope.
Press ~e~ to toggle indentation feedback in the selected scope.

Up/down selects a control, and left/right moves between sections. On the
/Volume/ control, Shift-left/right lowers or raises the value in steps of
five, bounded from 0 to 100. On other items, shifted arrows give brief
guidance; ~RET~ activates the selected item. These shifted-arrow bindings
apply only while navigating the Indentation menu. Input prompts and the
source buffer retain their normal bindings.

Press ~v~ or activate /Volume/ to enter a number directly. The ~-~ and ~+~
shortcuts also remain available. Volume always affects all main-stream Omnivox tones,
even while editing current-buffer settings. Each adjustment speaks just
the percentage and interrupts previous main-stream speech, so repeated
presses announce the latest value without queuing older values.

Changes take effect immediately. ~SPC~ previews four-column indentation
with the settings shown, even when feedback is off. ~q~ closes the menu
and keeps your changes. In Global defaults scope, ~S~ saves indentation
defaults and tone volume across sessions. Closing without saving leaves
the defaults changed only for this session.

You can still choose a presentation directly with
~M-x emacsvox-set-indentation-presentation~.

Character-rate scaling, text chunking, engine-specific controls, and reusable
presentation profiles are intentionally outside this starter chapter.  Use
live help for the current speech keymap and see [[*Aural Presentation: Speech, Voices, And Sound][Aural Presentation]] when
you want a complete presentation setup rather than a temporary buffer change.

**** Edit Punctuation Pronunciations
:PROPERTIES:
:TEXINFO_NODE: no
:END:

The punctuation level controls how much punctuation is spoken. To change how
individual characters are pronounced, use the punctuation editor on a
supporting local Omnivox host. Run ~M-x omnivox-punctuation~ or choose
/Punctuation/ under /Voices and speech/ in Aural Home. This editor shows saved host settings and an unsaved draft;
running speech may still use an earlier configuration. It requires the updated
bundled local launcher and Omnivox's punctuation-editor capability. Older hosts
report that an update is needed. Remote and native-direct configuration editing
are not provided by this interface.

Each row names its Unicode character explicitly and shows the pronunciation and
whether it comes from a default or an override. The initial level is /some/.

#+attr_texinfo: :indic kbd :compact t
- l :: Choose /none/, /some/, or /all/. Each level has independent overrides.
- RET :: Speak a name, preserve the character, or restore its shipped default.
- a :: Add a character that is absent from the table.
- d :: Restore the selected character's default in this level.
- s :: Save edits for all three levels on the speech host. Saving does not
  restart speech or change another setting in the configuration file.
- r :: After confirmation, restart this session's main and notification speech
  workers with the saved settings. Save or discard drafts first.
- g :: Read the saved file again, asking before discarding edits.
- q :: Return to the previous view, retaining the draft. Reopen /Punctuation/
  or choose /Resume unfinished changes/ in Aural Home to continue.
- ? :: Read help, including the selected host configuration path.

/Preserve character/ leaves punctuation for the engine's pronunciation and
pauses; it does not promise silence. Org normally selects /some/. To name
apostrophes in Org prose, set both /APOSTROPHE/, U+0027, and
/RIGHT SINGLE QUOTATION MARK/, U+2019, to speak “apostrophe” in /some/.
This also names apostrophes inside contractions. Omnivox 1.15.0 names straight,
curly and modifier apostrophes at /all/ by default, without a configuration file.

***** Save And Activate Changes
:PROPERTIES:
:TEXINFO_NODE: no
:END:

A save rejects changes if the file or selected target differs from the version
you reviewed. Your draft is retained so you can review the conflict. Saving
preserves other settings. With a host supporting named profiles, saving uses
Omnivox configuration version 4; Omnivox 1.16.0 and earlier cannot read that
version. The older built-in-only editor service uses version 3, which requires
Omnivox 1.15.0 or newer. Do not save a file shared with an executable that cannot
read its format. Named profiles are currently unreleased.

***** Work With Named Profiles
:PROPERTIES:
:TEXINFO_NODE: no
:END:

Named profiles are available with the updated Omnivox host. In the punctuation
editor, ~N~ creates a profile inheriting =none=, =some= or =all=. Use a lowercase
ID such as =prose= or =proofreading=. Edit characters as usual; ~l~ switches
between levels and profiles, and ~X~ removes the selected profile from the draft.
Profiles inherit edits to their base level and can override individual characters.
~s~ saves all drafts together without changing running speech. Restart explicitly
with ~r~ to load the same saved definitions in both workers.

~M-x tts-set-punctuations~ offers profiles whose definitions agree in the current
speech workers. An explicit selection applies to the buffer. A mode preference
in ~tts-punctuation-mode-policy-alist~ can use =(text-mode profile "prose" some)=;
it retains =some= as the fallback for an older server, a missing profile, or
workers reporting different definitions. The punctuation status describes when
that fallback is in use. ~tts-reset-punctuation-mode~ restores the mode policy.
Choosing a built-in level explicitly overrides a profile. Character inspection
remains independent, and there is no new built-in =most= level.

*** Stop Or Restart Speech
:PROPERTIES:
:TEXINFO_NODE_NAME: Miscellaneous
:ALT_TITLE: Stop Or Restart Speech
:DESCRIPTION: Stop, silence, restart, or identify the speech server.
:END:

Stopping speech ends the current output without disabling future feedback.
Quiet mode is useful when you temporarily want to keep working without speech.
Restart the server after correcting a backend problem or changing the selected
synthesizer.

#+attr_texinfo: :indic kbd :compact t
- C-e s ::

  Stop speech now with =tts-stop=.
- C-e d q ::

  Toggle quiet mode in the current buffer.  Press ~C-u~ first to toggle
  it globally.
- C-e C-s ::

  Stop and restart the selected speech server.
- C-e d V ::

  Speak the selected adapter and its version information.

Use ~C-h m~ or the generated keymap reference for server selection,
repeated-pattern cleanup, text splitting, language selection, and direct engine
controls.  Those specialist settings are intentionally outside this starter
guide.

** Hear Structure With Voice Lock
:PROPERTIES:
:TEXINFO_NODE_NAME: Voice-lock
:ALT_TITLE: Hear Structure With Voice Lock
:DESCRIPTION: Hear document and program structure through voice changes.
:END:

Voice Lock is enabled automatically in supported buffers.  It maps faces and
other structural text properties to speech personalities, allowing comments,
strings, headings, links, and other elements to sound distinct without adding
words to the document.

Try it in source code, Org, Info, or EWW.  Move between two differently styled
elements, such as a comment and a string or a heading and a link.  Press
~C-e d v~ to turn Voice Lock off in that buffer, compare the same text,
then press the key again to restore it.

Use ~C-e d C-v~ when you want to change Voice Lock globally.  Turning it
off removes this layer of voice changes; it does not silence ordinary speech,
semantic feedback, tones, or auditory icons.

The exact personalities depend on the speech engine and active presentation
settings.  For an explanation of the separate Voice Lock, face-presentation,
and semantic-presentation layers, see [[*Voice Lock And Advanced Configuration][Voice Lock]].  Use
[[*Aural Presentation: Speech, Voices, And Sound][Aural Presentation]] when you want to choose voices, sounds, profiles, or
other reusable presentation behavior.
