* Basic Usage
:PROPERTIES:
:TEXINFO_NODE_NAME: Basic Usage
:ALT_TITLE: Basic Usage
:DESCRIPTION: Learn the essentials in a speaking Emacsvox session.
:END:

Now that Emacsvox is speaking, this chapter helps you become comfortable with
the essential keys and feedback.  It begins with a short guided session, then
introduces the reading and speech controls you are most likely to need.

** Key Notation And Emacs Words
:PROPERTIES:
:TEXINFO_NODE: no
:END:

Emacs documentation writes @@texinfo:@kbd{C-}@@ for the Control key and @@texinfo:@kbd{M-}@@ for the
Meta key, which is usually Alt or Option.  For example, @@texinfo:@kbd{C-n}@@ means
hold Control and press @@texinfo:@kbd{n}@@.  A sequence such as @@texinfo:@kbd{C-e l}@@ means press
@@texinfo:@kbd{C-e}@@, release it, and then press @@texinfo:@kbd{l}@@.

@@texinfo:@kbd{M-x}@@ prompts for an Emacs command by name, and @@texinfo:@key{RET}@@ means the
Return or Enter key.  A /buffer/ is the Emacs workspace containing text or an
application.  /Point/ is the current editing position—the place affected by
movement and editing commands.

If Emacs itself is new to you, @@texinfo:@kbd{C-h t}@@ opens its interactive tutorial.
You can return to this chapter whenever the tutorial refers to buffers, point,
windows, or key sequences.

** Your First Few Minutes
:PROPERTIES:
:TEXINFO_NODE: no
:END:

Try these actions in the clean session started during installation:

1. Press @@texinfo:@kbd{C-n}@@ and @@texinfo:@kbd{C-p}@@ to move down and up by one line.  Emacsvox
   speaks the line you reach.

1. Press @@texinfo:@kbd{C-e l}@@ to hear the current line without moving.

1. Press @@texinfo:@kbd{C-e s}@@ whenever you want to stop speech immediately.

1. Press @@texinfo:@kbd{C-h k}@@ followed by any key to hear what that key does.

1. Press @@texinfo:@kbd{C-h m}@@ to hear about the modes and commands available in the
   current buffer.

1. Press @@texinfo:@kbd{C-h C-e}@@ to open the Emacsvox overview.

These commands are enough to begin exploring safely.  The rest of this chapter
adds reading controls and speech settings as you need them.  The generated
@@texinfo:@ref{Emacsvox Keymaps,,,emacsvox-reference,Emacsvox Reference Manual}@@ records the complete default keymaps, while live
help remains authoritative when a package or personal configuration changes a
binding.

** Emacsvox Overview
:PROPERTIES:
:TEXINFO_NODE_NAME: Overview
:ALT_TITLE: Overview
:DESCRIPTION: Understand the main kinds of Emacsvox feedback.
:END:

Emacsvox adds spoken feedback to Emacs editing and to applications that run
inside Emacs.  Movement speaks the corresponding character, word, line, or
larger unit.  Commands announce useful results and state changes, while
application integrations present structures such as messages, search results,
tables, source code, and Web pages.

Voice Lock uses changes in speech characteristics to make text structure
audible.  For example, comments, quoted strings, reserved words, headings, and
links can sound different without an explanation being inserted into the text.
See @@texinfo:@ref{Voice Lock}@@ for configuration and @@texinfo:@ref{Web Browsing}@@ for a
task-oriented example in EWW.

Pronunciation dictionaries let you adjust how a name, technical term, or
programming-language word is spoken.  A dictionary can apply everywhere or
only in a particular mode or file; see
@@texinfo:@ref{emacsvox-pronounce,,,emacsvox-reference,Emacsvox Reference Manual}@@.

Short auditory icons and tones mark events such as opening or deleting a file,
finishing an action, receiving mail, or displaying completions.  They
supplement speech and become especially useful as familiar events no longer
need a full spoken explanation.  See
@@texinfo:@ref{emacsvox-sounds,,,emacsvox-reference,Emacsvox Reference Manual}@@ for the available sound support.

** Using Emacs Buffers
:PROPERTIES:
:TEXINFO_NODE_NAME: Working
:ALT_TITLE: Working
:DESCRIPTION: Understand feedback while editing and completing text.
:END:

As you type, character echo can speak individual characters and word echo can
speak a word when you finish it.  Completion interfaces announce candidates,
the inserted completion, and the item currently selected.  Prompts and error
messages are spoken through the same Emacs feedback that appears on screen.

Most everyday feedback happens automatically.  Emacsvox also provides three
useful groups of explicit commands:

- Reading commands speak a character, word, line, region, or larger portion of
  a buffer without requiring you to move first.  Their names usually begin
  with ~emacsvox-speak-~, and their default keys use the main @@texinfo:@kbd{C-e}@@
  prefix.[fn::The prefix is inherited from Emacspeak, where C-e was mnemonic
  for the project name.]

- Speech-system commands change settings such as rate, punctuation, and echo.
  Their names usually begin with ~tts-~, and many are grouped under
  @@texinfo:@kbd{C-e d}@@.[fn::Historically, d was mnemonic for DECtalk; the prefix now
  contains engine-independent speech controls.]

- Help commands describe the active modes, available keys, and Emacsvox
  integrations in the buffer where you are working.

The following sections introduce a practical starter set.  Use live Help or
the generated reference when you need the complete commands for a particular
application.

** Reading And Navigating
:PROPERTIES:
:TEXINFO_NODE_NAME: Reading
:ALT_TITLE: Reading
:DESCRIPTION: Reading chunks of information.
:END:

Ordinary Emacs movement speaks the text crossed by point: moving by a
character, word, line, or paragraph presents the corresponding unit.
The commands below let you inspect useful units without first moving.
They use the default @@texinfo:@kbd{C-e}@@ prefix.

This is deliberately a starter set, not a second complete key reference.
If a binding below differs in your session, use @@texinfo:@kbd{C-h k}@@ on that key
and check your customizations.  The complete generated defaults are in the
@@texinfo:@ref{Emacsvox Keymaps,,,emacsvox-reference,Emacsvox Reference Manual}@@.

with the command.

*** Choose What Is Echoed While Typing
:PROPERTIES:
:TEXINFO_NODE_NAME: Controlling Echo
:ALT_TITLE: Controlling Echo
:DESCRIPTION: Choose character, word, and line feedback while typing.
:END:

#+cindex: line echo

#+cindex: character echo

#+cindex: word echo

Character echo speaks each character you type.  Word echo speaks a word when
you finish it, and optional line echo speaks a completed line.  Toggle each
kind independently to suit the buffer: character feedback may help in a
form where accuracy matters, while word echo is often more fluent for prose.

The commands below affect the current buffer.  Press @@texinfo:@kbd{C-u}@@ first to
change the corresponding default and apply it to the current buffer.

- C-e d k ::

  #+findex: emacsvox-toggle-character-echo

  #+kindex: C-e d k

  ~emacsvox-toggle-character-echo~

  Toggle character echo.
- C-e d w ::

  #+findex: emacsvox-toggle-word-echo

  #+kindex: C-e d w

  ~emacsvox-toggle-word-echo~

  Toggle word echo.
- C-e d l ::

  #+findex: emacsvox-toggle-line-echo

  #+kindex: C-e d l

:PROPERTIES:
:TEXINFO_NODE_NAME: Speech Output Control
:ALT_TITLE: Speech Output Control
:DESCRIPTION: Adjust rate and how textual detail is presented.

Use these controls to match speech to the current material.  A faster rate may
suit familiar prose; full punctuation can help when inspecting code or exact
text.  Capitalization and indentation each have an on/off control and a
separate choice of spoken or tonal presentation.

The commands affect the current buffer unless their interactive help describes
a global prefix form.  Use @@texinfo:@kbd{C-h k}@@ on a key before changing the global
default.

- C-e d p ::

*** Stop, Silence, Restart, Or Identify Speech
:PROPERTIES:
:TEXINFO_NODE_NAME: Miscellaneous
:ALT_TITLE: Miscellaneous
:DESCRIPTION: Stop, silence, restart, or identify the speech server.
:END:

Stopping speech ends the current output without disabling future feedback.
Quiet mode is useful when you temporarily want to keep working without speech.
Restart the server after correcting a backend problem or changing the selected
synthesizer.

#+attr_texinfo: :indic kbd :compact t
- C-e s ::

  #+findex: tts-stop

  #+kindex: C-e s

  ~tts-stop~

  Stop speech now.
- C-e d q ::

  #+findex: tts-toggle-quiet

  #+kindex: C-e d q

  ~tts-toggle-quiet~

  Toggle speech in the current buffer.  Press @@texinfo:@kbd{C-u}@@ first to toggle it
  globally.
- C-e C-s ::

  #+findex: tts-restart

  #+kindex: C-e C-s

  ~tts-restart~

  Stop and restart the selected speech server.

To hear which speech adapter is running, use:

#+attr_texinfo: :indic kbd :compact t
- C-e d V ::

  #+findex: tts-speak-version

  #+kindex: C-e d V

  ~tts-speak-version~

  Speak the selected adapter and its version information.

Use @@texinfo:@kbd{C-h m}@@ or the generated keymap reference for server selection,
repeated-pattern cleanup, text splitting, language selection, and direct engine
controls.  Those specialist settings are intentionally outside this starter
guide.

** Voice Lock Mode
:PROPERTIES:
:TEXINFO_NODE_NAME: Voice-lock
:ALT_TITLE: Voice-lock
:DESCRIPTION: Hear document and program structure through voice changes.
:END:

Voice Lock is enabled automatically in supported buffers.  It maps faces and
other structural text properties to speech personalities, allowing comments,
strings, headings, links, and other elements to sound distinct without adding
words to the document.

The exact personalities depend on the selected speech engine and your Aural
Presentation settings.  Try Voice Lock in source code, Org, Info, or EWW to
hear the active mode's structure.

To disable Voice Lock globally, run @@texinfo:@kbd{M-x global-voice-lock-mode}@@ or
add this form to your Emacs init file:

#+begin_src emacs-lisp
(global-voice-lock-mode -1)
#+end_src

The current binding and command reference are in
@@texinfo:@ref{Emacsvox Keymaps,,,emacsvox-reference,Emacsvox Reference Manual}@@.  For detailed configuration, see @@texinfo:@ref{Voice Lock}@@.  For historical
context on Aural CSS, see
@@texinfo:@ref{Audio Formatting And Aural CSS,,,emacsvox-heritage,Emacspeak Heritage}@@.
