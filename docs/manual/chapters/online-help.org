* Find Help While You Work
:PROPERTIES:
:TEXINFO_NODE_NAME: Using Online Help
:ALT_TITLE: Using Online Help
:DESCRIPTION: Discover commands and solve problems with live Emacs help.
:END:

#+cindex: Online Help

Emacs can explain the key you are about to use, the modes active in a buffer,
and the commands and settings available in your session. This live help
reflects installed packages and personal customisations. Use it to understand
an unfamiliar command or resolve a difference between a manual and your
running Emacs.

Most Emacs help commands begin with ~C-h~. Press ~C-h C-h~ for
=help-for-help= when you need to discover what can follow that prefix.
Settings menus also have their own contextual Help, described below.

** Ask About A Key, Command, Or Setting
:PROPERTIES:
:TEXINFO_NODE: no
:END:

Choose a help command according to what you already know:

- ~C-h k~ followed by a key runs =describe-key= and explains the command
  currently bound to that key.
- ~C-h f~ runs =describe-function=. Enter a command or function name to
  read its documentation.
- ~C-h v~ runs =describe-variable=. Enter an option name to inspect its
  current value and documentation.
- ~C-h w~ runs =where-is= and reports the keys that invoke a command.

For example, ~C-h k C-e l~ explains the current-line speaking key without
running that command. If you know its command name but not its key, use
~C-h w~ and enter the name instead.

** Discover What The Current Buffer Can Do
:PROPERTIES:
:TEXINFO_NODE: no
:END:

Start with ~C-h m~ after opening Dired, EWW, mail, a terminal, or another
application. This runs =describe-mode= and explains the major mode, active
minor modes, and their local commands. Use ~C-h b~ (=describe-bindings=)
when you need the effective key bindings after package maps and personal
customisations have been applied.

For Emacsvox settings that apply to the current task, press ~C-e S~. It opens
the integration's focused menu when one is available, otherwise general buffer
settings. ~C-e H .~ always opens general buffer settings. The menu captures
the buffer on entry, so its controls continue to refer to that task while you
navigate its menus and editors.

*** Find a setting and read its menu Help
:PROPERTIES:
:TEXINFO_NODE: no
:END:

Press ~C-e H /~ to find a setting by part of its name. The search is
case-insensitive and includes supported aliases. For example, =cap= finds
capitalisation controls. Completion lets you choose a result; accepting it
opens the appropriate menu and selects the control without changing its
value. Press ~RET~ again to activate or edit it. Cancelling completion
leaves the originating menu open.

The main menu groups its entries in this order: /Everyday settings/,
/This buffer and item/, /Rules and saved work/, /Find and get help/, and
/Finish/. Use left/right to reach a group, then up/down to select an item.
The same arrows navigate sections and items in the submenus.
Press ~C-e H n~ to choose navigation and announcement preferences; the
same controls remain available through ~C-e H s n~.
~RET~, ~M-RET~, or ~C-j~ activates the selected item; its displayed shortcut
also works directly. Press ~?~ followed by an item's key to hear its effect
and scope, or ~? ?~ for the menu overview. ~q~ in that Help returns to the
menu with the selection retained.

Within the menu itself, ~q~ or ~C-g~ goes back one level, while ~C-q~ closes
the sequence. Returning from an Emacsvox submenu selects the entry that opened
it, including when you used its shortcut. The return announcement identifies
that item; ~RET~ opens it again. These navigation commands do not undo changes
already applied.
A linked editor keeps its own preview, saving, and discard rules. See
[[info:emacsvox#Saving And Startup][Choose What Persists]] before treating a saved default, a live adjustment,
or a retained draft as the same thing.

Use ~C-e H a~ to find an action such as browsing voices, inspecting
diagnostics, or reading the manual. It uses the same partial-name matching and
two-Enter selection as settings search. Alternative names lead to one displayed
result for each action: for example, =Feedback for this item= finds
/Explain this item/, and =Recent aural feedback= finds /Recent feedback/.
Editors opened from these menus retain their own Help,
preview, save, and return commands.

** Read And Leave A Help Window
:PROPERTIES:
:TEXINFO_NODE: no
:END:

Ordinary Emacs Help usually appears in a separate =*Help*= window. Emacsvox
speaks the most relevant initial result automatically. Press ~C-e h~
(=emacsvox-speak-help=) to hear the displayed help again.

To explore the text directly, press ~C-x o~ to select its window and use
ordinary reading and navigation commands. Press ~q~ in the Help buffer when
finished. If the selected window is unclear, ~C-e C-w~ describes the window
arrangement. Help opened by an Emacsvox settings menu uses the menu-return
behaviour described above instead of requiring you to find the source window.

** Learn Interactively And Read Manuals
:PROPERTIES:
:TEXINFO_NODE: no
:END:

~C-h t~ opens the interactive Emacs tutorial. Emacsvox speaks its text and
your navigation as you work through it. For a separate key-learning exercise,
~C-h C-l~ runs =emacsvox-learn-emacs=: it speaks the function of each key
you press. Leave that loop with ~C-g~.

Press ~C-e H i~ to read the offline Emacsvox manual from the settings menu.
It opens at the top in Info, plays the opening cue, and reads the first screen
or the whole node according to your Info speech setting. Info's navigation and
index lookup remain available.
Press ~q~ to return to the menu with /Read the manual/ selected and the same
source buffer and settings scope. ~C-e C-i~ opens the manual directly.

~C-h i~ opens Info's general manual reader. Press ~d~ for the Info directory,
then ~m~ and enter =Emacsvox= to choose this manual.
[[*Using this manual][Using this manual]] provides an exercise in index lookup, following a link,
and returning to your work. [[*Find a task][Find a task]] starts from an everyday goal, and
[[*Terms used in this manual][Terms used in this manual]] explains the names used in the procedures. The
[[info:info#Top][Info manual]] covers the reader's complete navigation and search commands.

In an Aural interface, ~C-c C-i~ opens the relevant manual topic and ~q~ in
Info returns to that interface. In the interface's own Help, ~i~ opens the
same topic.

** Emacsvox-Specific Help
:PROPERTIES:
:TEXINFO_NODE: no
:END:

Use ~C-h C-e~ (=emacsvox-describe-emacsvox=) for the Emacsvox overview.
~C-e N~ (=emacsvox-view-emacsvox-news=) opens project news, and ~C-e T~
(=emacsvox-view-emacsvox-tips=) opens productivity tips.

For unexpected feedback, leave point on the item and press ~C-e E~ to
explain its voices, sounds, and other presentation actions. ~C-e H x~ opens
Feedback Details through the settings menu. Its report distinguishes retained
output from a simulation; see [[info:emacsvox#Explaining Presentation][Understand Why Something Sounded That Way]].

~C-e H D~ opens diagnostics. Use ~d~ there for Aural Doctor, ~s~ for spatial
capabilities, or ~m~ and ~n~ for retained main and notification diagnostics.
These inspection routes do not imply that speech has been repaired. Run a
repair or restart only when you deliberately choose that action. If there is
no speech at all, begin with
[[info:emacsvox#Recovering From No Speech][Recovering From No Speech]] rather than presentation settings.

The generated [[info:emacsvox-reference#Emacsvox Keymaps][Emacsvox Keymaps]] in the /Emacsvox Reference Manual/ records
default bindings. Return to ~C-h k~, ~C-h m~, and ~C-h b~ when a package or
personal configuration changes those defaults.
