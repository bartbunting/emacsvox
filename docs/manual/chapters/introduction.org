* Welcome to Emacsvox
:PROPERTIES:
:TEXINFO_NODE_NAME: Introduction
:DESCRIPTION: Meet Emacsvox and choose where to begin.
:END:

#+cindex: Introduction

Welcome to Emacsvox, a keyboard-driven spoken environment built on Emacs.  It
helps you read and write text, browse the Web, use mail and messaging, work in
shells, program, and explore structured information through speech and sound.

Emacsvox requires Emacs 31 or newer and is derived from Emacspeak.  Emacspeak's
pioneering audio-desktop design and T. V. Raman's original work remain the
foundation of this project.

Emacsvox works inside Emacs rather than reading the screen as a grid of pixels.
Because it can use commands, modes, text structure, and application state, it
can announce what an action means and what changed.  Ordinary movement speaks
the text crossed; different voices convey structure; auditory icons and tones
mark events without interrupting you with unnecessary words.

** Where To Begin
:PROPERTIES:
:TEXINFO_NODE: no
:END:

- If Emacsvox is not installed yet, start with
  @@texinfo:@ref{Installation}@@.  It takes you from a source checkout to a clean
  speaking session and includes a recovery path if speech does not start.

- If Emacsvox is already speaking, continue with @@texinfo:@ref{Basic Usage}@@ for a
  short first-session guide and the essential reading commands.

- If Emacs itself is new to you, @@texinfo:@kbd{C-h t}@@ opens the Emacs tutorial.
  Emacsvox speaks the tutorial and the commands you use while following it.

- In any Emacs buffer, @@texinfo:@kbd{C-h m}@@ describes the active modes and their
  commands, while @@texinfo:@kbd{C-h k}@@ followed by a key explains that key.  See
  @@texinfo:@ref{Using Online Help}@@ when you want to explore further.

** What You Will Hear
:PROPERTIES:
:TEXINFO_NODE: no
:END:

Emacsvox combines several kinds of feedback:

- speech for text, prompts, results, and status;
- voice changes that make syntax and document structure audible;
- short auditory icons and tones for events such as opening a file or
  completing an action; and
- pauses and spatial cues that help separate related information.

You can adjust this presentation gradually.  Aural Home, opened with
@@texinfo:@kbd{C-e H}@@, brings voices, sound packs, profiles, and other presentation
options together.  You do not need to configure it before beginning.  See
@@texinfo:@ref{Aural Presentation}@@ when you want to understand or change what you hear.

Emacsvox sends speech through a speech server.  New GNU/Linux, macOS, and WSL2
installations use Omnivox; established direct servers remain available for
compatible existing setups.  The installation chapter introduces only what
you need for first speech.  @@texinfo:@xref{Speech Backends}@@ contains the platform and
compatibility details.

** About This Manual
:PROPERTIES:
:TEXINFO_NODE: no
:END:

The maintained chapters provide the current Emacsvox setup and task guides.
The separate generated reference records commands, options, and keymaps from
the source, while the heritage manual preserves Emacspeak essays and
application guides for their historical and design value.  Historical material
may describe software or Web services from its original period.

Rapidly changing features are also documented in ~README.org~, ~etc/NEWS~,
and the generated Aural Presentation reference.  When a copied key binding
differs from your running Emacs, prefer the live help shown by @@texinfo:@kbd{C-h m}@@ or
@@texinfo:@kbd{C-h k}@@.
