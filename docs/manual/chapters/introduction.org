* Welcome to Emacsvox
:PROPERTIES:
:TEXINFO_NODE_NAME: Introduction
:DESCRIPTION: Meet Emacsvox and choose where to begin.
:END:

#+cindex: Introduction

Emacsvox is a keyboard-driven spoken environment built on Emacs. You can use
it to read and write text, browse the Web, manage mail and messaging, work in
shells, program, and explore structured information through speech and sound.

Emacsvox requires Emacs 30.2 or newer and is derived from Emacspeak. Emacspeak's
pioneering audio-desktop design and T. V. Raman's original work remain the
foundation of this project.

Emacsvox works with Emacs commands, modes, text structure, and application
state rather than treating the screen as a grid of pixels. It can therefore
announce what an action means and what changed. Movement speaks the relevant
text; voices distinguish structure; auditory icons and tones mark events
without adding words to everything you read.

** Where To Begin
:PROPERTIES:
:TEXINFO_NODE: no
:END:

Start with [[*Getting Started: Installation and First Speech][Installation]] if Emacsvox is not yet installed. It explains the
supported installation routes, takes you to a clean speaking session, and
provides recovery instructions when speech does not start. Once speech is
working, continue with [[*Basic Usage][Basic Usage]] for reading, editing, and speech controls.
[[*Work With The Audio Desktop][Audio Desktop]] then explains the buffers, modes, and navigation habits that
connect these tasks across applications.

If Emacs itself is new to you, ~C-h t~ opens its interactive tutorial.
Emacsvox speaks the tutorial and your navigation while you follow it. At any
point, ~C-h m~ describes the active modes and ~C-h k~ followed by a key
explains its current command. [[*Find Help While You Work][Using Online Help]] shows how to explore further.

** The Welcome Screen
:PROPERTIES:
:TEXINFO_NODE: no
:END:

At an idle startup, after speech is ready, Emacsvox offers a short welcome
screen. Its actions test speech, adjust rate and output volumes, choose voices
and engines, open the tutorial or manual, and start normal use. Move between
actions with ~TAB~ and ~S-TAB~, activate one with ~RET~, and use ~q~ to
return. Arrow keys read the instructions normally.

Toggle /Show this welcome screen at startup/ to stop showing it automatically.
The choice is saved in this Emacs profile and survives application upgrades.
Open the screen again through Help's /Emacsvox welcome/ entry, ~C-h W~, or
~M-x emacsvox-welcome~. Startup leaves explicitly opened files and sessions
already in use alone.

** What You Will Hear
:PROPERTIES:
:TEXINFO_NODE: no
:END:

Emacsvox combines several forms of feedback. Speech reads text, prompts,
results, and status. Voice changes make syntax and document structure audible.
Short auditory icons and tones identify events such as opening a file or
completing an action. Pauses and spatial cues help separate related information.

Begin with the supplied settings and adjust them as you learn what helps your
work. From the buffer you are using, ~C-e H~ opens the experimental Emacsvox
settings menu. Press ~s~ for speech controls, ~v~ for voices and engines, or
~o~ for sounds and output. ~C-e S~ opens focused settings for the current
integration, falling back to general buffer settings when no focused menu is
available. To understand a particular item's feedback, leave point on it and
press ~C-e E~.

In a settings menu, up/down selects an item, left/right changes sections, and
~RET~ activates the selection. ~?~ followed by an item's key explains that
item; ~? ?~ explains the menu. ~q~ returns one level and ~C-q~ closes the
menu sequence. Leaving a menu does not reverse adjustments already applied.
Settings and editors have distinct saving rules, explained alongside each task
in [[*Aural Presentation: Speech, Voices, And Sound][Aural Presentation]].

Aural Home remains available through ~C-e H h~ or ~M-x emacsvox-aural~ for
comparison and workflows that still return through Home. It is a separate
table-based interface, not another name for the settings menu. Follow the
navigation instructions for the interface you opened.

Emacsvox sends speech through a speech server. New GNU/Linux, macOS, and WSL2
installations use Omnivox; established direct servers remain available for
compatible existing setups. Installation introduces what you need for first
speech. [[*Speech Backends][Speech Backends]] provides the platform and compatibility details.

** About This Manual
:PROPERTIES:
:TEXINFO_NODE: no
:END:

The maintained chapters teach current setup and everyday tasks. Each explains
what you do, what feedback to expect, and how to inspect or recover the result.
The separate generated reference records commands, options, and keymaps from
the source. The heritage manual preserves Emacspeak essays and application
guides for their historical and design value; it is not a current setup guide.

Rapidly changing features are also documented in =README.org=, =etc/NEWS=,
and the generated Aural Presentation reference. When a copied binding differs
from your running Emacs, consult ~C-h k~, ~C-h m~, or ~C-h b~ for the
commands and bindings available in that session.
