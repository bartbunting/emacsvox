** Your working context
:PROPERTIES:
:TEXINFO_NODE_NAME: Working Context Terms
:DESCRIPTION: Distinguish buffers, views, editing positions and restrictions.
:END:

#+cindex: buffer, meaning
#+cindex: point, meaning
#+cindex: window, meaning
#+cindex: frame, meaning
#+cindex: read-only, meaning
#+cindex: narrowing, meaning
#+cindex: captured source
#+cindex: scope, meaning

- Buffer :: An Emacs object containing a document or application view. It is
  not necessarily a file, and switching buffers does not close the one you
  leave. A window displays a buffer. See [[info:emacsvox#Desktop Objects][Buffers hold your work]].
- Window :: A view of a buffer inside an Emacs frame. Removing a window does
  not kill its buffer. Two windows showing the same buffer are views of the
  same text, not independent copies. See [[info:emacsvox#Working With Windows][Working with windows]].
- Frame :: An outer Emacs application window, or the corresponding display in
  a terminal session. It contains Emacs windows. Selecting another window
  within a frame differs from switching applications in the operating system.
  See [[info:emacsvox#Working With Windows][Windows and frames]].
- Point :: The current editing position, between characters. Text is normally
  inserted there. Short reading often leaves it unchanged; tracked reading
  advances it. See [[info:emacsvox#Reading From Point][Reading position and interruption]].
- Mode :: The commands and behaviour associated with a buffer. Its major mode
  supplies its principal tools; minor modes add other behaviour. See
  [[info:emacsvox#Object Oriented Desktop][Let modes give each buffer its tools]].
- Read-only :: A buffer state that prevents ordinary text edits. It does not
  mean the buffer has no unsaved changes, and making a buffer writable does
  not grant permission to overwrite a protected file. Special applications
  may still provide their own operations. See [[info:emacsvox#Opening A Document][Opening a document safely]].
- Narrowing :: Restricting access to part of a buffer without deleting the
  rest. Reading, movement and many editing commands stay within that portion;
  widening removes the restriction. Ordinary file saving still saves the
  entire buffer. See [[info:emacsvox#Reading Without Moving Point][Reading accessible text]] and
  [[info:emacs#Narrowing][Narrowing]] in the GNU Emacs Manual.
- Captured source :: The buffer and position retained when a settings workflow
  starts. Contextual actions continue to refer to that source rather than
  whichever menu or editor is currently selected. A changed or closed source
  may need to be captured again. See [[info:emacsvox#Aural Home][Getting started with settings menus]].
- Scope :: Where a setting or rule applies, such as one buffer, a session,
  or global defaults. Scope is not the same as persistence: a global change
  need not be saved, and a saved resource need not be active. See
  [[info:emacsvox#Saving And Startup][Choose what persists]].

** Selection, copying and editing
:PROPERTIES:
:TEXINFO_NODE_NAME: Editing Terms
:DESCRIPTION: Translate selection, cut and paste into mark, region, kill and yank.
:END:

#+cindex: mark, meaning
#+cindex: region, meaning
#+cindex: selection, meaning
#+cindex: active region, meaning
#+cindex: Transient Mark mode, meaning
#+cindex: copy, meaning
#+cindex: cut, meaning
#+cindex: kill, meaning
#+cindex: paste, meaning
#+cindex: yank, meaning
#+cindex: kill ring, meaning
#+cindex: clipboard, meaning
#+cindex: undo, meaning

- Mark :: A remembered position in a buffer. Point and mark delimit the
  region, whichever comes first. The mark can remain after the selection is
  deactivated; it is not copied text. See [[info:emacsvox#Selecting Text With Speech][Selecting and checking text]].
- Region or selection :: The text between point and mark, including any
  selected spaces and newlines. The character at its end is excluded. The
  active region is the current selection; some commands can also use an
  inactive mark. Establish a fresh region before cutting. See
  [[info:emacsvox#Selecting Text With Speech][Selection boundaries and activation]].
- Transient Mark mode :: Emacs's usual active-selection behaviour, used by
  the editing examples. It is unrelated to the Transient package that supplies
  settings menus. See [[info:emacsvox#Selecting Text With Speech][Using the region through speech]] and
  [[info:emacs#Mark][The mark and the region]] in the GNU Emacs Manual.
- Copy :: Store a passage in the kill ring while leaving its source text
  unchanged. The destination becomes an independent text copy when you paste
  it. See [[info:emacsvox#Copying Text Between Buffers][Copying between buffers]].
- Kill or cut :: Remove text and keep it in the kill ring for later insertion.
  Some deletion commands do not keep that copy. Killing a buffer is a different
  operation: it closes the buffer rather than copying its contents. See
  [[info:emacsvox#Moving Text Safely][Moving text safely]].
- Yank or paste :: Insert text from the kill ring, or through configured
  clipboard integration, at point. It changes the destination buffer, not
  automatically its saved file. See [[info:emacsvox#Copying Text Between Buffers][Checking a paste]].
- Kill ring :: Emacs's shared history of copied and cut text. It can contain
  more than the latest passage, including text placed there by inspection
  commands. It is not a permanent backup or the same store as the system
  clipboard. See [[info:emacsvox#Choosing Earlier Copied Text][Choosing an earlier copy]].
- Clipboard :: The operating system's text-transfer facility. Its connection
  to Emacs depends on the display session and configuration; a new external
  copy can affect the next paste. See [[info:emacsvox#Copying Through The Clipboard][Testing clipboard exchange]].
- Undo :: Reverse recorded edits in the selected buffer. It does not reverse
  a settings save or an action already sent to another application. When
  listening between successive corrections, use the recovery guide's
  =undo-only= procedure. See [[info:emacsvox#Recovering Text Edits][Undo and spoken inspection]].

** Voices and presentation resources
:PROPERTIES:
:TEXINFO_NODE_NAME: Presentation Resource Terms
:DESCRIPTION: Distinguish physical voices, named voices, palettes, rules and profiles.
:END:

#+cindex: physical voice, meaning
#+cindex: named voice, meaning
#+cindex: palette, meaning
#+cindex: profile, meaning
#+cindex: rule, meaning
#+cindex: auditory icon, meaning

- Physical voice :: A voice reported by a speech engine, such as an installed
  system voice or a downloaded model's voice. Installation alone does not
  prove that it is enabled, active, or audible. See
  [[info:emacsvox#Installed Voices And Engines][Installed voices and engines]].
- Named voice :: A presentation name such as =default= or =bolden=, resolved
  through a voice palette to physical choices and adjustments. Editing a
  shared named voice can affect several kinds of text that use it. See
  [[info:emacsvox#Editing Named Voices][Edit a named voice]].
- Voice palette :: A collection defining named voices, including their
  physical choices, fallbacks, and adjustments. Palettes can inherit values;
  editing one is different from changing an engine preference. See
  [[info:emacsvox#Voices And Routing][Voices and routing]].
- Presentation rule :: A match between application meaning or context and
  the feedback to produce, such as a voice, cue, or silence. A rule chooses
  presentation; it does not install a physical voice. See
  [[info:emacsvox#Managing Feedback Rules][Manage feedback rules]].
- Auditory icon or cue :: A short sound conveying an event or state. A sound
  pack supplies cues, while presentation rules determine when to use them.
  Tones can convey information without a recorded sound file. See
  [[info:emacsvox#Sounds And Space][Sounds and space]].
- Presentation profile :: A saved selection of presentation resources and
  options. It refers to resources rather than copying everything into a full
  configuration backup. Applying a profile also retains its selection for
  startup; individual palette operations have different rules. See
  [[info:emacsvox#Presentation Profiles][Presentation profiles]].

** Changes and speech output
:PROPERTIES:
:TEXINFO_NODE_NAME: Speech And Settings Terms
:DESCRIPTION: Distinguish preview, drafts, saving, application and speech workers.
:END:

#+cindex: preview, meaning
#+cindex: retained draft, meaning
#+cindex: Save, meaning
#+cindex: Apply, meaning
#+cindex: startup selection
#+cindex: speech worker, meaning

- Preview :: An audition or comparison of a proposed result. Previewing does
  not by itself save the draft or make it the ordinary live configuration.
- Retained draft :: An unfinished edit kept in the current Emacs session for
  return to its editor. Retaining it is not a promise of recovery after Emacs
  exits, and discarding it does not undo a save already completed.
- Save :: Record data in the store owned by that editor or setting. Read the
  action's label: /Save and apply/ and /Save to collection without selecting/
  intentionally have different effects.
- Apply :: Put a chosen configuration into use. The operation may require
  confirmation, validation, or a worker restart. Its exact effect depends on
  the resource; it is not a universal synonym for saving.
- Startup selection :: The configuration to select when a later session
  starts. Selecting something for this session does not always select it for
  the next one. [[info:emacsvox#Saving And Startup][Choose what persists]] compares these states and their owners.
- Speech server, engine, and worker :: Emacsvox talks to a speech server;
  the server uses engines to synthesise speech. The manual uses /worker/ for
  a running speech instance whose configuration and reported voices can
  differ from another instance or from installed files. See
  [[info:emacsvox#Speech Backends][Speech Backends]].
- Main and notification speech :: Separate output paths for foreground
  reading and other announcements. An integration decides which path to use
  for an event; their existence is not a guarantee that all background text
  is private. See [[info:emacsvox#Aural Speech Output][Speech output and notifications]].
