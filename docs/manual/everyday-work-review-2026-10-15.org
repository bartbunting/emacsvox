* Editorial responsibilities and content

=using-manual.org= now owns the beginner explanation of answering minibuffer
prompts, completion, sequential questions, filename entry, example paths and
input contexts. It distinguishes typing an answer from editing a document,
Emacs commands from shell commands, and cancelling an unfinished command from
undoing an operation already performed. It links to the existing key primer
rather than duplicating it.

=applications.org= adds files and directories before Document Authoring, expands
the existing authoring section into a real Org-document workflow, and replaces
the short EWW overview with a connected web-reading guide. These tasks are
independent of the tutorial and use existing speech settings.

File guidance separates the working buffer from the saved file. It explains
read-only visits, checking a destination, writing a separate working copy with
write-file, copying the last saved file with copy-file, and preserving work
after a save error or external modification. Dired guidance distinguishes
inspection from marking, ordinary RET from the smart opener, lowercase c from
Copy, and leaving a listing from deletion. External du/file dependencies are
stated beside the affected inspections.

The Org task creates a deliberately named file, reviews headings and folding,
then searches for and corrects one word. It distinguishes visibility from
content, undo from saving, and buffer names from file destinations. The literal
sample contains no executable code or file-local configuration.

The EWW task uses Emacsvox's actual bindings rather than copying stock EWW keys.
It distinguishes links from browser history, a link address from the page URL,
readable views from site content, and web bookmarks from ebook-position marks.
It covers changing buffer titles, separate buffers, contextual k, search
privacy, network errors, form-input loss on reload, and external-browser
handoff. A browser or network failure is not treated as a speech-engine failure.

The remaining application sections retain their instructions. The existing CSV
copy list gains explicit verbs in two descriptions for spoken clarity; no key
or behaviour changes there. All material from Messaging to the chapter's end
is byte-for-byte unchanged. The expanded summaries keep the original upstream
and generated-reference destinations.

=finding-tasks.org= adds direct routes for prompts, files, notes and web pages.
It retains the prior goals and recovery links. Procedures have one maintained
home; the task finder does not copy their steps.
