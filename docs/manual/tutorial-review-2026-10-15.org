* Scope

The tutorial is based on =ui-experiments= at
=6729d414c28d573fdf2f954e81dba257de6ea7d9=. It follows the retired-Home
settings routes and retains the committed Transient requirement without
changing dependencies, Lisp, packaging, or publication machinery.

Six connected lessons use one disposable document: reading, editing, Help and
buffers, Org structure and shared table reading, buffer punctuation, and voice
experiments. Twelve exercises have separate answers. The required path saves
no speech settings. The optional palette exercise clearly identifies file
writes, session selection, restoration of baseline-following, and the separate
startup action. Existing drafts and personal resources are not cleanup targets.

=examples/tutorial-practice.org= is the single source of the example. The
tutorial includes it as an Org example block so Info and HTML readers receive
the complete text without needing a checkout. Changes to that file must also
be checked against the lessons' search strings, table answers, and line count.
The source block in the sample is for reading and is never evaluated by the
lesson. Do not copy its contents into a second maintained example.

The master includes the tutorial immediately after Installation. Introduction
and Using This Manual link to it while retaining the reference reading paths.
Ten named destinations are added; all 136 previous identifiers and their
relative ordering remain. Next/Previous navigation around the inserted chapter
changes intentionally. Existing application chapters are unchanged.
