* Editorial changes

The keyboard chapter now starts with 35 reminders grouped by reading, editing,
files and windows, Help, and speech settings. Each identifies a purpose, default
key, consequential condition and link to the fuller procedure. The displayed
chapter title is /Everyday commands and key prefixes/; its existing heading and
Info identifier remain. The original prefix, customisation and binding-discovery
material is retained after the reminders, not replaced by another cheat sheet.

The reminders retain the distinctions established by the detailed guides:
tracked reading moves point; short inspection generally does not; large buffer
or region reads can change the window layout; a paste and an immediate yank-pop
form a command sequence; undo-only supports inspection between corrections;
Help selects its own view; and filename/message inspection changes the kill ring.
Settings navigation does not undo applied changes. The generated reference
remains the exhaustive inventory, and Basic Usage remains the procedure owner.

The glossary adds windows, frames, read-only state, narrowing and selection-based
editing vocabulary. Familiar copying, cutting and pasting terms lead to mark,
region, kill, yank and kill ring. Transient Mark mode is distinguished from the
settings-menu package. Existing voice, profile, scope and persistence definitions
are preserved. Four glossary destinations prevent the editing definitions from
absorbing later presentation material in Info navigation.

The task finder retains existing routes. It adds ordinary index phrases for
reading from here, earlier copies, undo while listening and closing a view, plus
symptom routes for an unexpected filename/message paste and Help replacing
split windows. The stop-speech link reaches the concise reading reference.
It does not duplicate the procedures or reintroduce the retired Home entry.
