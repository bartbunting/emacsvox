* Scope

Follow the completed directory migration with internal responsibility splits.
Preserve public commands, features, keys, saved data, speech protocols and
optional-package behaviour. The directory registry and Make inventory retain
their roles under ADR 0029. No compatibility removal or runtime dependency
upgrade is included. Existing broad core utilities remain later work.

Each slice gets affected source tests, current byte-code, fresh compiled
verification, header and documentation checks, and its own commit. Graphical
navigation uses isolated Xvfb Emacs sessions. The running personal session is
not reloaded. Automated checks do not establish listening acceptance.

* Delivery

1. Extract Agent Shell's rendered-table adapter, retaining central activation.
2. Separate library runtime activation from the interactive voice library;
   share explicit library operations with the workbench.
3. Separate workbench row construction and filtering from editing interaction.
4. Extract Omnivox control and preview codecs and aural timeline encoding from
   runtime lifecycle ownership where their dependencies permit it.
5. Review the remaining Agent Shell navigation/event and TTS lifecycle splits
   against the resulting boundaries. Record any design choice before changing
   ownership, ordering or public contracts.
