** Confirm upgrade and feature scope

Palette readers accept schema 3 only. The previous shared per-voice routing
and migration screens are gone. Confirm that the published upgrade guidance
is sufficient for existing personal setups, with originals retained and
palette identity, choices and profile references preserved. Do not imply
that opening a palette converts older data automatically. See
[[file:adr/0018-unified-voice-palette-model.org][ADR 0018]].

Engine-described native parameters are still being implemented separately.
Do not advertise a finished native-control editor based only on helper codec
or runtime qualification work. Reconcile release scope with
[[file:engine-voice-parameters-design.org][the implementation record]] and update NEWS when its public behavior is
implemented and verified.

Voice-library management currently uses the bundled WSL-to-Windows launcher.
Do not imply equivalent management on remote or direct native launches.
