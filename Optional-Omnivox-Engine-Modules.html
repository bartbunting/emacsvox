4.3.2 Optional Omnivox Engine Modules ¶

The ordinary WSL2 archive is the Omnivox core, not a claim that every supported engine is installed. It keeps first speech small while matching companion archives provide engines that are larger, experimental, architecture-specific, or incomplete without separately chosen data.

From a running Emacsvox session, open: 

M-x emacsvox-omnivox-manage-components RET

You can also press C-e H for Aural Home and then I on Omnivox engine modules. The spoken table reports each engine as installed, downloadable, unavailable on this architecture, needing a core update, or needing a separately supplied runtime or model. Release state describes the managed release installation. Browse and try voices reports the active speech server, which can use a different installation, such as a development runtime or a remote workstation. Installing a module here changes the managed release only. Move to an engine row, then choose the task you want:

  • To install a not installed module, press i and confirm. The manager downloads the version matched to your Omnivox core, verifies it, and announces when installation is complete. Its state changes to installing immediately and stays that way if you refresh or reopen the manager.
  • To check any engine, press t. Emacsvox announces how many voices Omnivox found and selects an accessible buffer containing the complete list. If the check fails, it announces and displays the actual diagnostic instead of only an exit code. Press q to return to the manager or h for Aural Home.
  • To remove an installed module, press u and confirm. This is available only for Flite, RuTTS, Piper, and TGSpeechBox modules installed by this manager. It cannot remove the Omnivox core, built-in engines, or runtime bridges.

Removal keeps the verified download in the local cache. If you change your mind, select the module again—its state will now be not installed—and press i to reinstall it. A valid cached download is reused.

The module’s whole managed directory is removed. Move anything you placed inside that directory somewhere else before confirming. User-supplied runtimes and models stored outside it are not touched; remove those separately using their supplier’s instructions. Before removal, the manager announces the operation and briefly stops its active Omnivox speech streams so Windows can release the module helper. It restores speech when removal finishes, including after an error. After a successful installation, it also refreshes the table and restarts a running Omnivox server. Operations run asynchronously so Emacs remains responsive. The table shows uninstalling during removal and testing during a voice check. Completion or failure refreshes the state; if that refresh fails, the last known state remains with a spoken error.

If a removal reports that its helper is still in use, close any other Emacsvox or Omnivox session using that release and press u again. The manager safely recognizes an interrupted removal when the expected helper is the only file left; it continues to refuse directories containing unrecognized files.

The manager reads ‘etc/omnivox-components.conf’. Every archive name, byte size, and SHA-256 hash is pinned to the same Omnivox version as the installed core. The WSL2 installer rejects a mismatched core, an unsafe archive layout, missing source provenance, or a helper that cannot pass its staged voice-discovery check. It then installs the module below the same versioned Windows ‘LocalAppData’ release directory. It does not invoke ‘sudo’ or edit shell startup files.

The choices have different boundaries:

  • Flite includes its compact English SLT voice and needs no external runtime.
  • RuTTS includes its compact Russian voices and needs no external runtime.
  • Piper installs native engine support, but appears only after you separately review and configure an ONNX voice model and its model card.
  • TGSpeechBox is an explicitly experimental multilingual formant engine. The 1.10.0 module calibrates rate control to the Eloquence scale and supplies exact requested text anchors for capitalization and timed presentation.
  • RHVoice, Eloquence, and DECtalk use distributable bridges, but Emacsvox never downloads their external runtimes, voices, dictionaries, or licence material. Supply those only when you have the appropriate distribution and licence.

For a terminal-only installation, run ‘./bin/emacsvox-omnivox-components --list’ and then, for example, ‘./bin/emacsvox-omnivox-components --install flite’. Multiple module names may follow ‘--install’ or ‘--uninstall’. For example, use ‘./bin/emacsvox-omnivox-components --uninstall flite’ to remove the managed Flite directory while retaining its cached archive. Restart Omnivox after a terminal installation or removal, then use ‘--test ENGINE’ or the Emacs manager’s t command. The direct Omnivox release assets remain available for maintainers and recovery, but the manager is the recommended way to select them.
