9.4.3 Reading Markdown and Org tables ¶

In a Markdown or Org table, press a Control-Meta arrow to enter table reading and move immediately. Left/right moves between columns; up/down moves between logical rows, retaining the column. Every Control-Meta arrow reads the destination cell. The first movement announces table reading and the destination together. Table reading starts on demand by default in these source buffers; you can choose automatic entry in the Tables settings described below. Outside supported tables, these arrows retain their existing bindings, including inside code examples.

C-e C-t C-r enters at the current cell with the default speech prefix. It announces the dimensions and current cell. The equivalent named command is M-x emacsvox-table-reader-mode. Press q or the same command to restore ordinary editing keys without moving point. This suspends automatic entry for the current visit: another explicit entry command, or leaving the table and returning, can start reading again. From prose, C-e C-t ] and C-e C-t [ find and enter the next or previous table. Inside table reading, t and T do the same; code examples are skipped.

While table reading is active:

  • Plain Up/down moves by logical row and reads the complete destination row by default. You can select cell speech for these keys. Control-Meta-up/down always reads the destination cell; both retain the column.
  • Control-Meta-left/right moves between cells. Plain left/right retains character movement. TAB and S-TAB move between cells without editing; RET or SPC reads the current cell.
  • r reads the row and c the column. . announces coordinates and = gives dimensions.
  • a opens Tables settings for titles, order, movement speech, activation and optional detail. Browsing settings leaves the table untouched.
  • w or k k copies the cell, k r copies the row with tabs between cells, and k c copies the column with newlines between cells.
  • Meta-up/down leaves directly for preceding/following prose. Up/down also leaves across a vertical table edge when content exists beyond it by default. Choose Stop at the edge to retain the cell instead. If no adjacent content exists, point stays in the table.

A horizontal edge or a missing cell in a shorter row leaves point unchanged and announces the boundary. Separators are skipped. A separator immediately after the first row identifies column titles; otherwise that row is data. Coordinates distinguish the header from one-based data rows. Empty cells are spoken as “blank.” Wrapping never shortens a logical cell’s speech or copy.

Reading does not align tables, create rows, or evaluate Org formulas. Copies use cell values: ordinary links become their labels and inline code becomes its literal text. Use the host mode to copy exact markup or formulas. This reader covers simple pipe tables; HTML spans, nested tables, and spreadsheet-specific structures have separate interfaces.

Other editing commands retain their normal meaning. An edit ends reading and suspends automatic re-entry while you continue typing. Org’s native table editing feedback, including its table Muggle, remains independent; it can speak after native cell movement without starting this reader. Markdown’s markup-stripping speech preference also remains independent.

Agent Shell uses the same reading preferences and movement units, with automatic entry as its initial policy. It retains native Tab, Shift-Tab and Return actions and handles character movement within rendered cells; see Agent Shell.

9.4.4 Reading application lists ¶

In an application built on Tabulated List mode, use a Control-Meta arrow or C-e C-t C-r to enter shared reading. Ordinary application navigation stays unchanged until you enter, unless you select automatic entry. Within reading, plain up/down reads complete logical rows by default, Control-Meta arrows read cells, and plain left/right inspects characters. q leaves reading and restores the application’s usual navigation.

Application actions take precedence over other shared reader keys. Opening, refreshing, sorting, searching, and editing keep their commands, including RET on a button. When a shared key is occupied, use M-x emacsvox-table-reader-speak-cell, M-x emacsvox-table-reader-speak-row, M-x emacsvox-table-reader-speak-column, M-x emacsvox-table-reader-speak-context, or M-x emacsvox-table-reader-speak-dimensions. The matching emacsvox-table-reader-copy-cell, emacsvox-table-reader-copy-row and emacsvox-table-reader-copy-column commands copy logical values.

Speech and copies use complete entry text even when a displayed column is truncated. Column headings come from the application, not the first item. Coordinates count visible data rows; hidden rows are excluded and empty cells say “blank.” Movement stops at the first or last row. A refresh ends reading; enter again to inspect the refreshed list. Custom table printers, image-only cells, and duplicate column names are not supported by this reader.

9.4.5 Choose table reading preferences ¶

Open M-x emacsvox-table-settings from the buffer you want to configure. While reading a source or Agent Shell table, a opens the same page. The speech settings menu provides C-e H s T, and the focused Org and Agent Shell menus provide T. Settings search at C-e H / finds table reading, titles, activation and inheritance. Each route captures the original buffer so moving through the menu does not redirect your changes.

A control shows its pending choice, its effective value and the source of that value. Open the control, browse with arrows, then press RET to stage a choice and return to that control. Press q in the choice list to cancel. Neither browsing nor selecting changes runtime behaviour yet. Press ? and a choice’s key for Help; returning restores the browsed choice. The page’s h explains scopes, migration and host exceptions.

For example, open Titles with t, select Both titles, and press SPC to preview a small sample. The sample includes a second row and a blank cell; it uses the pending speech choices without moving or editing your source. s stops it. Preview treats pending choices as buffer overrides, so inheritance uses the current mode settings. Saving inheritance for the mode can resolve to a different common value; the effective labels refresh after saving. Try activation and edge behaviour in an actual table after applying them, since the speech sample does not navigate the source.

Choose one explicit action to use the pending settings:

  • A applies only the changed choices temporarily to the captured buffer.
  • W saves only those choices as common defaults through Customize.
  • M saves only those choices for the captured major mode through Customize. Agent Shell’s transcript and viewport share one mode setting.

After Apply, choices are labelled applied here, not saved. You can then Save without selecting them again. Closing keeps applied buffer choices but does not persist them.

Buffer overrides take precedence over mode overrides, which take precedence over common defaults. Saving a wider default preserves narrower overrides; the effective labels show when an override still wins. No titles is an explicit choice, distinct from inheritance. Select Inherit wider scope and Apply to release a buffer choice, or Save mode to make that mode follow the common default. I stages inheritance for all settings; it still requires Apply or Save mode. Common defaults cannot inherit. D discards pending choices. Closing the page discards choices that were neither applied nor saved.

The controls cover titles, data/title order, plain-arrow speech, activation, coordinates during movement, entry detail, repeated titles and vertical edges. Initial defaults retain whole-row plain arrows, full entry detail, repeated titles, no extra movement coordinates and leaving at vertical edges when adjacent prose exists. Brief entry still identifies a table and reads its cell. Suppressing repeated titles affects consecutive cell moves; explicit cell inspection remains complete. Application lists always stop at their edges.

Activation’s Mode defaults choice means automatic entry in Agent Shell and Notmuch HTML data tables, and on-demand entry in Org, Markdown and application lists. A common Automatic or On demand choice applies wherever there is no narrower override. Quitting always provides a temporary escape from automatic reading. A redraw or Agent Shell response update alone cannot undo that quit.

Existing shared title/order settings retain their scope. Older Agent Shell title/order choices remain effective as Agent Shell overrides, including saved choices equal to their original defaults. The page identifies their source; Help lists retained older values even when a newer override takes precedence. An older value whose origin cannot be determined is preserved and identified as uncertain. Select a replacement or inheritance explicitly to resolve it. Opening the page never rewrites configuration. Advanced configuration lives in the emacsvox-table-reader customisation group.

9.4.6 Browsing CSV data ¶

Use emacsvox-table-find-csv-file to open a CSV file in the table browser, or emacsvox-table-view-csv-buffer for the current buffer’s CSV data. Quoted commas, doubled quotation marks, and multiline fields remain single logical cells. Blank records outside quoted fields are skipped; empty fields remain cells. Empty input or malformed quoting produces an error before creating a view.

Browsing preserves source text. If the file is already open, the view uses that buffer’s current contents, including unsaved edits, without replacing the source buffer. Shared table controls are active immediately:

  • Up/down and Control-Meta-up/down move by logical row and read the whole row.
  • Control-Meta-left/right and TAB~/~S-TAB move by cell. Plain left/right and C-b~/~C-f move by character; C-p~/~C-n move by logical row.
  • RET or SPC reads the cell; r reads the row and c the column.
  • . gives coordinates and = dimensions. The first row supplies column titles and is announced separately from data rows.
  • w or k k copies the cell, k r copies the row with tabs between cells, and k c copies the column with newlines between cells. K copies the whole table to the clipboard used by emacsvox-table-paste-from-clipboard.
  • a changes column titles, row titles, or data order for this view using shared reader preferences. q closes the view.

These replace the old browser cell-arrow, header-reading, automatic-speech, and single-key table-copy bindings. The old local aliases b, n, p, A, B, E, and T are removed; speech-prefix table commands remain available.

Search with s, R for a row, C for a column, or h for headers. # sorts on the current column and M-<~/~M-> jumps to the top or bottom. At an edge, movement announces the boundary and leaves point in place.

Filters remain on f for a row and g for a column; a prefix argument requests a new filter. Filter indexes and the j jump prompt retain zero-based model coordinates, including the header, although spoken coordinates count data rows and columns from one. For example, the row filter (0 "value" 2) reads the first column, “value”, and the third column. M-l and M-s load and save filters. Filters are explicit inspections; shared row movement always reads the whole row. Sorting preserves filters and speech preferences. Use C-h m for the full browser key map.
