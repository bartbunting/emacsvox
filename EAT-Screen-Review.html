12.4 Explicit Review Commands ¶

With the default speech prefix, C-e q provides review commands in every EAT input mode:

C-e q l

Speak the cursor row from the latest retained screen.

C-e q d

Speak the last classified change.

C-e q h

Speak the conservative likely-focus inference and its confidence.

C-e q c

Speak retained completion candidates or help rows.

C-e q s

Speak a bounded copy of the retained visible screen.

C-e q r

Open a read-only frozen copy for line-by-line review.

C-e q t

Speak retained progress, application, or shell-prompt status.

C-e q p

Speak the last identified shell prompt.

C-e q i

Speak the retained, sanitised title or working-directory change.

C-e q v

Cycle terse, normal, and verbose automatic feedback for this terminal.

C-e q m

Toggle content-free background monitoring for this terminal.

The reading commands inspect retained snapshots with concealed content redacted. The verbosity and monitoring commands instead change the source terminal’s preferences. Neither operation sends terminal input. Speech is bounded: the retained visible screen is not arbitrary scrollback and need not match a changing live screen.

  • Frozen Screen Review

12.4.1 Frozen Screen Review ¶

C-e q r opens an immutable copy of the latest visible screen. It does not refresh, move the live cursor, or send input. It preserves normalised styling, cursor and likely-focus anchors, and retained completion rows. Opening and closing play distinct object cues and announce the transition.

n, p; C-n, C-p; down, up

Move by captured terminal row and speak the destination, interrupting the previous row announcement.

SPC, RET, .

Speak the current captured row.

a

Speak a bounded form of the current screen or completion view.

s, c

Show captured screen rows or retained completion/help rows.

C

Go to the captured terminal cursor.

h

Go to retained likely focus when available.

[, ]

Move among inverse/background-styled, selection-like regions. They are not labelled as confirmed focus.

t, i

Speak status or metadata copied when review opened.

v, m

Change verbosity or monitoring in the source terminal without sending terminal input. The copied content stays frozen.

?

Describe frozen review mode.

q

Kill the content-bearing review buffer and restore its window.

Secure input, terminal reset or restart, killing the source, or leaving EAT mode also destroys its frozen review. These events bound the lifetime of copied terminal content.
