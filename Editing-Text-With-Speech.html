5.6 Select, copy, and move text ¶

Reading a passage is not the same as selecting it for an operation. These procedures make the affected text and destination explicit before changing anything. They apply to ordinary editable text, not terminal input, a settings editor or a table reader. Keep using the application’s own instructions in those contexts.

For practice, use C-x b to create an unused buffer named evox-edit-source, run M-x text-mode RET, and insert the following text, including the blank lines and a final newline after the last sentence. Use another unused name if that buffer already contains work. No file or speech-setting save is needed. 

Keep the opening paragraph.

Move this paragraph.

Keep the closing paragraph.

Keep the manual open separately and return to this buffer before trying a step. Answer a prompt and return to your work explains command entry; the Killing and moving text chapter in the GNU Emacs Manual supplies the wider editing reference.
