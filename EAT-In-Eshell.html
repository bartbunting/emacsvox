12.10 EAT In Eshell ¶

With global eat-eshell-mode enabled, Emacsvox uses the same screen observer for EAT’s terminal region inside Eshell. Rendered command output follows one speech path instead of also being repeated by generic Eshell feedback.

With eat-eshell-visual-command-mode, a visual command runs in a separate EAT buffer. Emacsvox announces its start, delivers eligible final output before process-exit feedback, and identifies the exit as an Eshell visual command. EAT and Eshell still own window return. In particular, eshell-destroy-buffer-when-process-dies determines whether a successful visual-command buffer is killed and Eshell restored; Emacsvox does not change it.
