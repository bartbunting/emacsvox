12 Speech Access To EAT ¶

EAT (Emulate A Terminal) is a third-party terminal emulator, commonly installed from NonGNU ELPA. Run M-x eat to start it; a prefix argument creates or selects another terminal. Follow the Eat User Manual for installation, terminal setup, and EAT’s complete command reference.

Three parts cooperate here. EAT emulates the terminal; the shell, router, or other program handles terminal input and completion; Emacsvox presents the rendered result. Emacsvox observes a bounded screen, not the program’s private state. It does not generate shell or router completion candidates.

First choose an input mode appropriate to the program. Then use automatic feedback for current work and explicit review for content you need to examine again. C-e S opens focused EAT speech settings; those menu keys apply only while the menu is open, not to ordinary terminal input.
