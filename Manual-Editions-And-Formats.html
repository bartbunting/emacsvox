2.4 Recognise the document you are reading ¶

This user manual explains tasks, feedback, and recovery. The generated Emacsvox Reference Manual lists commands, options, and keymaps from source. The heritage manual preserves historical Emacspeak material; it is not a current setup guide. A linked application’s own manual remains authoritative for that application’s general operations.

Some stable Info identifiers predate their displayed headings. For example, Aural Home now identifies Getting started with settings menus. This keeps old links and bookmarks valid; it does not make the retired Home menu entry part of the learning route.

In HTML, use the contents, headings, and task links, then your browser’s Back command to return from a link. The Info keys above are not browser commands. The published website may describe a different revision from your installed manual. Use the manual matching your Emacsvox version, and check live Help when a key differs from the documented default.
