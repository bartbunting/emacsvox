11 Agent Shell ¶

Agent Shell is an Emacs package for interactive AI-agent sessions. Emacsvox adds speech and structured navigation to its prompts, responses, permissions, and other activity. Agent Shell remains responsible for providers, sessions, prompt editing, and permission decisions. Install and configure Agent Shell using its own documentation; Emacsvox requires version 0.85.3 or newer.

This chapter follows a session from writing a prompt through receiving and reviewing an answer, then explains speech choices and recovery. The generated emacsvox-agent-shell section in the Emacsvox Reference Manual lists the complete Emacsvox command and option interfaces.

  • Start and control a session
  • Answer an agent’s question
  • Choose automatic speech and privacy
  • Respond to urgent permissions
  • Inspect a response on demand
  • Navigate transcript blocks
  • Read and copy source blocks
  • Navigate and copy rendered tables
  • Recover from interruption or failure
