3.8 Find Out Where You Are ¶

Use these commands when you need context without moving point. They repeat the last message, identify the current buffer and modes, or report your position. Less common status commands are listed in the Emacsvox Keymaps in Emacsvox Reference Manual.

C-e a ¶

emacsvox-speak-message-again

Repeat the last Emacs message.

C-e m ¶

emacsvox-speak-mode-line

Speak the mode line, including the buffer name and major mode.

C-e f ¶

emacsvox-speak-buffer-filename

Speak the current file name, or the default directory when the buffer is not visiting a file.

C-e C-l ¶

what-line

Report the current line number and position in the buffer.

C-e = ¶

emacsvox-speak-current-column

Speak the current column.

C-e % ¶

emacsvox-speak-current-percentage

Announce the percentage into the current buffer.
