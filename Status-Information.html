5.10 Find Out Where You Are ¶

These commands report context without moving point: the last message, current buffer/modes, or position.

C-e a ¶

emacsvox-speak-message-again

Repeat the last Emacs message and copy it to the kill ring. This can change what the next yank inserts.

C-e m ¶

emacsvox-speak-mode-line

Speak the mode line, including buffer name and major mode.

C-e f ¶

emacsvox-speak-buffer-filename

Speak the file name, or default directory when no file is visited, and copy that location to the kill ring. Inspect it before copying text for a transfer.

C-e C-l ¶

what-line

Report the line number and position in the buffer.

C-e = ¶

emacsvox-speak-current-column

Speak the current column.

C-e % ¶

emacsvox-speak-current-percentage

Announce the percentage into the buffer.
