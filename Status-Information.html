3.6 Status Commands ¶

These common commands answer frequent orientation questions. Less common status commands are listed in the Emacsvox Keymaps in Emacsvox Reference Manual.

C-e a ¶

emacsvox-speak-message-again

Speak the last message from Emacs once again.

C-e m ¶

emacsvox-speak-mode-line

Speak the mode-line.

C-e M ¶

emacsvox-speak-minor-mode-line

Speak the minor mode-information.

C-e C-x ¶

emacsvox-speak-header-line

Speak the header-line.

C-e C-w

emacsvox-speak-window-information

Speaks information about current windows.

C-e f ¶

emacsvox-speak-buffer-filename

Speak name of file being visited in current buffer. Speak default directory if invoked in a dired buffer, or when the buffer is not visiting any file.

C-e C-l ¶

what-line

reports the current line number and position in the buffer.

C-e = ¶

emacsvox-speak-current-column

Speak the current column.

C-e % ¶

emacsvox-speak-current-percentage

Announce the percentage into the current buffer.
