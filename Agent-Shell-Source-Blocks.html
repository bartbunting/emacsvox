11.7 Read and copy source blocks ¶

Use k or K, or typed block navigation, to reach a source block, then:

C-c C-b

Run emacsvox-agent-shell-speak-source-block to read the complete rendered source block with its language and line count.

C-c C-y

Run emacsvox-agent-shell-copy-source-block to copy the logical source through Agent Shell’s public copy operation.

The source commands are explicit operations and do not use the automatic content limit. Ordinary line navigation retains its separate bounded speech policy.

11.7.1 Review proposed changes ¶

Opening an Agent Shell change review announces its file and hunk counts and, for a single file, its name. The normal Diff Mode hunk navigation remains available; opening the review does not accept or reject changes.

These events can have their own presentation rules. You can customise speech, voices and earcons for steering outcomes, queue changes, list editing, setting changes, updated tool output and change-review entry. Use Feedback Details to inspect a representative event before changing it.
