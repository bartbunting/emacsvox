2 Getting Started: Installation and First Speech ¶

This chapter takes you from installation to a speaking Emacsvox session. Use a Debian package when available, or follow the source checkout route. Start an isolated session before changing your personal Emacs setup.

Commands shown before Emacsvox starts are entered in a terminal. Keys written with C- or M- are entered inside Emacs. The same chapter is available before installation at https://bartbunting.github.io/emacsvox/Installation.html.

2.1 Debian and Ubuntu package ¶

Debian packaging is new development work; Emacsvox 2026.9.2 predates it. Use a package from a release that includes one, or a locally built development package. Omnivox 1.10.0 includes an amd64 deb for supported Ubuntu systems.

With a downloaded Emacsvox deb, install it using apt: 

sudo apt install ./emacsvox_VERSION_all.deb
emacsvox --diagnose
emacsvox --check
emacsvox

Replace VERSION with the version in the downloaded filename. Apt requires a packaged Emacs 30.2 or newer; an installed terminal-only emacs-nox also satisfies this dependency. The package never builds GNU Emacs. If your distribution cannot provide a supported version, use the source installation route below, which offers an explicit Emacs 31 source build.

Omnivox 1.10.0 or newer is recommended. If it is unavailable from your apt repositories, include its downloaded deb in the same apt command, or select an existing installation. Confirm both tone and speech from emacsvox --check. For remote Emacs or WSL with an existing Windows speech server, use sudo apt install --no-install-recommends ./emacsvox_VERSION_all.deb. Remote sessions start with emacsvox --remote after the workstation service, token and tunnel are prepared as described in Installing On A Remote Linux Host. The package does not acquire a Windows speech runtime; the guided WSL source installer below handles that.

Emacsvox installs under /usr/share/emacsvox, with the command /usr/bin/emacsvox. It includes Lisp sources, sounds and offline manuals. No personal initialization is changed and ordinary Emacs sessions do not automatically start speaking. To enable Emacsvox in your own Emacs setup, add (load-file "/usr/share/emacsvox/lisp/emacsvox-setup.el") explicitly. Upgrade the system tree using apt; the source build instructions below apply to checkouts. Removing the package preserves personal settings and speech tokens. Package details are in /usr/share/doc/emacsvox/README.Debian.
