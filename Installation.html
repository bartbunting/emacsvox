1 Getting Started: Installation and First Speech ¶

This is the canonical first-use procedure for a source-checkout installation. It starts before Emacsvox is available, establishes an audible acceptance checkpoint, and delays personal configuration until an isolated session has spoken successfully. The same chapter is published for pre-installation web access at https://bartbunting.github.io/emacsvox/Installation.html.
