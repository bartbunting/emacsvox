11.8 Navigate and copy rendered tables ¶

Agent Shell gives rendered Markdown tables their own navigation commands. Moving into a table activates a contextual table map. It announces the table dimensions and current cell. Leaving the table restores the ordinary Agent Shell keys. Markdown and Org source buffers offer explicit table reading with matching logical operations; see Browsing Structure. Agent Shell retains its own table speech preferences and automatic contextual activation. Plain Left and Right, or C-b and C-f, move by character within the current cell. M-b and M-f, or Control-Left and Control-Right, move by word. These commands follow wrapped text within the same cell, skipping borders, padding, and neighbouring columns. At the beginning or end of the cell, they stop and announce the boundary. Use Control-Meta-Left and Control-Meta-Right to move between columns. Control-Meta-Up and Control-Meta-Down move between logical rows in the current column and read only the destination cell. Plain Up and Down make the same move and read the entire destination row. Wrapped cells are read in full, using your table title settings.

C-n and C-p retain ordinary line movement. They can move through wrapped cell text, but do not stay within the logical cell or skip other columns. Use character and word movement to follow the cell’s text in order.

Outside editable input, press t for the next table or T for the previous table. These keys skip the current table and announce the destination table and cell. Like the bracket navigation keys, they insert themselves in a live prompt or viewport editor, including while the agent is working.

11.8.1 Understand table key conflicts ¶

In viewport view mode, t takes the place of Agent Shell’s thought-level shortcut; use M-x agent-shell-viewport-set-session-thought-level for that action. Inside a table, r, c, and a read rows, read columns, and select the table speaking method. To invoke the displaced viewport actions there, use M-x agent-shell-viewport-reply, M-x agent-shell-viewport-reply-continue, or M-x agent-shell-viewport-reply-again. In the shell transcript, table r replaces quoting; use M-x agent-shell-quote-region with a selected region. Leaving the table restores these ordinary bindings.

Outside tables, C-M-<up> and C-M-<down> do nothing in Agent Shell, including its viewport and prompt editor. Repeating a row key after leaving a table therefore keeps point at the exit. These two keys also do nothing in ordinary shell-mode buffers. For structural movement there, use M-x backward-up-list or M-x down-list. Source-code buffers keep their usual bindings.

Continuous speech and response-block reading omit rendered table borders and keep the cell text. Decorative borders therefore do not force a switch to a different speech engine. Literal box-drawing characters in prose or code remain available to symbol naming and exact character inspection.

11.8.2 Table command reference ¶

t

Run emacsvox-agent-shell-next-table outside editable input.

T

Run emacsvox-agent-shell-previous-table outside editable input.

C-M-<right>

Run emacsvox-agent-shell-table-next-column.

C-M-<left>

Run emacsvox-agent-shell-table-previous-column.

<down>

Run emacsvox-agent-shell-table-next-row and read the destination row.

<up>

Run emacsvox-agent-shell-table-previous-row and read the destination row.

C-M-<down>

Run emacsvox-agent-shell-table-next-row-cell and read the destination cell.

C-M-<up>

Run emacsvox-agent-shell-table-previous-row-cell and read the destination cell.

M-<down>

Run emacsvox-agent-shell-table-exit-forward.

M-<up>

Run emacsvox-agent-shell-table-exit-backward.

SPC

Run emacsvox-agent-shell-table-speak-cell.

r

Run emacsvox-agent-shell-table-speak-row.

c

Run emacsvox-agent-shell-table-speak-column.

.

Run emacsvox-agent-shell-table-speak-context for row, column, and table position.

=

Run emacsvox-agent-shell-table-speak-dimensions.

w

Run emacsvox-agent-shell-table-copy-cell.

k k

Also run emacsvox-agent-shell-table-copy-cell.

k r

Run emacsvox-agent-shell-table-copy-row; copied cells are tab-separated.

k c

Run emacsvox-agent-shell-table-copy-column; copied cells are separated by newlines.

a

Run emacsvox-agent-shell-table-select-speaking-method to toggle column titles, row titles, or whether data is spoken before titles.

Copy commands use logical cell values, excluding renderer padding and Markdown borders. Wrapped cell contents remain complete.
