15.1 Reading reminders ¶

These commands apply to the selected buffer’s accessible text. In Info that means the current node, not the whole manual. Use the application’s own reader for a table, terminal or other specialised view.

Read from here (C-e i)

Read towards the accessible buffer end with tracked position. Requires a supporting speech server; point advances by chunks, and another command stops reading before performing its action. See Stopping and restarting tracked reading.

Stop current speech (C-e s)

Stop main and notification speech without disabling future feedback. During tracked reading this retains a chunk boundary, not an exact spoken word. See Where stopping leaves point.

Repeat the current line (C-e l)

Inspect the line without moving point. C-u C-e l reads from point to the line’s end. See Short reading and prefix variants.

Read or spell the word (C-e w)

Read the word at point; repeat at the same position to spell it. See Inspecting short passages.

Inspect the character (C-e c)

Read the character at point, using its phonetic name where available. Point does not move. See Character and word reading.

Read the paragraph (C-e [)

Read the paragraph around point without moving it. The mode determines its boundaries. Sentence reading is also available by name. See Sentence and paragraph inspection.

Read a checked selection (C-e r)

Read between point and mark. A short region read preserves its endpoints and activation; it does not establish a new selection for you. See Selecting and checking text.

Read the buffer (C-e b)

Read its accessible contents without tracked interruption position. Requests of 40,000 characters or more fall back to windowful reading at the current default limit, removing other windows. The same limit applies to region reading. See Buffer-reading limits and alternatives.

Page reading and the complete reading-key list remain under Reading and navigating. Page reading changes the mark; it is not a substitute for inspecting an existing selection.
