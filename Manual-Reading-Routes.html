2.2 Choose a reading route ¶

After Installation gives you speech, work through Learn the audio desktop for six progressive lessons using a disposable practice document. It teaches reading, editing, Help, structure, temporary settings, and voice previews, with exercises and separate answers. No additional engine is needed.

If Emacs itself is new to you, C-h t opens its separate interactive tutorial. Use it for more practice with general editing. Basic Usage, Using Online Help, and Audio Desktop are references to return to as you work.

If you already use Emacs, start with Basic Usage once speech works. Keep your usual editing and mode commands. The tutorial’s temporary-settings lesson and voice experiments provide guided practice without making its earlier editing lessons prerequisites for experienced users; prepare its disposable buffer before experimenting. Then read Aural Presentation for application meaning, voices, sounds, and settings, and choose an application guide for your work.

For independent everyday tasks, use Work with files and directories, Write a note with headings, or Web browsing with EWW. These guides explain real files and pages; they do not require completing the tutorial or changing your voice configuration.

For one question, use Find a task, Info’s index or a text search. For a familiar action whose key you cannot remember, use Everyday commands and key prefixes. When something is not working, Something is wrong starts with symptoms rather than the names of settings. Speech Backends contains alternative installation and backend configuration procedures; it is not required reading between your first speaking session and everyday editing. The final Developer Guide is for changing and maintaining Emacsvox, not for ordinary use.
