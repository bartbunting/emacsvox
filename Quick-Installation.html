5.2 First Speech Checklist ¶

  1. Select Emacs 31 or newer. If it is not the system emacs, copy local.mk.example to the ignored local.mk and set EMACS: 
    EMACS=/path/to/emacs-31/bin/emacs

    Verify the selection before diagnosing a compiler failure: 

    make check-emacs
  2. Configure and compile the checkout: 
    make all

    Do not compile Emacsvox with an older system Emacs. Tests prefer source and therefore do not prove that the byte-code used by a normal startup is current.

  3. Install the recommended Omnivox speech server. See Speech Backends, for the supported platform matrix, exact prerequisite classes, source and WSL2 build paths, and compatibility alternatives.
  4. Run the non-audible launcher preflight from the Emacsvox checkout: 
    ./bin/emacsvox --diagnose

    It validates the checkout, Emacs, and backend without playing audio, creating an Omnivox session log, or opening interactive Emacs. Before continuing, confirm that its report includes Emacs 31 or newer, the omnivox speech backend, and an isolated -Q startup. Correct any path or version error that it prints.

  5. Run the deliberately audible backend check: 
    ./bin/emacsvox --check

    The launcher prints its selections and explicitly announces that the audible check is starting. Continue only after hearing both the tone and speech. Do not diagnose Emacs configuration until this standalone Omnivox check passes.

  6. Prove a clean Emacsvox start: 
    ./bin/emacsvox

    The launcher defaults to Omnivox, uses the selected Emacs 31 or newer, and loads the setup source by its absolute path. The session uses -Q: it loads neither site files nor a personal Emacs init file. This makes first speech a reproducible installation proof rather than a side effect of existing configuration.

    ./bin/emacsvox --diagnose prints the selected root, setup source, Emacs version, and backend without playing audio or starting interactive Emacs. ./bin/emacsvox --help documents explicit EMACS, TTS_PROGRAM, and EMACSVOX_DIR overrides. Arguments after -- are passed to Emacs.
