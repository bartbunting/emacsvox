6.10.1 Walkthrough: Switch Reading And Working Setups ¶

This example saves two profiles with different voice or sound selections. Use unused names and note the profile selected before starting.

  1. Open C-e H P. If you want a restore point for the current selected options and resources, press N and save before-demo with a short purpose. This captures those selections and makes the new profile selected. It does not back up rules, resource definitions, or engine settings.
  2. From Home, activate the voice palette and sound pack you want for reading. Enable any desired Presentation Options and choose spatial settings. Return to Profiles and press N to save reading-setup-demo.
  3. Choose a different palette or sound pack for working, then save another new profile named working-setup-demo. Both profiles should show their selected resources in the list. RET describes a profile’s saved fields.
  4. Select reading-setup-demo and press a to apply it. Check the active palette and sound pack in Home, then repeat familiar feedback. Select working-setup-demo and apply it to compare the two setups.
  5. Change one live option without updating the profile. The selected profile now reports Diverged. Press a on it to restore its saved settings, or w if you intend to replace its saved values with the current ones. Read the confirmation before discarding live differences.
  6. Applying a profile also saves its selection for future sessions. Finish on the profile you want at startup. To restore the earlier setup, apply the original profile or before-demo. Delete unwanted demonstration profiles with d only after selecting the one you want to retain.

If both profiles select reading-demo, later edits to that palette affect both profiles. For independently adjustable voices, first use Copy Palette and select different palettes in the two profiles. A profile’s Copy action copies selections, not the selected resources. To change only the startup palette while preserving the profile’s other saved fields, use U in Voice Palettes instead of capturing all current settings again.
