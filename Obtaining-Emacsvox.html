2.1 Before You Begin ¶

Install git so you can obtain the Emacsvox checkout. Emacsvox requires Emacs 31 or newer, but WSL2 users do not need to find a separate Emacs package before beginning. The guided installer below uses an existing supported Emacs or builds the pinned stable release for the current user.

On GNU/Linux and macOS, install Emacs 31 or newer and make. Omnivox 1.6.4 or newer is the supported speech-server baseline. Installing its release archive also requires curl and either sha256sum on GNU/Linux or shasum on macOS, plus tar. GNU Texinfo is needed only when building or editing the documentation, not for an ordinary installation.

To check the Emacs found by your shell, run: 

emacs --version

The first line should begin with GNU Emacs 31 or a higher version number. If the command is not found or reports an older version, install a supported Emacs or locate its executable. You can check a specific executable in the same way: 

/path/to/emacs-31/bin/emacs --version

The Linux x86-64 archive requires an Ubuntu 24.04-compatible glibc, libstdc++, libgcc, and ALSA runtime. If the archive does not match the host, the Omnivox source route requires Rust, Python 3, a C and C++ toolchain, CMake, and Clang with libclang. It additionally requires pkg-config and ALSA development headers on GNU/Linux or the Xcode command-line tools on macOS. These are not requirements for the recommended WSL2 binary route. Docker and Windows .NET Framework are needed only for the advanced reproducible source-build route in Building Omnivox For WSL2.

Choose a permanent parent directory and clone Emacsvox: 

cd /path/where/you/keep/source
git clone https://github.com/bartbunting/emacsvox

The Emacsvox checkout is the installation directory. It builds in place and does not create a second tree to copy elsewhere. Clone Omnivox beside it only when following the Omnivox source-build or reproducible WSL2 build route.

Under WSL2, first ask the guided installer to inspect the machine without changing it: 

cd /path/where/you/keep/source/emacsvox
./bin/emacsvox-wsl-install --check

The report names the Emacs it will use, the matching Omnivox Windows archive, and the per-user installation paths. If Emacs build packages are missing, it prints one apt command for you to review and run. The installer never invokes sudo itself. After resolving any reported prerequisite, run: 

./bin/emacsvox-wsl-install

It builds the pinned stable Emacs only when Emacs 31 or newer is unavailable, downloads and verifies the matching Omnivox 1.6.4 Windows archive, records its path without editing a shell startup file, compiles Emacsvox, runs a diagnostic, and plays the final speech-server check. The Emacs build can take a while on a fresh machine; later runs reuse it and the verified downloads. Routine compiler output is kept below $XDG_CACHE_HOME/emacsvox/logs, normally ~/.cache/emacsvox/logs. If a build fails, the installer shows its final log lines and the complete log path. Continue only after hearing both the final tone and speech. You can then skip to the last step in Build And Start Emacsvox and start Emacsvox.
