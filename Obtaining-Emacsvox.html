2.1 Before You Begin ¶

Install git, make, GNU Texinfo (which provides makeinfo), and Emacs 31 or newer. The recommended Omnivox speech server also needs the Rust toolchain, Python 3, a C and C++ toolchain, CMake, and Clang with libclang.

To check the Emacs found by your shell, run: 

emacs --version

The first line should begin with GNU Emacs 31 or a higher version number. If the command is not found or reports an older version, install a supported Emacs or locate its executable. You can check a specific executable in the same way: 

/path/to/emacs-31/bin/emacs --version

On GNU/Linux, install pkg-config and the ALSA development headers. On macOS, install the Xcode command-line tools. WSL2 has additional Docker and Windows requirements described in Building Omnivox For WSL2.

Choose a permanent parent directory and clone Emacsvox and Omnivox beside one another: 

cd /path/where/you/keep/source
git clone https://github.com/bartbunting/emacsvox
git clone https://github.com/bartbunting/omnivox

The Emacsvox checkout is the installation directory. It builds in place and does not create a second tree to copy elsewhere.
