1.1 Obtaining Emacsvox ¶

Before beginning, install git, make, GNU Texinfo (which provides makeinfo), and Emacs 31 or newer. The Speech Backends chapter lists the additional platform prerequisites for the recommended Omnivox server.

The maintained source is https://github.com/bartbunting/emacsvox. Clone it into the permanent directory where it will be used: 

git clone https://github.com/bartbunting/emacsvox
cd emacsvox

The checkout itself is the source-checkout installation. The build operates in place; it does not create a second directory to copy elsewhere.
