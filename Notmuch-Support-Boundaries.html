10.7 Know the support boundaries ¶

Hello

Widget navigation, view lifecycle, and searches have Notmuch-specific feedback.

Search

Results, asynchronous lifecycle, tags, archiving, opening, and configured detail inspection have Notmuch-specific feedback.

Show

Messages, MIME parts, pages, visibility, tags, archiving, and explicit inspection have Notmuch-specific feedback.

Tree

Receives emacsvox-aural-module context only. Core speech can operate, but this module has no Tree-specific row formatter, navigation, mutation, visibility, or asynchronous lifecycle.

Composition

Standard Message mode owns composition. Speech after new-mail, reply, forward, or resume transitions belongs to emacsvox-message, not the Notmuch integration.

There is no independent Notmuch speech-disable or unload command. Its advice, hooks, and Search arrow bindings remain installed for the Emacs session after loading. Repeated loading is idempotent and does not duplicate them.
