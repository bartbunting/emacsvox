3.3 Emacsvox Overview ¶

Emacsvox adds spoken feedback to Emacs editing and to applications that run inside Emacs. Movement speaks the corresponding character, word, line, or larger unit. Commands announce useful results and state changes, while application integrations present structures such as messages, search results, tables, source code, and Web pages.

Voice Lock uses changes in speech characteristics to make text structure audible. For example, comments, quoted strings, reserved words, headings, and links can sound different without an explanation being inserted into the text. See Hear Structure With Voice Lock for configuration and Web Browsing With EWW for a task-oriented example in EWW.

Pronunciation dictionaries let you adjust how a name, technical term, or programming-language word is spoken. A dictionary can apply everywhere or only in a particular mode or file; see emacsvox-pronounce in Emacsvox Reference Manual.

Short auditory icons and tones mark events such as opening or deleting a file, finishing an action, receiving mail, or displaying completions. They supplement speech and become especially useful as familiar events no longer need a full spoken explanation. See emacsvox-sounds in Emacsvox Reference Manual for the available sound support.
