3.3 Emacsvox Overview ¶

Emacsvox adds spoken feedback to Emacs editing and to applications that run inside Emacs. Movement speaks the corresponding character, word, line, or larger unit. Commands announce useful results and state changes, while application integrations present structures such as messages, search results, tables, source code, and Web pages.

Changes in voice, short auditory icons, and tones make structure and familiar events recognizable without inserting extra words. Pronunciation dictionaries can also correct names and technical terms globally or for one mode or file. You do not need to configure these systems before beginning; first notice what the active mode presents automatically.

For an everyday Voice Lock experiment, see Hear Structure With Voice Lock. When you want to understand or change voices, sounds, pronunciation, or other presentation choices, continue with Aural Presentation: Speech, Voices, And Sound. The generated reference remains the exact inventory of their commands and options.
