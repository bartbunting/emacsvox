2 Using this manual ¶

You can read the early chapters in sequence or use this manual to answer a question while working. Find a task links everyday goals to their detailed instructions. Terms used in this manual explains names such as palette, profile, scope, and draft without requiring you to study the whole settings system first.

Start with Read the key instructions if Emacs notation is unfamiliar. It explains which keys to hold together, when to release them, and how to enter a command by name. The reading routes below assume that notation, not prior experience with Emacs.

  • Answer a prompt and return to your work
  • Choose a reading route
  • Find an answer in Info and return
  • Recognise the document you are reading
