13.3 Automatic Speech Feedback ¶

emacsvox-eterm-autospeak controls automatic feedback in the current buffer and defaults to enabled. C-t C-q toggles it. The older spelling eterm-autospeak is not an Emacsvox variable.

A Term buffer must be displayed in a live window for automatic output speech. A hidden buffer can keep running silently. This displayed-window condition is not EAT’s selected-buffer and keyboard-focus policy.

In line mode, speech reads newly inserted output as a range rather than interrupting it for every character. In character mode, rendered cursor and screen changes determine whether a character, word, movement, or reached line is presented. New terminal activity can stop earlier speech.

This integration does not provide EAT’s bounded screen transactions, completion model, or alternate-screen policy. When a redraw is ambiguous or an announcement too brief, use the explicit review commands.
