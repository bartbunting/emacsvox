6.5.2 Walkthrough: Inheritance, Aliases, And Reset ¶

Use reading-demo from the previous example, or another personal palette with acss-default as its parent.

  1. In the palette manager, create reading-child-demo with N and choose reading-demo as its parent. The chain is now reading-child-demo -> reading-demo -> acss-default.
  2. Enter the child and inspect bolden’s Source. If reading-demo has a direct bolden entry, it supplies the child’s whole entry. Otherwise acss-default supplies it. O opens the supplying palette; u shows Where Used, including known references, aliases, and affected descendants.
  3. The alias voice-bolden refers to the same named voice as bolden. It is an alternative spelling used by integrations, not another entry with independent settings. You do not create or edit aliases in this view.
  4. Return to the child palette and copy bolden with c. Give the copy an unused name such as reading-heading-demo. Change its pitch, compare it, and choose Save to collection without selecting. You now have a separate named entry. A rule must select this new name before ordinary content uses it; copying alone does not remap headings.
  5. For a Reset experiment, edit the child’s inherited bolden, change one field, and save to the collection. Its Source becomes the child. Back in the voice list, press R on bolden. The confirmation names the parent entry that will take over. After confirming, bolden remains in the list and Source returns to that provider.
  6. To remove the custom copy, select reading-heading-demo and press d. This deletes it if there is no inherited replacement or known use. If you assigned it to a rule, remove or remap that rule first. Reset is for a local entry with an inherited replacement; Delete is for a removable custom name.

The standard root ensures standard voices remain available after Reset. It cannot be deleted or edited here. A palette can contain additional custom names; the standard list grows when loaded integrations register voices. Copy Palette is different from New Palette: it copies all current effective entries and stops following edits to the source palette, while still inheriting new standard names from acss-default. Definitions referring to an existing personality still use that personality’s settings. A copy is not a recording of its sound.
