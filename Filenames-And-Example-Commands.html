2.1.1 Interpret filenames and examples ¶

A path identifies a file’s location as well as its name. A file prompt often starts with a directory already filled in. Append a filename to use that directory, or replace the editable answer with a complete path. In an ordinary file minibuffer, C-a C-k removes the current editable answer: Control-a goes to its beginning and Control-k removes the text that follows. This edits the answer, not a file. Then type the intended path and press RET.

Like other kill commands, C-k also puts the removed text in the kill ring. If you intended to paste a previously copied path, clearing the prompt this way can change the next paste. Type the intended path here, or use Choose text copied earlier to retrieve the right entry.

The examples use ~/ for the home directory understood by the running Emacs. For example, ~/evox-notes.org names evox-notes.org in that home directory. In WSL this normally means the Linux home, not Windows Documents. A Windows C-drive path is normally reached through /mnt/c/ in WSL; native Windows Emacs uses its own Windows paths. Use a directory that exists and is writable in the environment running Emacs. A speech server running on another host does not change where ordinary Emacs document files are stored.

A relative name is resolved against the directory in the prompt, which may change with the selected buffer. Do not assume it means the repository root or the folder used in an earlier task. When an instruction says "from the checkout", it explicitly means that source directory. Replace placeholders such as /path/to/document.txt with real names; do not create those directories merely to copy the example literally. In Emacs file prompts, type spaces in names normally rather than adding shell quotes around the whole path.

Keyboard sequences invoke Emacs commands. A shell example belongs at a shell or terminal prompt in the environment named by the instructions, not after M-x. Lisp configuration belongs in the specified Emacs configuration file; it is not ordinary document text or a shell command. A displayed command’s output is something to check, not another command to enter. Read the sentence introducing each example to establish which of these contexts it uses.

When practising, choose unused names. If a proposed name already contains work, cancel and substitute another name consistently. An overwrite warning is not a routine confirmation to accept. Opening, copying, saving and deleting have different effects; the following task guides explain the effect before the step.
