5.4 Using Emacs Buffers ¶

Much editing feedback is automatic. Echo settings can speak each character or each completed word. Completion announces candidates, inserted completion, and the selected item. Prompts and error messages are also spoken.

Other information is requested explicitly:

  • Reading commands speak a character, word, line, region or larger unit. Most inspections preserve point; tracked rest-of-buffer reading advances it. Names usually begin with emacsvox-speak- and default keys use C-e.1
  • Speech-system commands adjust rate, punctuation, echo, and related controls. Many use C-e d and names beginning tts-.2
  • Help commands explain the active modes, bindings, and integrations.

The settings menus provide discoverable routes to these controls; the direct keys remain useful for frequent actions. C-e S opens focused settings for the current integration, or general buffer settings when no focused menu exists. C-e H . always opens general buffer settings.

Buffers remain available as you change tasks. C-e n and C-e p cycle among buffers with the same major mode; repeat with n or p. See Audio Desktop for buffer selection and its other navigation controls.

(1)

The prefix comes from Emacspeak, where C-e was mnemonic for the project name.
