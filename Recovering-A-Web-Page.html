9.5.4 Recover a cluttered or incomplete page ¶

In a page buffer, lowercase s runs EWW’s readable-view command. It tries to isolate the main text; it is not the same action as s inside the focused settings menu. To return from the filtered view, run M-x emacsvox-eww-restore RET. This restores the retained canonical view rather than changing the site. The command is also on DEL, but its name avoids differences in how keyboards report Backspace and Delete.

If the retained view is unavailable or you need fresh content, g reloads the current address. Reloading makes a new request and can lose form input or change the page and reading position. Save needed notes and finish or abandon forms deliberately before reloading. Search for a known phrase afterwards rather than assuming the old screen position still identifies the passage.

For content that requires JavaScript or another unsupported browser feature, use M-x eww-browse-with-external-browser RET to hand the page to the configured external browser. The external browser and any screen reader then provide its controls; Emacsvox’s EWW keys do not operate there. Browser configuration, login state and downloaded-content handling can differ. A failed or inaccessible website is not in itself a reason to change speech engines or reset voices.

For speech preferences, open C-e S from EWW. In that focused menu, s toggles section-navigation autospeak and i changes image suppression for subsequent rendering. The latter also changes the shared SHR image default while preserving buffer-local overrides; it does not reload the current page. Lowercase w saves those two Emacsvox defaults, A opens advanced settings, and q returns. These are presentation choices, not EWW’s site or account preferences. Returning does not undo changes you have already made.

The Emacs/W3 and w3m survey is historical. Do not install either on the strength of the Heritage manual; use EWW unless a separately maintained integration says otherwise. The GNU Emacs Manual’s EWW entry provides its general introduction.
