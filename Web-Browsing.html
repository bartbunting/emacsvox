8.4 Web Browsing With EWW ¶

EWW is the built-in browser supported for current Emacsvox. Run M-x eww RET, enter a URL or search words, and press RET. Emacsvox speaks EWW navigation and rendering feedback and adds commands for moving by HTML structure and filtering the displayed DOM. In an EWW buffer, use C-h m for the live workflow and C-h b for its effective keys. See EWW in The GNU Emacs Manual for browser operation and emacsvox-eww in Emacsvox Reference Manual for the speech integration.

The former Emacs/W3 and w3m survey is historical. Do not install either one on the strength of the Heritage manual; use EWW unless a separately maintained integration says otherwise.
