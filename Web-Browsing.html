9.5 Web Browsing With EWW ¶

EWW is Emacs’s built-in text-oriented web browser. Emacsvox adds speech and navigation using the page’s HTML structure. These commands act on the rendered page, not on the manual you are reading now. Start with a speaking session and use a public page for practice; a site requiring JavaScript may need your ordinary external browser instead.

The keys below include Emacsvox’s EWW bindings, which differ from unmodified EWW. In particular, lowercase b moves to the previous link, lowercase s requests a readable view, and ? is not the settings menu’s Help key. Use C-h m or C-h k to inspect the running buffer. Help can select its own buffer and remove other windows. Return to the page with C-x b and check its name with C-e m before using the browser keys below. The upstream EWW guide and emacsvox-eww reference cover the rest of the interface.

  • Read by heading, paragraph or search
