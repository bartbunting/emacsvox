15.118.1.1 emacsvox-annotate-add-annotation ¶

Command: emacsvox-annotate-add-annotation (&optional reset) ¶
Add annotation to the annotation working buffer.
Prompt for annotation buffer if not already set.
Interactive prefix arg ‘reset’ prompts for the annotation
buffer even if one is already set.
Annotation is entered in a temporary buffer and the
annotation is inserted into the working buffer when complete.

(fn &optional RESET)

15.118.1.2 emacsvox-clipfile-copy ¶

Command: emacsvox-clipfile-copy (start end &optional prompt) ¶
C-e C-M-c ¶
Use file-based Emacsvox Clipboard —
dis a convenient way of sharing information between independent
Emacsvox sessions running on  different machines.

(fn START END &optional PROMPT)

15.118.2 emacsvox-extras Options ¶

Variable: User Option emacsvox-clipfile-file ¶
File used to save Emacsvox clipboard.
The emacsvox clipboard provides a convenient mechanism for exchanging
information between different Emacs sessions.

Default Value: 

"~/.emacsvox/clipboard"
Variable: User Option emacsvox-curl-cookie-store ¶
Cookie store used by Curl.

Default Value: 

"~/.curl-cookies"
