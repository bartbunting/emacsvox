8.5.3 Remap One Item At Point ¶

  1. Move to a representative object and press C-e E to identify what controls it. Return to the source with q before starting a new action.
  2. Press C-e H f v to choose a voice for matching items. To tune the named voice already used there instead, use C-e H f t. Tuning changes that voice wherever the palette entry is used; remapping changes which voice a face or item receives. For a shell prompt, you can assign a different voice to the prompt face or tune the current prompt voice. It need not have been spoken before you begin.

    In the remapping editor, move with n~/~p or arrows. RET on Voice chooses a voice, Preview original plays the captured item, and Preview change plays the draft. O~/~P provide the same previews; S stops. Previewing does not save or retune the named voice. Use C-e H f e for an exact earcon remap.

  3. Choose How long: personal persists across Emacs sessions, session lasts until Emacs exits, and buffer affects only the captured live buffer.
  4. Review Applies to, Voice, and How long, then Save or w. A face mapping affects matching uses within its module/mode and lifetime. Advanced opens the full editor for finer criteria. At the top, q hides the compact editor and retains its draft. After a voice has been chosen, C-e H p d resumes it directly in the original editor.
  5. Return to the source, repeat the action, and press C-e E to confirm which rule wins.
