2.2 Install And Check Omnivox ¶

On GNU/Linux or macOS, build and install Omnivox from its checkout: 

cd /path/where/you/keep/source/omnivox
make build
make install
omnivox --check

make install normally places the executable below ~/.cargo/bin. Make sure that directory is on PATH before running the check. No proprietary speech runtime is needed for the recommended GNU/Linux or macOS route.

Under WSL2, build the staged Windows runtime from a clean Emacsvox checkout: 

cd /path/where/you/keep/source/emacsvox
make windows-omnivox
./servers/omnivox --check

The check plays a tone followed by speech. When you hear both, the speech server is ready. If either is missing, use Backend Diagnostics And Responsibilities before continuing. See Speech Backends contains the complete platform matrix, build details, and compatibility alternatives. Native Windows Emacs support remains a preview; consult that matrix before choosing it for a first installation.
