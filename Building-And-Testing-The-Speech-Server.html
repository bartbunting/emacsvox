5.6 Building And Testing The Speech Server ¶

Speech-server launchers live in servers/. Build them through the repository-root targets above so the selected paths and staging rules remain consistent.

The Omnivox smoke test and its audible success condition are in Selecting And Checking Omnivox. The following protocol-level test is only for retained direct Tcl-compatible servers. Run one of those launchers from the repository root, for example: 

./servers/espeak

Then enter: 

q {This is a test.}
d
s

The q command queues text, d dispatches it, and s stops speech. Type C-d to close the server. Backend-specific READMEs may provide stronger diagnostics and should take precedence over this generic smoke test.

From Emacs, use M-x tts-speak-version to verify the selected adapter and M-x tts-restart after changing server configuration. Omnivox also records per-process diagnostic logs below $XDG_STATE_HOME/emacsvox/omnivox, defaulting to ~/.local/state/emacsvox/omnivox; spoken text is omitted unless explicit text logging is enabled.
