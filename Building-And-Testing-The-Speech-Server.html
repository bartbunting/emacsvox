3.5 Install And Check Omnivox ¶

If the guided WSL2 installer succeeded, Omnivox is already installed and checked. Continue to Quick Installation.

On macOS, follow the Homebrew instructions in Installing An Omnivox Release Binary. They install the matching Mac binary and record its stable executable path for Emacsvox, including sessions that do not inherit the shell’s PATH. Homebrew installs Omnivox only; continue below to build and start Emacsvox with your selected Emacs 30.2 or newer.

On a matching GNU/Linux x86-64 host, or for a manual Mac installation, use the archive instructions in that section. They verify the published 1.18.0 archive, keep its runtime data beside the executable, and add its versioned installation directory to PATH. Then run: 

omnivox --check

Use Installing Omnivox From Source on Linux ARM64, an incompatible distribution, or a host whose security policy does not permit the unsigned macOS archive. No proprietary speech runtime is needed for the GNU/Linux or macOS routes. For a manual WSL2 installation, or details of what its guided installer checks, see Installing An Omnivox Windows Release Under WSL2.

The check plays a tone followed by speech. Hearing both is the acceptance condition; a successful exit code alone does not prove audible output. If either is missing, follow Backend Diagnostics And Responsibilities before continuing.

  • When the binary does not match the host

3.5.1 When the binary does not match the host ¶

The Linux x86-64 archive requires an Ubuntu 24.04-compatible glibc, libstdc++, libgcc, and ALSA runtime. The Omnivox source route requires Rust, Python 3, a C and C++ toolchain, CMake, and Clang with libclang. It also requires pkg-config and ALSA development headers on GNU/Linux, or Xcode command-line tools on macOS. These are not requirements for the recommended WSL2 binary route. Docker and Windows .NET Framework are needed only for the advanced reproducible source-build route in Building Omnivox For WSL2.

Speech Backends owns the complete platform matrix, alternative builds, and compatibility servers. Native Windows x64 is supported with Emacs 30.2 or newer; its PowerShell installer reuses a prebuilt Emacs, can download a verified Emacs with -DownloadEmacs, or offers an explicit source build. It installs Omnivox without WSL; follow Installing Native Windows Emacsvox.
