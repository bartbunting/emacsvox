15.5 Speech and settings ¶

These routes use the current settings interface. A live adjustment, a saved default and a retained draft are distinct; follow the linked scope and saving instructions before making a persistent change.

Open speech controls (C-e H s)

Browse rate, punctuation and related controls for the captured context. Inspect the displayed scope; global defaults need not override local values. See Speech controls and scope.

Open settings for this task (C-e S)

Use the integration’s focused menu when available, otherwise general buffer settings. C-e H . always opens the latter. See Finding the appropriate settings menu.

Find a setting (C-e H /)

Choose a matching name; accepting the search selects its control without changing the value. Activate it separately. See Settings search and action search.

Explain this item’s feedback (C-e E)

Inspect the presentation chosen for the object at point. The report is not itself a repair. See Understanding voices, sounds and rules.

In an Emacsvox settings menu, q goes back and C-q closes the sequence. In an ordinary unfinished prompt, C-g cancels. None of these reverses an already applied change. Editors, tables and terminals have their own return commands; see Returning from settings and Recovering an unfinished edit.
