6.10.3 Export, Back Up, And Import Palettes ¶

For sharing, w exports effective portable entries and asks before omitting machine-local physical choices. W creates a full local backup containing the palette’s ancestry and referenced local choices. Import with i accepts either file and creates an independent personal palette under an unused name; it does not replace the original ancestry tree or activate the imported palette. Missing installed voices are reported and retained for later replacement. A partial import keeps its proposal available for Retry or Discard.

For example, select reading-demo in Voice Palettes and press w to export a portable file. Review any omitted local choices. Import that file with i under an unused name such as reading-import-demo. Enter the imported palette and preview its voices before activating it. A retained unavailable choice is a request to review, not evidence of successful audio. Delete the imported copy when finished if no profiles, children, or rules need it. The original palette is unchanged by this trial.

Use uppercase W when the aim is to retain exact local choice data with the required palette ancestry. Importing that backup still creates a new, independent palette; it does not overwrite the original tree. Neither form contains speech engines or sound-pack audio, and a palette backup is not a backup of every Emacsvox setting.
