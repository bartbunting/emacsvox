2.42 emacsvox-aural-schemes ¶

Register and inherit internal declarative rule sets, combine module, Presentation Option, personal, session, and buffer layers, preserve legacy personality hints, and persist user data without evaluating it. Public configuration no longer exposes a selectable scheme layer; historical scheme names remain in the data model and compatibility filename.

2.42.1 emacsvox-aural-schemes Options ¶

Variable: User Option emacsvox-aural-schemes-file ¶
Data-only file containing personal aural presentation settings.

Default Value: 

"~/.emacsvox/aural-schemes.el"
