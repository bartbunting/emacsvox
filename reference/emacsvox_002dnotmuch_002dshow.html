2.225 emacsvox-notmuch-show ¶

Notmuch message and attachment reading. Load through ‘emacsvox-notmuch’. The facade owns activation.

  • Emacsvox-Notmuch-Show Commands

2.225.1 Emacsvox-Notmuch-Show Commands ¶

  • emacsvox-notmuch-speak-show-message
  • emacsvox-notmuch-speak-show-position

2.225.1.1 emacsvox-notmuch-speak-show-message ¶

Command: emacsvox-notmuch-speak-show-message (&optional message body-line) ¶
Speak Notmuch MESSAGE, defaulting to the message at point.
When BODY-LINE is non-nil, speak it after the semantic message summary.

(fn &optional MESSAGE BODY-LINE)

2.225.1.2 emacsvox-notmuch-speak-show-position ¶

Command: emacsvox-notmuch-speak-show-position ¶
Speak thread position and complete details for the current Show item.
