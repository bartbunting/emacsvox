2.185 emacsvox-omnivox-components ¶

Spoken front end to the pinned, verified WSL2 Omnivox component manager. Proprietary runtimes and voice models remain user supplied.

2.185.1.1 emacsvox-omnivox-components-activate ¶

Command: emacsvox-omnivox-components-activate ¶
Install an available module, or test any other selected engine.

2.185.1.2 emacsvox-omnivox-components-help ¶

Command: emacsvox-omnivox-components-help ¶
Display and speak Omnivox engine-module manager help.

2.185.1.3 emacsvox-omnivox-components-install ¶

Command: emacsvox-omnivox-components-install ¶
Download, verify, and install the selected optional engine module.

2.185.1.4 emacsvox-omnivox-components-mode ¶

Command: emacsvox-omnivox-components-mode ¶
Spoken manager for verified Omnivox engine modules.

In addition to any hooks its parent mode
‘emacsvox-aural-tabulated-mode’ might have run, this mode runs the
hook ‘emacsvox-omnivox-components-mode-hook’, as the final or
penultimate step during initialization.

Key             Binding
——————————————————————————-
RET		emacsvox-omnivox-components-activate
?		emacsvox-omnivox-components-help
h		emacsvox-aural
i		emacsvox-omnivox-components-install
t		emacsvox-omnivox-components-test
u		emacsvox-omnivox-components-uninstall

2.185.1.5 emacsvox-omnivox-components-refresh ¶

Command: emacsvox-omnivox-components-refresh (&optional id) ¶

(fn &optional ID)

2.185.1.6 emacsvox-omnivox-components-speak-current ¶

Command: emacsvox-omnivox-components-speak-current ¶
Speak the complete Omnivox component row at point.

2.185.1.7 emacsvox-omnivox-components-test ¶

Command: emacsvox-omnivox-components-test ¶
Ask Omnivox to list voices through the selected engine.

2.185.1.8 emacsvox-omnivox-components-uninstall ¶

Command: emacsvox-omnivox-components-uninstall ¶
Confirm and uninstall the selected manager-installed engine module.

2.185.1.9 emacsvox-omnivox-manage-components ¶

Command: emacsvox-omnivox-manage-components ¶
Open the accessible Omnivox engine-module manager.

2.185.2 emacsvox-omnivox-components Options ¶

Variable: User Option emacsvox-omnivox-component-installer ¶
Program that lists, installs, uninstalls, and tests Omnivox modules.

Default Value: 

"<emacsvox-root>/bin/emacsvox-omnivox-components"
Variable: User Option emacsvox-omnivox-restart-after-component-install ¶
Whether to restart running Omnivox after a managed module change.

Default Value: 

t
