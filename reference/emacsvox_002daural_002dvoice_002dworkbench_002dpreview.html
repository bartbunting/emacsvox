2.85 emacsvox-aural-voice-workbench-preview ¶

Voice workbench preview and comparison. Load through ‘emacsvox-aural-voice-workbench’.

  • Emacsvox-Aural-Voice-Workbench-Preview Commands
  • emacsvox-aural-voice-workbench-preview Options

2.85.1 Emacsvox-Aural-Voice-Workbench-Preview Commands ¶

  • emacsvox-aural-voice-workbench-compare
  • emacsvox-aural-voice-workbench-edit-preview-text
  • emacsvox-aural-voice-workbench-preview
  • emacsvox-aural-voice-workbench-preview-all
  • emacsvox-aural-voice-workbench-stop-preview

2.85.1.1 emacsvox-aural-voice-workbench-compare ¶

Command: emacsvox-aural-voice-workbench-compare ¶
Compare the selected physical voice with another matching voice.

2.85.1.2 emacsvox-aural-voice-workbench-edit-preview-text ¶

Command: emacsvox-aural-voice-workbench-edit-preview-text ¶
Edit the common Voice Workbench comparison text.

2.85.1.3 emacsvox-aural-voice-workbench-preview ¶

Command: emacsvox-aural-voice-workbench-preview ¶
Preview the selected voice, identifying physical samples by name.

2.85.1.4 emacsvox-aural-voice-workbench-preview-all ¶

Command: emacsvox-aural-voice-workbench-preview-all ¶
Preview usable matching voices in displayed order, identifying each sample.

2.85.1.5 emacsvox-aural-voice-workbench-stop-preview ¶

Command: emacsvox-aural-voice-workbench-stop-preview ¶
Stop the active preview immediately.

2.85.2 emacsvox-aural-voice-workbench-preview Options ¶

Variable: User Option emacsvox-aural-voice-workbench-preview-text ¶
Common text used for Voice Workbench preview and A/B comparison.

Default Value: 

"The quick brown fox jumps over the lazy dog."
