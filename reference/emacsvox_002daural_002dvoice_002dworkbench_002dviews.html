2.87 emacsvox-aural-voice-workbench-views ¶

Row descriptions, columns, filtering and language trees for Voice Workbench. These helpers use the current workbench’s captured inventory and draft. They own derived display rows and language expansion, while the main module owns editing, asynchronous observations, preview and save/apply operations. Load through ‘emacsvox-aural-voice-workbench’.
