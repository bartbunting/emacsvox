2.120 emacsvox-feeds ¶

This module provides Feeds support for Emacsvox required modules

  • Emacsvox-Feeds Commands
  • emacsvox-feeds Options

  • emacsvox-feeds-add-feed

2.120.1.1 emacsvox-feeds-add-feed ¶

Command: emacsvox-feeds-add-feed (title url type) ¶
C-e M-u ¶
Add specified feed to our feed store.

(fn TITLE URL TYPE)

2.120.1.2 emacsvox-feeds-archive-feeds ¶

Command: emacsvox-feeds-archive-feeds ¶
Archive list of subscribed fees to personal resource directory.
Archiving is useful when synchronizing feeds across multiple machines.

2.120.1.3 emacsvox-feeds-atom-display ¶

Command: emacsvox-feeds-atom-display (feed-url) ¶
C-, a ¶
C-x @ a a ¶
Display ATOM feed.

(fn FEED-URL)

2.120.1.4 emacsvox-feeds-browse ¶

Command: emacsvox-feeds-browse (feed) ¶
C-e C-u ¶
Browse   feed.

(fn FEED)

2.120.1.5 emacsvox-feeds-delete-feed ¶

Command: emacsvox-feeds-delete-feed (title) ¶
Delete specified feed from our feed store.

(fn TITLE)

2.120.1.6 emacsvox-feeds-fastload-feeds ¶

Command: emacsvox-feeds-fastload-feeds ¶
Fast load list of feeds from archive.
This directly updates emacsvox-feeds from the archive, rather
than adding those entries to the current set of subscribed
feeds.

2.120.1.7 emacsvox-feeds-opml-display ¶

Command: emacsvox-feeds-opml-display (feed-url) ¶
C-e v o ¶
Display OPML feed.

(fn FEED-URL)

2.120.1.8 emacsvox-feeds-restore-feeds ¶

Command: emacsvox-feeds-restore-feeds ¶
Restore list of subscribed fees from  personal resource directory.
Archiving is useful when synchronizing feeds across multiple machines.

2.120.1.9 emacsvox-feeds-rss-display ¶

Command: emacsvox-feeds-rss-display (feed-url) ¶
C-, r ¶
C-x @ a r ¶
Display RSS feed.

(fn FEED-URL)

2.120.1.10 emacsvox-feeds-select-feed ¶

Command: emacsvox-feeds-select-feed (feed-type) ¶
Prompt for feed-type (Atom, RSS, OPML and open it.

(fn FEED-TYPE)

2.120.2 emacsvox-feeds Options ¶

Variable: User Option emacsvox-feeds ¶
Table of RSS/Atom feeds.
The feed list is persisted to file saved-feeds on exit.

Default Value: 

(("BBC Podcast Directory" "http://www.bbc.co.uk/podcasts.opml" opml)
 ("CNet Tech News" "http://feeds.feedburner.com/cnet/tcoc" rss)
 ("Wired News" "http://www.wired.com/news_drop/netcenter/netcenter.rdf" rss))
