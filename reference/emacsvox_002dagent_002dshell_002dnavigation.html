2.21 emacsvox-agent-shell-navigation ¶

Transcript locations, response summaries, semantic movement, fragment expansion and source-block interaction. Presentation supplies shared feedback, events owns asynchronous response observation, and motion owns visual movement and live-input policy. The facade retains activation. Repeat-key installation is explicit so the facade controls activation order. Load through ‘emacsvox-agent-shell’.

2.21.1.1 emacsvox-agent-shell-copy-source-block ¶

Command: emacsvox-agent-shell-copy-source-block ¶
Copy the rendered Markdown source block at point using agent-shell.

2.21.1.2 emacsvox-agent-shell-next-block-at-point ¶

Command: emacsvox-agent-shell-next-block-at-point ¶
Move to the next block matching the semantic block at point.
When invoked by ‘]’ at an editable prompt, insert that character instead.
