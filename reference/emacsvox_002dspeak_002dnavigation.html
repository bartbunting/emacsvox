2.281.1.1 emacsvox-beginning-or-end ¶

Command: emacsvox-beginning-or-end ¶
Move to start or end of buffer.

2.281.1.2 emacsvox-goto-percent ¶

Command: emacsvox-goto-percent (percent) ¶
C-e M-% ¶
Move to end  PERCENT of buffer like in View mode.
Display is centered at point.
Also set the mark at the position where point was.

(fn PERCENT)

2.281.1.3 emacsvox-mark-backward-mark ¶

Command: emacsvox-mark-backward-mark ¶
Cycle backward through the mark ring.
To cycle forward, use pop-to-mark-command bound to M-x pop-to-mark-command

2.281.1.4 emacsvox-selective-display ¶

Command: emacsvox-selective-display (&optional arg) ¶
C-e C-c ¶
Continuously adjust selective-display.
Use ‘,’ and ‘.’ to continuously decrease/increase ‘selective-display’.
 If not specified, ‘arg’ defaults to current-column.

(fn &optional ARG)

2.281.1.5 emacsvox-speak-continuously ¶

Command: emacsvox-speak-continuously ¶
C-e C-<return> ¶
Speak a buffer continuously.
First prompts using the minibuffer for the kind of action to
perform after speaking each chunk,   E.G.  speak a line at a time
etc.  Speaking commences at current buffer position.  Pressing
C-g breaks out, leaving point on last chunk that
was spoken.  Pressing SPC  continues to speak the buffer; any other
  key quits.

2.281.1.6 emacsvox-speak-current-column ¶

Command: emacsvox-speak-current-column ¶
C-e = ¶
Speak the current column.

2.281.1.7 emacsvox-speak-current-percentage ¶

Command: emacsvox-speak-current-percentage ¶
C-e % ¶
Announce the percentage into the current buffer.

2.281.1.8 emacsvox-speak-face-backward ¶

Command: emacsvox-speak-face-backward ¶
Property search for face at point see M-x text-property-search-backward

2.281.1.9 emacsvox-speak-face-browse ¶

Command: emacsvox-speak-face-browse ¶
C-e C-. ¶
Use C-f and C-b or left/right arrows to browse by current face.

2.281.1.10 emacsvox-speak-face-forward ¶

Command: emacsvox-speak-face-forward ¶
Property search for face — see M-x text-property-search-forward

2.281.1.11 emacsvox-speak-field ¶

Command: emacsvox-speak-field ¶
Speak the field at point, choosing the right-hand field at a boundary.
At the accessible buffer end, speak the final field.

2.281.1.12 emacsvox-speak-next-field ¶

Command: emacsvox-speak-next-field ¶
Move to and speak next field.
Signal a user error without moving if there is no next field.

2.281.1.13 emacsvox-speak-previous-field ¶

Command: emacsvox-speak-previous-field ¶
Move to previous field boundary and speak the field starting there.
Signal a user error without moving at the accessible buffer beginning.

2.281.1.14 emacsvox-speak-range ¶

Command: emacsvox-speak-range (&optional prop) ¶
Speak and return  range at point

(fn &optional PROP)

2.281.1.15 emacsvox-speak-skim-buffer ¶

Command: emacsvox-speak-skim-buffer ¶
Skim the current buffer  a paragraph at a time.
