2.235.1.6 emacsvox-table-reader-mode ¶

Command: emacsvox-table-reader-mode (&optional arg) ¶
C-e C-t C-r ¶
Read a Markdown or Org table in place with contextual navigation keys.

Use a Control-Meta arrow inside a table to enter reading and move, or use
the speech prefix followed by C-t C-r to toggle reading.  Up/Down read
logical rows, C-M-Left/Right read cells, and r/c read rows/columns.  TAB moves
right without editing and RET reads the cell.  q restores normal mode keys.
Leaving the table or editing its source also ends this context.  This mode
is independent of Markdown’s markup-stripping speech preference.

This is a minor mode.  If called interactively, toggle the
‘Emacsvox-Table-Reader mode’ mode.  If the prefix argument is positive,
enable the mode, and if it is zero or negative, disable the mode.

If called from Lisp, toggle the mode if ARG is ‘toggle’.  Enable the
mode if ARG is nil, omitted, or is a positive number.  Disable the mode
if ARG is a negative number.

To check whether the minor mode is enabled in the current buffer,
evaluate the variable ‘emacsvox-table-reader-mode’.

The mode’s hook is called both when the mode is enabled and when it is
disabled.

(fn &optional ARG)

2.235.2 emacsvox-table-reader Options ¶

Variable: User Option emacsvox-table-reader-data-position ¶
Whether table cell data precedes or follows its titles.

Default Value: 

first
Variable: User Option emacsvox-table-reader-mode-hook ¶
Hook run after entering or leaving ‘emacsvox-table-reader-mode’.
No problems result if this variable is not bound.
‘add-hook’ automatically binds it.  (This is true for all hook variables.)

Default Value: 

nil
Variable: User Option emacsvox-table-reader-titles ¶
Titles spoken with cells in the explicit table reader.
Agent Shell retains its own table speech preferences.

Default Value: 

(column)
