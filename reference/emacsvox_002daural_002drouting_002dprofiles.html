2.40 emacsvox-aural-routing-profiles ¶

Store physical-engine routing separately from portable ACSS voice palettes. Property selectors can travel between machines, exact native identifiers require explicit local scope, and session selectors are never persisted.

  • emacsvox-aural-routing-profiles Options

2.40.1 emacsvox-aural-routing-profiles Options ¶

Variable: User Option emacsvox-aural-routing-profiles-file ¶
Data-only file containing machine-local voice routing profiles.

This file is deliberately separate from portable voice palettes.  It may
contain explicitly local physical voice IDs and should not be synchronized
unless the user has reviewed those bindings.

Default Value: 

"~/.emacsvox/aural-routing-profiles.el"
