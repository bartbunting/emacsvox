2.237 emacsvox-vterm ¶

VTERM == vterm using native vterm library

  • Usage

2.237.1 Usage ¶

  • Turn on emacsvox-comint-autospeak for using the shell.
  • Turn off emacsvox-comint-autospeak when using full-screen ncurses apps like vi.
  • Use vterm-copy-mode to review the contents of the terminal — C-c C-t.
