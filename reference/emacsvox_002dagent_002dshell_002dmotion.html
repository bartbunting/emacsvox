2.20 emacsvox-agent-shell-motion ¶

Map rendered chat rows, labels, folds and padding to source positions. Keep visual movement, editable prompt boundaries and line speech together, including their dynamic context and buffer-local command hooks. Semantic block and source navigation remain in ‘emacsvox-agent-shell-navigation’. The facade retains advice installation and activation order. Load through ‘emacsvox-agent-shell’; loading definitions does not install command hooks.

2.20.1.1 emacsvox-agent-shell-browse ¶

Command: emacsvox-agent-shell-browse ¶
Return to Explicit browsing at point, preserving the live draft and undo.

2.20.1.2 emacsvox-agent-shell-edit-input ¶

Command: emacsvox-agent-shell-edit-input ¶
Activate inline input, preserving a draft and its current editing position.
From the transcript, move to the end of the live draft.  In Explicit mode,
‘C-c e’ returns to browsing without sending or discarding text.
