2.243 emacsvox-widget ¶

This module implements the necessary extensions to provide talking widgets.

required modules

  • Emacsvox-Widget Commands

2.243.1 Emacsvox-Widget Commands ¶

  • emacsvox-widget-browse-widget-interactively
  • emacsvox-widget-help
  • emacsvox-widget-summarize-parent
  • emacsvox-widget-summarize-widget-under-point
  • emacsvox-widget-update-from-minibuffer

2.243.1.1 emacsvox-widget-browse-widget-interactively ¶

Command: emacsvox-widget-browse-widget-interactively ¶
Allows you to browse a widget

2.243.1.2 emacsvox-widget-help ¶

Command: emacsvox-widget-help ¶
Speak help for widget under point.

2.243.1.3 emacsvox-widget-summarize-parent ¶

Command: emacsvox-widget-summarize-parent ¶
Summarize parent of widget at point.

2.243.1.4 emacsvox-widget-summarize-widget-under-point ¶

Command: emacsvox-widget-summarize-widget-under-point (&optional level) ¶
Summarize a widget if any under point.
Optional interactive prefix specifies how many levels to go up from current
widget before summarizing.

(fn &optional LEVEL)

2.243.1.5 emacsvox-widget-update-from-minibuffer ¶

Command: emacsvox-widget-update-from-minibuffer (pos) ¶
Sets widget at ‘pos’ by invoking its prompter.

(fn POS)
