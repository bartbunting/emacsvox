2.26 emacsvox-aural-inspection ¶

Source-buffer ownership and at-point context capture shared by aural managers, editors, explanations, and previews. Each interface keeps its own ordinary source buffer; the most recent source remains only as a fallback for interfaces opened without an explicit association.
