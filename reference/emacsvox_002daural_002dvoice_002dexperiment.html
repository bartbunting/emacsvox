2.54 emacsvox-aural-voice-experiment ¶

Explore exact physical voices in memory. Keeping an experiment prepares a review, then uses the existing separate palette and routing stores. Each completed step is retained so a partial save or apply can be retried.

2.54.1.6 emacsvox-aural-voice-experiment-keep-mode ¶

Command: emacsvox-aural-voice-experiment-keep-mode ¶
Review separate style and route changes before saving and applying them.

In addition to any hooks its parent mode
‘emacsvox-aural-interface-mode’ might have run, this mode runs the
hook ‘emacsvox-aural-voice-experiment-keep-mode-hook’, as the final or
penultimate step during initialization.
