2.30 emacsvox-aural-menu ¶

Experimental entry and speech menus. Retain the source item across submenus and delegate settings and feedback to their existing commands.

  • Emacsvox-Aural-Menu Commands

2.30.1 Emacsvox-Aural-Menu Commands ¶

  • emacsvox-aural-menu

  • emacsvox-aural-menu-punctuation

2.30.1.1 emacsvox-aural-menu ¶

Command: emacsvox-aural-menu (&optional arg1) ¶
C-e H ¶
Choose Emacsvox speech settings or inspect feedback for this item.
With prefix GLOBAL, start speech settings with global defaults.
The source item is captured on entry for contextual editing and return.
Up and Down select items; Left and Right select the first item of a section.
Enter activates the selected item; a displayed key invokes its action directly.
Shift-Left and Shift-Right adjust numeric controls where offered. Choice lists
use Up and Down to browse and Enter to choose. Text prompts keep normal editing.
Question mark followed by an item’s key explains its effect and scope.
q or C-g returns one menu; C-q closes the sequence. Applied changes remain;
each editor explains its own draft, Apply and Save actions.

2.30.1.2 emacsvox-aural-menu-line-cues ¶

Command: emacsvox-aural-menu-line-cues ¶
Choose a global line tone or boundary earcon to preview and edit.

2.30.1.3 emacsvox-aural-menu-navigation ¶

Command: emacsvox-aural-menu-navigation ¶
Choose arrow navigation, announcement order, and descriptions for all menus.
These preferences apply to all Transient menus, including Magit. Browse with
Up and Down, then Enter to apply a choice. Left and Right change sections
and select their first item. C-c l repeats that item without activating it.
Changes take effect immediately; S saves these preferences through Customize.

2.30.1.4 emacsvox-aural-menu-punctuation ¶

Command: emacsvox-aural-menu-punctuation (&optional arg1) ¶
Choose punctuation for this buffer or the session’s global default.
Global changes also apply to the source buffer.  S saves the displayed choice
as the default across restarts; mode policies still take precedence.

2.30.1.5 emacsvox-aural-menu-sounds ¶

Command: emacsvox-aural-menu-sounds ¶
Adjust global output volumes or browse sound packs.
Shift left and right adjust the selected volume by five percentage points.
Enter sets an exact value.  Save explicitly to retain volumes across restarts.

2.30.1.6 emacsvox-aural-menu-speech ¶

Command: emacsvox-aural-menu-speech (&optional arg1) ¶
Choose speech settings for the source buffer or global defaults.
With prefix GLOBAL, start with global defaults when opening directly.
When opened from the Emacsvox menu, share its selected scope.

2.30.1.7 emacsvox-aural-menu-voices ¶

Command: emacsvox-aural-menu-voices ¶
Browse voices and palettes or choose a global engine preference.
Browser quit commands return here after unwinding their own child views.
Engine preferences last for this session unless explicitly saved.
