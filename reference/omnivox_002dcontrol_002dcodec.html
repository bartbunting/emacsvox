2.347 omnivox-control-codec ¶

Bounded control and marker encoding, voice selectors, and preview values. These helpers validate and translate data. The voice adapter retains process capability checks, request admission, callbacks and registration. Pitch conversion and generic preview metadata use the established adapter and TTS helpers; loading this module does not initialize either runtime.
