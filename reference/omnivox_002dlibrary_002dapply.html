2.281 omnivox-library-apply ¶

Private, effect-driven Apply coordinator. A native provider executes one issued action and returns its correlated receipt. This module decides when retirement, replacement, commit and paired rollback may follow. It performs no process or file operations itself. There is deliberately no interactive entry point until a native provider supplies ownership and durable receipts. See docs/voice-library-apply-controller.org for the provider boundary.
