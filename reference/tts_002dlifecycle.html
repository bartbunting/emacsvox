2.375 tts-lifecycle ¶

Keep speech preparation, dispatch tracking, output observation, interruption and retirement together. These operations share process generations, cancellation epochs, queue guards and callback ownership.

The existing handoff with aural transport is retained: transport captures packets and binds semantic owners; this module reserves, sends, publishes and retires dispatches. The public ‘tts-speak’ entry point still owns speech configuration, process creation, text preparation and notification commands. Load through ‘tts-speak’. Loading definitions does not start speech or install process filters; the existing runtime entry points do that.
