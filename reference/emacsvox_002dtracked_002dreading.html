2.307 emacsvox-tracked-reading ¶

Read a buffer in bounded chunks, advancing point after playback completion. Keep session markers, callback generations and cancellation hooks together. The core speech library loads these definitions; loading them alone neither starts speech nor installs hooks. The public command starts each session.

2.307.1 Emacsvox-Tracked-Reading Commands ¶

  • emacsvox-speak-rest-of-buffer

2.307.1.1 emacsvox-speak-rest-of-buffer ¶

Command: emacsvox-speak-rest-of-buffer ¶
C-e i ¶
Speak from point to buffer end, tracking interrupt position by chunk.
Any subsequent user command interrupts speech.  Point remains at the start of
the sentence-oriented chunk that was audible when interruption occurred.

2.307.2 emacsvox-tracked-reading Options ¶

Variable: User Option emacsvox-tracked-reading-max-chars ¶
Maximum source characters in one tracked reading chunk.
Tracked reading prefers sentence boundaries and uses this limit to keep the
position retained after interruption reasonably close to audible playback.

Default Value: 

280
