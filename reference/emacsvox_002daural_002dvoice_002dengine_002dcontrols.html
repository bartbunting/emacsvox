2.60 emacsvox-aural-voice-engine-controls ¶

A descriptor-driven view of the existing voice draft. Discovery never samples, edits are sparse and previews and saving retain their usual owners.

2.60.1.7 emacsvox-aural-voice-engine-controls-mode ¶

Command: emacsvox-aural-voice-engine-controls-mode (&optional arg) ¶
Edit descriptor-based engine controls within the current voice draft.

This is a minor mode.  If called interactively, toggle the
‘Emacsvox-Aural-Voice-Engine-Controls mode’ mode.  If the prefix
argument is positive, enable the mode, and if it is zero or negative,
disable the mode.

If called from Lisp, toggle the mode if ARG is ‘toggle’.  Enable the
mode if ARG is nil, omitted, or is a positive number.  Disable the mode
if ARG is a negative number.

To check whether the minor mode is enabled in the current buffer,
evaluate the variable ‘emacsvox-aural-voice-engine-controls-mode’.

The mode’s hook is called both when the mode is enabled and when it is
disabled.

(fn &optional ARG)

2.60.1.8 emacsvox-aural-voice-engine-controls-open ¶

Command: emacsvox-aural-voice-engine-controls-open ¶
Open described engine controls for a selected physical choice in this draft.

2.60.1.9 emacsvox-aural-voice-engine-controls-refresh ¶

Command: emacsvox-aural-voice-engine-controls-refresh ¶
Check controls asynchronously, retrying busy replies for up to five seconds.
Do not stop speech or play a sample.  Leaving this view cancels retries.

2.60.1.10 emacsvox-aural-voice-engine-controls-reset-all ¶

Command: emacsvox-aural-voice-engine-controls-reset-all ¶
Remove only this choice’s native settings, retaining an undo step.

2.60.1.11 emacsvox-aural-voice-engine-controls-search ¶

Command: emacsvox-aural-voice-engine-controls-search ¶
Filter controls by label, identifier or help, across collapsed groups.

2.60.2 emacsvox-aural-voice-engine-controls Options ¶

Variable: User Option emacsvox-aural-voice-engine-controls-mode-hook ¶
Hook run after entering or leaving ‘emacsvox-aural-voice-engine-controls-mode’.
No problems result if this variable is not bound.
‘add-hook’ automatically binds it.  (This is true for all hook variables.)

Default Value: 

nil
