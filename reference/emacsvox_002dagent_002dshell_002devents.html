2.18 emacsvox-agent-shell-events ¶

Capture rendered response sections and translate lifecycle, permission and tool events into speech. This module retains the event subscriptions, timers, marker snapshots and caches with their existing cleanup functions. The presentation module owns shared feedback policy. The facade calls setup and teardown in the established order. Loading these definitions does not subscribe buffers. Load through ‘emacsvox-agent-shell’.
