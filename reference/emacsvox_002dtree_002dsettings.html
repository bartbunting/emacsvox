2.309 emacsvox-tree-settings ¶

Browse and preview tree feedback presets, then commit ordinary aural rules. The shared tree parser and integrations do not depend on this interface.

  • Emacsvox-Tree-Settings Commands

2.309.1 Emacsvox-Tree-Settings Commands ¶

  • emacsvox-tree-settings
  • emacsvox-tree-settings-preview-mode

2.309.1.1 emacsvox-tree-settings ¶

Command: emacsvox-tree-settings ¶
Browse and preview shared tree feedback for a captured source buffer.
Apply to that buffer or this session, or save personal rules explicitly.

2.309.1.2 emacsvox-tree-settings-preview-mode ¶

Command: emacsvox-tree-settings-preview-mode ¶
Browse draft tree feedback with Up and Down; Space repeats and q returns.
The sample uses captured source settings. It changes no source or preferences.

In addition to any hooks its parent mode ‘special-mode’ might have
run, this mode runs the hook
‘emacsvox-tree-settings-preview-mode-hook’, as the final or
penultimate step during initialization.
