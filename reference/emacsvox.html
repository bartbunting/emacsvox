2.4 emacsvox ¶

Emacsvox extends Emacs to be a fully functional audio desktop. This is the main emacsvox module. It actually does very little:

  • It sets up Emacs to load package-specific Emacsvox modules as and when a package is loaded.
  • It implements function emacsvox which loads the rest of the system.
  • It provides affordances for setting up consistent behavior in programming modes.
  • emacsvox Options

2.4.1 emacsvox Options ¶

Variable: User Option emacsvox-pip-enable ¶
Load pip if Piper-TTS is available.

Default Value: 

nil
Variable: User Option emacsvox-ready-message-routing-timeout ¶
Seconds the startup announcement waits for acknowledged Omnivox routing.

Default Value: 

5
Variable: User Option emacsvox-speak-ready-message ¶
Whether to speak ‘emacsvox-ready-message’ after Omnivox is ready.
The announcement normally occurs after initial routing is acknowledged.  If
routing does not become ready within ‘emacsvox-ready-message-routing-timeout’,
the capability-ready route announces the bounded fallback checkpoint.

Default Value: 

t
