2.283 emacsvox-speak-status ¶

Buffer and system status speech. The core speech facade retains activation in its established order.

  • Emacsvox-Speak-Status Commands
  • emacsvox-speak-status Options

2.283.1.1 emacsvox-speak-buffer-filename ¶

Command: emacsvox-speak-buffer-filename (&optional filename) ¶
C-e f ¶
Speak name of file being visited in current buffer.
Speak default directory if invoked in a dired buffer, or when the
buffer is not visiting any file.  Interactive prefix arg
‘filename’ speaks only the final path component.  The result is
put in the kill ring for convenience.

(fn &optional FILENAME)

2.283.1.2 emacsvox-speak-header-line ¶

Command: emacsvox-speak-header-line ¶
C-e C-x ¶
Speak header line if set.

2.283.1.3 emacsvox-speak-minor-mode-line ¶

Command: emacsvox-speak-minor-mode-line (&optional log-msg) ¶
C-e M ¶
Speak the minor mode-information.
Optional interactive prefix arg ‘log-msg’ logs spoken info to
*Messages*.

(fn &optional LOG-MSG)

2.283.1.4 emacsvox-speak-mode-line ¶

Command: emacsvox-speak-mode-line (&optional buffer-info) ¶
C-e m ¶
Speak the mode-line.
Speaks header-line if that is set when called non-interactively.
Interactive prefix arg speaks buffer info.

(fn &optional BUFFER-INFO)

2.283.1.5 emacsvox-speak-net-id ¶

Command: emacsvox-speak-net-id ¶
C-e ` ¶
Shows active network interfaces in the echo area.
 The address is also copied to the kill ring for convenient yanking.

2.283.1.6 emacsvox-speak-which-function ¶

Command: emacsvox-speak-which-function ¶
C-e M-w ¶
Speak which function we are on.  Uses which-function from
which-func without turning that mode on.

2.283.1.7 emacsvox-toggle-header-line ¶

Command: emacsvox-toggle-header-line ¶
Toggle Emacsvox’s default header line.

2.283.1.8 emacsvox-toggle-mail-alert ¶

Command: emacsvox-toggle-mail-alert (&optional prefix) ¶
C-e M-m ¶
Toggle state of  Emacsvox  mail alert.
Interactive PREFIX arg means toggle  the global default value, and then set the
current local  value to the result.
Turning on this option results in Emacsvox producing an auditory icon
indicating the arrival  of new mail when displaying the mode line.

2.283.2 emacsvox-speak-status Options ¶

Variable: User Option emacsvox-mail-alert-interval ¶
Interval in seconds between mail alerts for the same pending
  message.

Default Value: 

300
Variable: User Option emacsvox-mail-spool-file ¶
Mail spool file examined  to alert you about newly
arrived mail.

Default Value: 

"<system-mail-spool>/<login>"
