2.279 emacsvox-speak-filters ¶

Own column selection, inversion and saved per-file or per-mode filters. The core speech library loads these definitions at the original filter setup point. Saved settings are loaded and the exit hook is installed only when requested by the existing filter commands.

  • Emacsvox-Speak-Filters Commands

2.279.1 Emacsvox-Speak-Filters Commands ¶

  • emacsvox-speak-line-set-column-filter
  • emacsvox-speak-load-filter-settings
  • emacsvox-speak-persist-filter-settings
  • emacsvox-toggle-speak-line-invert-filter

2.279.1.1 emacsvox-speak-line-set-column-filter ¶

Command: emacsvox-speak-line-set-column-filter (filter) ¶
C-e | ¶
Set up filter for selectively speaking or ignoring portions of lines.
The filter is specified as a list of pairs.
For example, to filter  columns 1 – 10 and 20 – 25,
specify filter as
((0 9) (20 25)). Filter settings are persisted across sessions.  A
persisted filter is used as the default when prompting for a filter.
This allows one to accumulate a set of filters for specific files like
/var/adm/messages and /var/adm/maillog over time.
Option emacsvox-speak-line-invert-filter determines
the sense of the filter.

(fn FILTER)

2.279.1.2 emacsvox-speak-load-filter-settings ¶

Command: emacsvox-speak-load-filter-settings ¶
Load emacsvox filter settings.

2.279.1.3 emacsvox-speak-persist-filter-settings ¶

Command: emacsvox-speak-persist-filter-settings ¶
Persist emacsvox filter settings for future sessions.

2.279.1.4 emacsvox-toggle-speak-line-invert-filter ¶

Command: emacsvox-toggle-speak-line-invert-filter (&optional prefix) ¶
C-e \ ¶
Toggle state of   how column filter is interpreted.
Interactive PREFIX arg means toggle  the global default value, and then set the
current local  value to the result.
