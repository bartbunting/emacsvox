2.285 emacsvox-speak-windows ¶

2.285.1.1 emacsvox-buffer-select ¶

Command: emacsvox-buffer-select ¶
C-e p ¶
C-e n ¶
C-e . ¶
C-e , ¶
Select buffer by smart cycling.
Use option emacsvox-buffer-select-help to customize interactive feedback.
By default, this command is bound to multiple keys.
The final key of the initial  key-sequence, and  further invocations
of the keys below call the following bindings:

, previous-buffer
. next-buffer
b switch-to-buffer
f find-file
k emacsvox-kill-buffer-quietly
n emacsvox-cycle-to-next-buffer
o other-window
p emacsvox-cycle-to-previous-buffer

2.285.1.2 emacsvox-cycle-to-next-buffer ¶

Command: emacsvox-cycle-to-next-buffer ¶
Cycles to next buffer having same mode.

2.285.1.3 emacsvox-cycle-to-previous-buffer ¶

Command: emacsvox-cycle-to-previous-buffer ¶
Cycles to previous buffer having same mode.

2.285.1.4 emacsvox-describe-tapestry ¶

Command: emacsvox-describe-tapestry (&optional details) ¶
C-e M-t ¶
Describe the current layout of visible buffers in current frame.
Use interactive prefix arg to get coordinate positions of the
displayed buffers.

(fn &optional DETAILS)

2.285.1.5 emacsvox-owindow-next-line ¶

Command: emacsvox-owindow-next-line (count) ¶
ESC <down> ¶
Move to the next line in the other window and speak it.
Numeric prefix arg COUNT can specify number of lines to move.

(fn COUNT)

2.285.1.6 emacsvox-owindow-previous-line ¶

Command: emacsvox-owindow-previous-line (count) ¶
ESC <up> ¶
Move to the next line in the other window and speak it.
Numeric prefix arg COUNT specifies number of lines to move.

(fn COUNT)

2.285.1.7 emacsvox-owindow-scroll-down ¶

Command: emacsvox-owindow-scroll-down ¶
ESC <prior> ¶
Scroll down  the window that command ‘other-window’ would move to.
Speak the window contents after scrolling.

2.285.1.8 emacsvox-owindow-scroll-up ¶

Command: emacsvox-owindow-scroll-up ¶
ESC <next> ¶
Scroll up the window that command ‘other-window’ would move to.
Speak the window contents after scrolling.

2.285.1.9 emacsvox-owindow-speak-line ¶

Command: emacsvox-owindow-speak-line ¶
Speak the current line in the other window.

2.285.1.10 emacsvox-select-window-by-name ¶

Command: emacsvox-select-window-by-name (buffer-name) ¶
C-e W ¶
Select window by the name of the buffer it displays.
This is useful when using modes like ECB or the new GDB UI where
  you want to preserve the window layout
but quickly switch to a window by name.

(fn BUFFER-NAME)

2.285.1.11 emacsvox-speak-current-window ¶

Command: emacsvox-speak-current-window ¶
Speak contents of current window.
Speaks entire window irrespective of point.

2.285.1.12 emacsvox-speak-other-window ¶

Command: emacsvox-speak-other-window ¶
C-e 2 ¶
Speak other window

2.285.1.13 emacsvox-speak-predefined-window ¶

Command: emacsvox-speak-predefined-window (&optional arg) ¶
Speak one of the first 10 windows on the screen, 0 is current window.
Speaks entire window irrespective of point.  Semantics of ‘other’
is the same as for the Emacs builtin ‘other-window’.

(fn &optional ARG)

2.285.1.14 emacsvox-speak-this-window ¶

Command: emacsvox-speak-this-window ¶
C-e 1 ¶
Speak current window.

2.285.1.15 emacsvox-speak-window-information ¶

Command: emacsvox-speak-window-information ¶
C-e C-w ¶
Speaks information about current window.

2.285.1.16 emacsvox-speak-windowful ¶

Command: emacsvox-speak-windowful ¶
C-e SPC ¶
Delete other windows, Line to top, then Speak window contents.

2.285.2 emacsvox-speak-windows Options ¶

Variable: User Option emacsvox-buffer-select-help ¶
String passed to speak help.
Set this to the empty string once you’ve learnt this command.

Default Value: 

""
