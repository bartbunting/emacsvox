2.104 emacsvox-empv ¶

EMPV == Emacs Front-End To mpv — the GNU media player — Provides better Youtube integration.

This section documents Emacsvox extensions to EMPV , the Emacs interface of choice to the GNU MPV media player. This section should be read alongside the EMPV documentation; Install EMPV from ELPA.

  • Interactive Commands
  • Navigating In Time
  • Toggling Filters
  • Emacsvox-Empv Commands
  • emacsvox-empv Options

2.104.1 Interactive Commands ¶

Emacsvox adds a few convenience commands to the those provided by package empv:

  1. Command emacsvox-empv-play-url to play a URL using MPV .
  2. Adds history tracking to our EMPV commands.
  3. Command empv-play-last-url to play from our EMPV history.
  4. Command emacsvox-empv-play-file to play local media and Internet streams.

2.104.2 Navigating In Time ¶

Emacsvox defines additional convenience commands to seek in streams at different time granularities, the names are self-documenting and bound in the empv-map.

2.104.3 Toggling Filters ¶

Command mpv provides a number of audio filters. Emacsvox exposes a select few for interactive use.

  1. Toggle active filter: emacsvox-empv-toggle-filter
  2. Toggle Audio Balance: emacsvox-empv-toggle-balance
  3. Clear any active filters: emacsvox-empv-clear-filter
  4. Toggle our custom filter: emacsvox-empv-toggle-custom
  5. Toggle left output: emacsvox-empv-toggle-left
  6. Toggle right output: emacsvox-empv-toggle-right

2.104.5 emacsvox-empv Options ¶

Variable: User Option emacsvox-empv-custom-filters ¶
List of custom filters to turn on/off at one shot
The default value is suitable for classical instrumental music.

Default Value: 

("extrastereo" "stereowiden=4.25:.1:735:.8" "haas")
