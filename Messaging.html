8.5 Messaging ¶

Emacsvox integrates with several Emacs mail and messaging modes. The curated workflow for indexed mail search, asynchronous results, thread reading, attachments, and privacy controls is Notmuch Mail. For another client, start with its own manual and C-h m; use the generated reference to find an Emacsvox module with the same package or mode name.
