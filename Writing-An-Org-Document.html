9.2.1 Write a note with headings ¶

Unlike the tutorial’s disposable buffer, this task creates a file you can return to. Use an unused name and a writable directory. The name ~/evox-notes.org is an example, not a file the package supplies.

  1. Press C-x C-f, enter ~/evox-notes.org and press RET. If it already contains work, choose another name before typing. The .org extension normally selects Org mode; check with C-e m. If a personal configuration selected another mode, run M-x org-mode RET in this new note.
  2. Type or insert the following text in the document buffer, not in the minibuffer or the manual. Start each heading at the beginning of its line. One asterisk and a space introduce the main heading; two asterisks and a space introduce a heading beneath it. 
    * Project notes
The draft is ready for review.
** Questions
Check the delivery date.
** Decisions
Keep a separate review copy.
  3. Press M-< and read with C-n and C-e l. Verify the heading words and body text. Org heading feedback can identify structure without reading every leading asterisk; exact character inspection remains available.
  4. Press C-x C-s and read the save result. That writes this Org text to the selected file. It does not export a formatted document or change speech settings. Keep the file open for the following review, or reopen it later with C-x C-f and its path.

Choose your own heading titles when writing real notes. Org stores the title and body as plain text, so the structure remains in the file even when parts of it are folded in the current view. Do not delete a folded heading to try to reveal its body: folding is a visibility operation, not missing content.
