15.4 Help and orientation ¶

Help can change the selected buffer and window arrangement. Before your next editing command, check that you have returned to the intended document.

Identify your context (C-e m)

Speak the mode line, including the current buffer and major mode. See Position and status commands.

Describe the windows (C-e C-w)

Describe the current arrangement. This does not select a different view. See Working with windows through speech.

Explain a key (C-h k followed by the key sequence)

Describe its effective binding without invoking it as the requested action. See Discovering a key, command or setting.

Discover local commands (C-h m)

Describe the current modes. C-h b lists effective bindings; invoke these from the application you are asking about. See Help for the current buffer.

Read Help again (C-e h)

Select and read Help using a windowful helper that removes other windows without killing their buffers. Lowercase h is different from capital H for settings. See Reading Help and returning to work.

Open the manual (C-e C-i)

Open this manual directly in Info. Use i in Info to look up a subject and l to retrace a link. See Manual lookup and return navigation.

C-e f speaks a filename or default directory, and C-e a repeats a message. Both also put text in the kill ring and can affect the next paste. See Status commands and their side effects.
