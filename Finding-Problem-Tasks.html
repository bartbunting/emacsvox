16.6 Something is wrong ¶

Start with the closest symptom. These routes preserve existing work and help you decide what to inspect before attempting a repair. A failed preview, an unsaved draft and a failed application are different problems.

  • There is no speech at all: restore a working speech route before using tools that depend on spoken inspection.
  • Reading restarted part of a sentence: distinguish chunk-based tracking from exact-word pause/resume and inspect the retained position.
  • Text was pasted in the wrong place: undo in the affected buffer and check the result before trying the transfer again.
  • A paste inserted a filename or message instead of my passage: inspect which command changed the kill ring before choosing the earlier copy.
  • Help replaced my other windows: check the selected buffer and restore the desired views; a collapsed layout need not mean lost documents.
  • I saved a voice, but it still sounds the same: check selection, matching rules, individual tuning and engine support in that order.
  • My settings disappeared after restarting: distinguish temporary changes from saved resources and their startup selection.
  • Only one application or document sounds wrong: compare the same kind of action and inspect local settings, integration policy and matching rules.
  • There is too much talking: distinguish automatic content, training explanations, extra labels and the notification stream before silencing it.
  • I cannot tell whether a change succeeded: keep the saved result and unfinished work while checking stream acknowledgements or a timeout.
  • I cannot get back to what I was reading: leave the current editor using its own return action, then use the menu’s captured-source return.
  • A web page is cluttered or missing content: restore its reading view, distinguish a fresh request from history, or use an external browser.
  • I need to report an unresolved problem: collect a reproducible example and a reviewed diagnostic report without exposing private speech or paths.

For a missing cue, an unfamiliar profile status or another symptom, use Troubleshooting and recovery. Avoid resetting unrelated settings to test one explanation; change only the cause you have identified and repeat the original action to check the result.
