* Piper Voice Downloads

This file belongs to the experimental =lisp/pip.el= notification path, not the
Omnivox Piper engine.  The old hand-maintained model URLs and voice list were
removed because Piper now provides a supported downloader and the direct URLs
age independently.

Install the current =piper-tts= package in a virtual environment, list
available voices with that environment's Python, and download a chosen model
into =pip-data-dir=:

#+begin_src sh
python3 -m venv ~/.local/share/emacsvox-piper-venv
~/.local/share/emacsvox-piper-venv/bin/python -m pip install piper-tts
~/.local/share/emacsvox-piper-venv/bin/python -m piper.download_voices
~/.local/share/emacsvox-piper-venv/bin/python -m piper.download_voices \
  --data-dir ~/.local/share/voices-piper en_US-lessac-medium
#+end_src

Put =~/.local/share/emacsvox-piper-venv/bin= on the environment inherited by
Emacs so =lisp/pip.el= can find the =piper= command.

See [[https://github.com/OHF-Voice/piper1-gpl/blob/main/docs/CLI.md][Piper's command-line reference]] for the maintained options and voice-download
workflow.
