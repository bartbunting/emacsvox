6 Hear Structure With Voice Lock ¶

Voice Lock makes structure audible by applying different speech personalities to text properties supplied by Emacs modes and Emacsvox integrations. Emacs calls its visual style labels faces; Emacsvox can use the same labels without requiring you to see them. A comment can sound different from program code, a heading from body text, or a link from surrounding prose without inserting extra words into the document.

Voice Lock is enabled automatically in supported buffers. Its differences are easiest to hear in source code, Org, Info, or EWW, where the active mode already marks several kinds of content.

6.1 Try It In One Buffer ¶

Move across a few elements that the mode treats differently, such as a comment and a string in source code or a heading and a link in Org. Then use:

C-e d v

Toggle Voice Lock in the current buffer. Comparing the same text before and after the toggle is a quick way to confirm that a voice change comes from the established face-and-personality layer.

C-e d C-v

Toggle Voice Lock globally. Existing and subsequently created buffers follow the new global state; an individual mode can still opt out when it starts.

C-e E

Explain the Aural Presentation at point. The explanation can identify the semantic facts, matching rules, voices, sounds, and other actions that contributed to what you heard.

Voice Lock controls the compatibility mapping from faces and personality text properties to voices. Turning it off does not disable semantic presentation, auditory icons, tones, or ordinary spoken status. This distinction makes the current-buffer toggle a useful diagnostic rather than an all-or-nothing speech control.
