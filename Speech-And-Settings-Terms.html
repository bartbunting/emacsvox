17.4 Changes and speech output ¶

Preview

An audition or comparison of a proposed result. Previewing does not by itself save the draft or make it the ordinary live configuration.

Retained draft

An unfinished edit kept in the current Emacs session for return to its editor. Retaining it is not a promise of recovery after Emacs exits, and discarding it does not undo a save already completed.

Save

Record data in the store owned by that editor or setting. Read the action’s label: Save and apply and Save to collection without selecting intentionally have different effects.

Apply

Put a chosen configuration into use. The operation may require confirmation, validation, or a worker restart. Its exact effect depends on the resource; it is not a universal synonym for saving.

Startup selection

The configuration to select when a later session starts. Selecting something for this session does not always select it for the next one. Choose what persists compares these states and their owners.

Speech server, engine, and worker

Emacsvox talks to a speech server; the server uses engines to synthesise speech. The manual uses worker for a running speech instance whose configuration and reported voices can differ from another instance or from installed files. See Speech Backends.

Main and notification speech

Separate output paths for foreground reading and other announcements. An integration decides which path to use for an event; their existence is not a guarantee that all background text is private. See Speech output and notifications.
