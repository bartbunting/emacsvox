3 Basic Usage. ¶

This chapter gives a short, task-oriented introduction to Emacsvox. For the complete generated key reference, see Emacsvox Keymaps in Emacsvox Reference Manual. Use C-h m to inspect the modes and bindings active in the current buffer, or C-h k followed by a key to ask Emacs what that key does. These sections describe the speech-enabling extensions, but are not a substitute for the Emacs manual.

All Emacs navigation and editing commands have been speech enabled. Thus, moving to the next or previous word, line or paragraph results in the text around point being spoken. Exactly how much text is spoken is determined by the amount by which you moved.

In addition, Emacsvox provides basic reading functions that can be invoked to listen to chunks of text without moving.
