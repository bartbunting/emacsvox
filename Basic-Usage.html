5 Basic Usage ¶

Once Emacsvox is speaking, ordinary Emacs commands let you read, edit and navigate. Emacsvox announces their results. Short speech commands inspect text at your editing position, while tracked reading follows a longer passage. This chapter moves from those reading choices to selecting and editing text, then to everyday speech controls. Audio Desktop explains how to keep several tasks available through buffers and windows.

5.1 Key Notation And Emacs Words ¶

Start with Read the key instructions if the notation is unfamiliar. It explains modifiers, uppercase letters and successive keypresses before asking you to use them. Answer a prompt and return to your work covers command names, completion and filename questions.

A buffer holds text or an application view; point is the position at which movement and editing act. The selection guide below introduces the mark and region when they are needed. For a separate introduction to Emacs editing, C-h t opens its interactive tutorial.

5.2 Your First Few Minutes ¶

Try these in the speaking session started during installation:

  1. Press C-n to move down one line and C-p to move back up. Emacsvox speaks the destination line.
  2. Press C-e l to hear that line without moving.
  3. Press C-e s to stop speech. Later commands still speak.
  4. Press C-h k, then a key, to learn what it does.
  5. Press C-h m to discover the current modes and commands.
  6. Press C-h C-e for the Emacsvox overview.

When you want to adjust speech, C-e H s opens Speech settings. Browse with arrows and ask for an item’s Help with ? followed by its key. RET activates it; q goes back and C-q closes the menu sequence. Browsing does not change a value, but leaving does not reverse adjustments already applied. Detailed scope and saving instructions follow below.

The keys in this manual are defaults. Use C-h k if one behaves differently. The generated Emacsvox Keymaps records default bindings; live Help reflects installed packages and personal customisations. These menu quit keys apply while an Emacsvox menu is active, not to every application buffer.
