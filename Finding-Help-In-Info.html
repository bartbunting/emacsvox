2.3 Find an answer in Info and return ¶

Info is Emacs’s manual reader. A node is one navigable topic, which can have its own menu of subtopics. These instructions apply to the Info buffer, not to Emacsvox’s settings menus.

Try this lookup without changing your configuration:

  1. From a working buffer, press C-h i to open Info, d for its directory, then m. Enter Emacsvox and press RET to open this manual.
  2. Press i, enter ordinary reading voice, and press RET. The index takes you to the voice-task links. Read with your ordinary speech commands.
  3. Use TAB to reach Change my ordinary reading voice and press RET. You are now at the named-voice instructions. Reading them changes nothing; leave the editing commands for when you deliberately want to make a change.
  4. Press lowercase l to return to the task links. Another l returns to the topic you were reading before the index lookup. This follows your visiting history rather than the chapter order.
  5. Press q to leave Info. From an Aural interface’s contextual manual link, q returns to that interface. If you opened other windows or switched buffers during the exercise, C-x b also lets you select your original working buffer by name.

If the directory has no Emacsvox entry, the manual is not yet discoverable by that Emacs session; follow Installation rather than guessing a file path. In an Aural editor, C-c C-i opens its relevant manual topic, and i in that editor’s Help opens the same topic.

The following Info commands are useful during later lookups:

i

Look up a subject in the manual’s indexes. Use ordinary words, a command name, or a key sequence. , visits further matching entries.

s

Search the manual text, including other nodes. Enter the words and press RET; s RET continues the same search.

TAB, S-TAB

Move among links. RET follows the selected link.

m

Choose a subtopic from the current node’s menu by name, with completion.

u

Go to the containing topic. This is different from l, which goes back to the topic you last visited.

g

Go to a node by its identifier. For example, enter Finding Tasks to return directly to the task finder.

For the full reader tutorial and search behaviour, see the Info manual. If a key behaves differently in your session, C-h k followed by that key explains its effective binding without invoking it.
