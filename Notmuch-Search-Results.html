10.3 Navigate and inspect Search results ¶

Thread movement reads configured semantic fields and status cues. At a boundary, speech identifies the beginning or end instead of repeating the current row. Emacsvox makes the arrow keys equivalent to Notmuch’s next and previous thread commands.

n

Run notmuch-search-next-thread.

<down>

Also run notmuch-search-next-thread.

p

Run notmuch-search-previous-thread.

<up>

Also run notmuch-search-previous-thread.

RET

Run notmuch-search-show-thread. Show lands on a useful visible body line or leaf MIME part and presents the opened message.

SPC

Run notmuch-search-scroll-up. This scrolls the viewport rather than selecting a semantic thread.

C-c C-p

Run emacsvox-notmuch-speak-search-details to read all configured fields for the result at point without automatic content limits.

+

Run notmuch-search-add-tag.

-

Run notmuch-search-remove-tag.

*

Run notmuch-search-tag-all for the selected results.

a

Run notmuch-search-archive-thread.

g

Run notmuch-refresh-this-buffer; completion follows the interruptible refresh policy above.

Search defaults to authors, subject, relative date, matched and total message counts, and ordinary tags. Status tags assigned auditory cues are not repeated as words. Notmuch fields and privacy explains omission and ordering of sensitive fields.
