8.5.1 Walkthrough: Change Headings In One Buffer ¶

This experiment changes headings in a temporary Org buffer without altering palette definitions or saved personal rules. Use an unused buffer name; if *aural-practice* already contains work, choose another name throughout the exercise. Do not erase existing text to recreate the example.

  1. Use C-x b to create that new buffer. Run M-x org-mode RET and insert: 
    * Reading notes
An ordinary paragraph.
* Next steps
Another ordinary paragraph.
  2. Move onto the first heading and press C-e E. Identify its named voice and heading facts, noting whether the report describes recorded output or a simulation. Press q to return to the source before opening a new menu.
  3. Press C-e H f c for the guided change. Press c, select Content voice, and choose annotate with RET, or bolden if annotate is already used. O plays the original and P previews the proposed voice. Only the draft has changed.
  4. Press m for What should match. Keep the Org module, heading role, and heading level if shown. Leave other criteria as shown for this experiment. Press l and select Current buffer, until it is killed. This matches every qualifying heading in the buffer, not only the original heading.
  5. Review the summary and press a to apply it. Open settings with h, then press b in that menu to return to the captured item. Move between the two headings using the same navigation action. Both matching headings should use the chosen voice; ordinary paragraphs should keep their previous presentation.
  6. Press C-e E on a heading again. Check that the buffer rule supplies the selected voice. If the sound is too similar to distinguish, the report still shows whether it matched. Compare voices or consult Troubleshooting. Return to the source with q.
  7. Open C-e H r o for Your feedback rules. Find the rule in buffer scope and inspect its target. t disables it and d removes it. Revisit the heading to check the result. Killing the practice buffer also ends its buffer rules; none survives an Emacs restart.

For a lasting change, repeat on a representative item and choose Saved personal rule at step 4. Review the criteria carefully: that rule can affect future matching buffers.
