11.6 Navigate transcript blocks ¶

Agent Shell responses contain semantic prompt, response, thought, activity, tool, plan, permission, error, source-block, table and recognised tree locations. Emacsvox navigation reports the block type, visibility, and a bounded body preview.

Up and Down play the ellipses cue when you enter a collapsed heading, such as Capabilities, Models, or Notices. Wrapped continuation rows do not repeat the cue; leaving and returning to the heading plays it again. The optional block visibility cue replaces this default cue. Reading the current line with C-e l continues to indicate hidden content.

Press RET on a foldable heading to toggle that fragment. With Agent Shell 0.94.1 or newer, C-u RET toggles its entire group and sets every child to the same state. From an ungrouped fragment it toggles that fragment alone. Emacsvox presents one visibility change for the affected group: expansion reads the group’s name and state, while collapse uses the configured visibility cue. Collapsing a group from a child moves point to the group heading.

h / H

Use h (emacsvox-agent-shell-next-heading) or H (emacsvox-agent-shell-previous-heading). Move to the next or previous visible Markdown heading and speak its text.

k / K

Use k (emacsvox-agent-shell-next-source-block) or K (emacsvox-agent-shell-previous-source-block). Move to the next or previous source block and announce its language and line count. Inside a table, lowercase k remains the table copy prefix; use M-x emacsvox-agent-shell-next-source-block to jump forward to code from there.

u / U

Use u (emacsvox-agent-shell-next-user-prompt) or U (emacsvox-agent-shell-previous-user-prompt). Move to the next or previous submitted user prompt, skipping the live editor.

j / J

Use j (emacsvox-agent-shell-next-response) or J (emacsvox-agent-shell-previous-response). Move to the next or previous agent response and speak its bounded body preview. These keys skip intervening thoughts, tools, and other block types. From code or a table inside an answer, they skip that enclosing answer. When no later response exists, j moves to the end of the buffer and announces the boundary. With Explicit input activation, browsing stays active there, so J returns to the last response without changing your draft.

l / L

Use l (emacsvox-agent-shell-next-link) or L (emacsvox-agent-shell-previous-link). Move to the next or previous visible rendered link and speak its label and Return action together. The cursor hint remains visible without a second voice repeating it, including when you reach links with ordinary arrows or word movement. Press RET to follow the link. To inspect the full destination, press C-h . (display-local-help). M-x agent-shell-copy-link-url-at-point copies it to the kill ring. Both commands announce the URL when message speech is enabled.

e / E

Use e (emacsvox-agent-shell-next-error) or E (emacsvox-agent-shell-previous-error). Move to the next or previous error or failed tool call. Failed tools are identified by Agent Shell’s error styling in their status label, rather than by words in their output.

]

Run emacsvox-agent-shell-next-block-at-point to find the next block of the current semantic type.

[

Run emacsvox-agent-shell-previous-block-at-point to find the preceding block of the current semantic type.

C-c ]

Run emacsvox-agent-shell-next-block-of-type, choose a type, and move to its next occurrence.

C-c [

Run emacsvox-agent-shell-previous-block-of-type, choose a type, and move to its preceding occurrence.

After a successful typed jump, ] and [ repeat in that direction. At an editable live prompt or viewport editor, bare brackets and navigation letters insert themselves instead of taking over prompt editing. With Explicit input activation, the inline prompt remains navigable until you activate editing.
