8.13.4 Inspect the system with Aural Doctor ¶

Open Aural Doctor with C-e H D d. It checks live bindings, loaded source and byte-code, the compatibility baseline, options, profiles, personal data, resources, spatial fallback and backend. Opening the report neither starts speech nor changes settings. A row that offers a reviewed safe repair can be acted on explicitly with r; read the proposed effect first.

Worker rows report current capabilities and the last inventory. Agreement between configuration identities means the startup identities were acknowledged; it does not prove that saved files are in use. Missing or retired connections leave the evidence unknown. A running process or available engine does not establish audible playback.

In the diagnostics menu, s reports spatial capabilities and policy. Lowercase m and n open retained local main and notification output, reporting an absent buffer where appropriate. Press q in those views to return to the selected menu item. For reporting and logging precautions, see Prepare a useful problem report.
