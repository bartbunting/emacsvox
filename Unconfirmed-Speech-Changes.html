8.13.8 An Apply result is unconfirmed ¶

Apply waits for acknowledgements from each speech stream. After an Omnivox timeout, Workbench reports server outcome unconfirmed, stops that transaction and sends no later steps. Requests already sent may still take effect. A timeout does not undo the saved settings, and it does not tell you that Omnivox rejected them.

  1. Read the result for each stream. Partial results retain acknowledged streams and identify timeouts; do not describe both as failed when only one is unconfirmed.
  2. Check for newer staged edits before retrying. Save them deliberately or cancel them; do not mistake an older reply for acceptance of newer work.
  3. In Workbench, r reapplies saved engine settings and requests a new result. This is an engine-settings recovery action, not a universal retry key in every editor. For a palette review or voice save, use that view’s own retained proposal and retry action.
  4. Inspect the new result and repeat the original speaking task. If the result remains unconfirmed, keep that distinction in your problem report rather than claiming a rollback or a successful application.

Do not delete the saved resource or discard unrelated drafts merely because a worker did not answer. Prepare a useful problem report describes the evidence and privacy precautions for further investigation.
