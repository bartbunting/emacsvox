9.5.2 Read by heading, paragraph or search ¶

In the EWW page buffer, period, ., moves to the next supported heading and comma, ,, to the previous one. 1 through 4 find the next heading at the corresponding level; M-1 through M-4 go backwards. These are HTML heading levels, not numbered paragraphs. A page without suitable heading markup cannot be navigated as though that structure existed.

Use ] and [ to move between paragraphs. M-SPC requests the contents of the current HTML element. Section-navigation autospeak can read more than a heading or a line, depending on your setting; use explicit line or element reading when you want to control the amount. Stop current speech with C-e s without disabling later feedback.

For known words, press C-s, type the text, and press RET to finish at the match. Repeat C-s while searching to find another occurrence. This is Control-s, not the unmodified s key used for a readable view. Search covers the current rendered buffer; it does not submit a web search or find text that was never loaded into the page.

Use the original page when checking whether information is genuinely absent. A readable or filtered view can omit menus, tables or other useful material. The recovery procedure below explains restoring the page without treating a filter as an edit to the website.
