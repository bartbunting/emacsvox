* Scope

This source-only editorial pass is based on =ui-experiments= at
=c242e75529ee9602728ad3a0f447fb2d56cbf799=. It changes no Lisp, dependency,
packaging or publication behaviour and preserves the concurrent tutorial and
Transient work already present at that revision. Before committing, the pass
was rebased onto =82a5207c18db7c4c3bac77ba0dba9daea16d62d0=. Its menu-help,
menu grouping, implementation, tests and generated-document changes do not
overlap these edited files and are preserved. The updated menu and Online Help
were checked for the continuing routes and lowercase Help key.

The Introduction now explains Emacs key notation before any operational key
instructions. It covers modifiers, released sequential steps, uppercase letters,
named keys, command names, cancellation and prefix arguments. Using This Manual,
the tutorial, keyboard reference, task finder and Aural Presentation link to
that explanation instead of relying on a novice to infer the notation.
The tutorial's practice text, lessons, exercises and answers are unchanged.

Aural Presentation has a connected prose edit and a decision guide for choosing
between a named-voice edit, a contextual rule, a palette-wide physical choice,
engine preference and delivery settings. The existing persistence explanation
is organised by intention: preview, retain, store for later, use now, retain at
startup, share or back up. These are not new operations or a universal Save.

Troubleshooting starts with symptoms and inspection. Dedicated topics cover
saved-but-inaudible voices, settings lost after restart, buffer differences,
unconfirmed application and privacy-aware problem reports. Existing diagnostic,
scope, timeout, stream acknowledgement and draft-protection qualifications are
retained. Repeated saving, global resets and deleting unrelated work are not
substitutes for identifying a cause.

The task finder retains its earlier goals, adds a problem route and uses precise
destinations for previews, drafts, notification routing, volumes and shared table
reading. Displayed headings are clarified without renaming existing source
headings or Info identifiers. Applications and Integrations changes only its
printed title and the shared Markdown/Org table reader's navigation properties.
The historical Aural Home identifier and compatibility note remain; no learning
route reintroduces its retired menu entry.
