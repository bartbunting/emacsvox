* Reading and editing contracts

=C-e i= is documented as tracked rest-of-buffer reading, not a synonym for
ordinary buffer inspection. It requires tracked completion, advances point
by sentence-oriented chunks, and stops before another user command executes.
The retained position is a chunk boundary rather than an exact spoken word.
Unsupported servers receive alternatives without a promise of equivalent
tracking. The default 280-character bound is identified as source characters.

Line, word, sentence, paragraph, page, region and buffer reading are explained
by purpose. Important exceptions remain explicit: page reading sets a mark;
large region/buffer requests use a windowful helper that removes other windows;
and restricted/structured buffers do not represent a whole file or manual.
Small region inspection preserves point, mark and activation in the inspected
implementation. The 40,000-character default threshold is not a promise of
unlimited whole-buffer speech.

The editing tasks use small disposable Text-mode examples. They teach region
endpoints and newline inclusion before copy or cut, preserve the source when
copying, and check source and destination after a move. The kill-ring guide
separates immediate yank-pop replacement from the chooser used after another
command. Automatic yank feedback permits listening during a yank sequence;
a separate reading command changes what a subsequent yank-pop does.

Recovery uses undo-only when inspection interrupts undo. Ordinary undo can
redo an earlier undo after a non-undo command, and an active region can limit
recovery. Separate-buffer histories, completed file saves, clipboard contents
and settings operations are not treated as one reversible transaction.
Filename speech and message repetition disclose their kill-ring side effects.

Query replacement first selects a checked region and then reviews each match.
It distinguishes query input from document input and does not insert an
ordinary speech command into the query loop. The existing match speech is
used there; stopping the loop does not undo accepted replacements.

The clipboard section gives a non-confidential two-way test rather than
assuming identical native Windows, WSLg, terminal or remote behaviour. It
neither installs a bridge nor changes operating-system or Emacs configuration.

Window guidance distinguishes buffer, window and frame; display of the same
buffer is not a copy. The reference/draft task checks each selected view and
insertion point. Closing a window is distinct from killing its buffer. Help
and large-reading windowful behaviour is disclosed so a collapsed layout is
not mistaken for lost work.
