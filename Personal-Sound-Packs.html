8.10.6 Inspect And Maintain A Personal Sound Pack ¶

In the manager, o opens the directory and g rescans. For a discovered personal pack, e edits summary, parent, coverage profiles, and default spatialisation. Built-ins are read-only. Editing metadata saves immediately; this is not a retained voice-editor draft.

Coverage profiles declare cue sets for validation, not working Presentation Profiles. Native assets belong to the pack; effective ones include inherited and fallback cues. Validation and details explain those sources.

Use the cue browser’s a to replace a cue from the recording library. Its Availability distinguishes explicit assignments from native files and inherited sounds. Assigned recordings show their names in Recording / file; row speech includes the name and provider. The manager does not record or edit audio, or create a pack through a wizard. For a new personal pack directory, see Authoring Sound Packs in the Developer Guide.

8.10.7 Browse recordings and assign them to cues ¶

Open C-e H o l for the recording library, or run M-x emacsvox-sound-library. The default directory is ~/.emacsvox/sounds/library/; change it through M-x customize-option RET emacsvox-sound-library-directory RET. Put Ogg, WAV, MP3 or FLAC files there, optionally in collection subdirectories, then press g to rescan. i imports a copy into a named collection and leaves its source intact. Adding files does not create cues or assign them to events.

Up and Down move between recordings and, by default, play each recording alongside its row announcement. Left and Right read names, collections, durations and known assignments without replaying the recording. SPC or P replays the current recording and S stops.

To change automatic playback, open Library preview with C-e H o L, or choose it from the library’s C-c C-a Actions menu. Choose Off, Before announcement, Alongside announcement or After announcement. Arrows explain choices without applying them; RET applies the selected choice to all library buffers. S saves it across restarts and q returns. Off still allows explicit replay with SPC or P. Before and After require Omnivox timeline support: Before finishes the recording before speaking; After finishes speaking before playing the recording. Moving again cancels the previous sequence. Alongside also supports external audio players, which control their own playback.

/ filters names and collections; an empty search restores all rows. u filters recordings without saved assignments; it also keeps pending choices visible so you can review them. Duration is shown when the optional ffprobe program is available. Playback still depends on your audio backend. Identical file bytes appear once, even under several names.

To assign several sounds in a writable personal pack:

  1. Select a recording in the library and press a to choose the destination pack and cue. This queues the recording without saving. Alternatively, open C-e H o p, select the pack, then RET for its cues. Find the cue and press a to open the library, then RET to queue a recording.
  2. The row shows and speaks Pending with the pack and cue. SPC previews the row; C plays the saved sound for the current cue. Browse and press RET to replace that cue’s pending choice. Saved cue assignments stay unchanged.
  3. To assign another cue, select another recording and press a again. Choose the cue; the pack stays the same. You stay in the same buffer, and earlier choices remain pending. Repeat for as many cues as needed. The header shows the current cue and the number of pending changes.
  4. Press W to save all pending changes together. Their status becomes Saved. Speech confirms the number of assignments, the pack and whether it is active. An active pack uses the saved sounds; an inactive pack stays inactive.
  5. Press q to return to the opening menu or cue row. This discards any changes still pending and announces how many were discarded. Saved assignments stay in place. Reopen the library to choose a different pack.

A recording can serve several cues. Its row lists each pending and saved assignment separately. Replacing one pending choice leaves the other cues’ choices intact. Until Save, an old recording still shows its saved assignment because that is the sound currently used.

To restore inheritance, open that cue’s assignment and press R. This queues Reset to parent alongside any other pending changes. W saves them together, skipping that cue’s local assignment and revealing its parent or fallback while retaining original audio files. Select and save another recording to replace it again. If the pack or a candidate changes while pending, Save refuses the stale edit and leaves the whole batch unsaved. Cancel, refresh and reopen it.

Saved assignments copy audio into the pack. Renaming or removing the library source cannot break that copy. To move a pack, copy its whole directory and retain its parent packs; the library is not required for playback. Older filename-based packs continue to work. A saved assignment takes precedence over their local file for that cue.

o opens the library directory for file management. d deletes the selected library file after confirmation, refusing recordings assigned in known packs or pending in the current buffer. Assignment reporting covers configured packs, not copies elsewhere. Original imports outside the library and audio copied into packs remain intact.

This browser does not upload audio to a remote speech host. Personal library paths outside the configured workstation sound root cannot be previewed through the remote resource route. Use local playback for those recordings; remote resource installation remains a separate task.
