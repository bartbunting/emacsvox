12.9 Full-screen Applications And Limitations ¶

Pagers, editors, menus, and refreshing dashboards often rewrite cells instead of printing lines. Emacsvox uses conservative cursor, style-change, input- direction, and timing evidence. Arrow movement and clear paired highlight movement work best. Printable keys such as h, j, k, and l are not assumed to mean navigation: the application may treat them as text.

After a silent update, use C-e q l, C-e q d, or C-e q h. For systematic inspection, open C-e q r and review rows or selection-like regions. Rapid dashboards are deliberately not read on every refresh. EAT’s current public API does not expose hyperlink targets, sixel/image semantics, true application accessibility focus, or exact update causes; pixels and faces are insufficient to infer them reliably.

When ordinary output is unexpectedly silent, check the input mode, selected buffer and live-cursor position, foreground autospeak, and verbosity before changing recognition settings. Retained review may explain what was observed, but it is not a replacement for live output or an unbounded transcript.

Remote programs also need compatible terminal information. Missing remote terminfo can break cursor addressing and screen layout; speech classification cannot repair that. Consult EAT’s manual when the terminal itself renders incorrectly.
