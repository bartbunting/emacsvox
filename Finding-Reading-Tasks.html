16.1 Read and navigate ¶

  • Understand the keyboard instructions: learn modifiers, separate steps, uppercase letters and command names before using a shortcut.
  • Know where to type an answer: distinguish minibuffer prompts, completion, document text and command examples.
  • Get speech working again: start with the no-speech recovery procedure before changing presentation rules or voices.
  • Stop current speech: recall the stop key and its effect on tracked reading without disabling feedback from subsequent commands.
  • Inspect a line, sentence or paragraph: choose the reading unit and preserve the editing position, with the limits of large requests explained.
  • Read from here and recover my place: use C-e i for supported tracked reading and understand stopping, repeated chunks and backend limitations.
  • Switch documents without closing my work: choose a buffer by name or cycle among related buffers; window selection is a separate operation.
  • Keep a reference beside my draft: select the intended view and move between tasks without closing either document.
  • Remove a window without losing the document: distinguish layout changes from killing a buffer or saving a file.
  • Find out what a key does: inspect the binding in the current buffer rather than assuming a manual’s default overrides your configuration.
  • Read a table by row or column: use the shared table reader for Markdown and Org. Agent Shell tables have their own contextual keys and spoken units.
