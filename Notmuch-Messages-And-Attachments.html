10.4 Read a thread and its MIME parts ¶

Opening a thread selects its newest unread message among the open messages matching the search. If there is none, Notmuch’s initial selection is retained. Emacsvox speaks the selected message’s summary and first visible body line, skipping hidden alternative bodies. When no body text is visible, point falls back to a leaf MIME-part button where possible. That button announces a bounded filename, content type, and size.

Line reading speaks a visible sender row even if the preceding message ends with folded quoted text; it does not unfold the quote. In a short graphical window, Down advances through ordinary body text before speaking the next line, even when the current line is only partly visible. Images or text taller than the window retain Emacs’s partial scrolling.

Tab and Shift-Tab move through the same sequence of links and MIME controls in either direction. HTML links retain their link voice without a navigation earcon; MIME controls keep their part descriptions and cues. Link navigation does not speak the destination URL on the notification stream.

When a row contains one visible MIME control and otherwise only whitespace, you can use Enter or the part actions below from the indentation or trailing space. Your reading position stays on that row. Enter shows or hides content that Notmuch can display; otherwise it uses notmuch-show-part-button-default-action, normally saving the part. Speech confirms the visibility change or the save/view action once. Rows containing other text or multiple controls require you to move onto the intended control.

n

Run notmuch-show-next-open-message.

p

Run notmuch-show-previous-open-message.

N

Run notmuch-show-next-message, including closed messages.

P

Run notmuch-show-previous-message, including closed messages.

SPC

Run notmuch-show-advance-and-archive. Within a message, speech reads the newly visible page; at a message transition it reads the new message; at the thread end it reports the actual archive outcome and destination.

DEL

Run notmuch-show-rewind and read the resulting page or message.

RET

Activate the button or the single MIME control on its row. Elsewhere, run notmuch-show-toggle-message and cue the resulting visibility.

M-RET

Run notmuch-show-open-or-close-all to open every message and report the state and total, for example “Opened all 5 messages.” C-u M-RET closes every message and reports the corresponding total.

C-c C-p

Run emacsvox-notmuch-speak-show-position for the message ordinal, total, and full configured details. On a MIME-part button it instead reads the complete part description, including its full filename.

TAB

Run notmuch-show-next-button and identify the button or MIME part.

<backtab>

Run notmuch-show-previous-button and identify the button or MIME part.

w

Run notmuch-show-save-attachments. Speech confirms when the command returns, but Notmuch exposes no per-attachment result here. The confirmation therefore cannot distinguish partial skips.

. s

Run notmuch-show-save-part on the current MIME part.

. v

Run notmuch-show-view-part.

. o

Run notmuch-show-interactively-view-part and choose an external action.

. m

Run notmuch-show-choose-mime-of-part.

These are the ordinary Show bindings. Table reading temporarily changes the reading keys described below. Viewing, saving, overwriting, or launching a MIME part is an explicit Notmuch operation. Navigation and detail inspection never open an attachment or an external viewer by themselves.

10.4.1 Read a table in an HTML message ¶

When you move into a supported data table, Emacsvox announces table reading, its dimensions and the current cell. The first row supplies column titles. Use Control-Meta-left/right to change columns and Control-Meta-up/down to change rows while retaining the column. These keys read the complete cell, even when its text wraps across several displayed lines. Blank cells say “blank.” Plain Up/down reads the complete destination row by default.

Press SPC to repeat the cell, r for its row, or c for its column. . gives coordinates and = gives dimensions. Tab, Shift-Tab and Enter keep their usual link and MIME actions. Press q to leave table reading in place and restore ordinary mail keys, including reply, archive, attachment saving and the MIME-part prefix. Another q then performs Notmuch’s usual quit. Meta-up/down leaves for the content before or after the table. Reading never changes the message or its tags.

Automatic entry is the initial HTML-mail policy. To change it, press a inside the table or run M-x emacsvox-table-settings from the message. The common, mode and buffer choices work as described under table reading preferences. An explicit On demand choice starts reading only with Control-Meta arrows or C-e C-t C-r. After quitting, automatic entry stays suspended until you leave the table and return or explicitly enter again. A message refresh ends reading; enter again after the refresh.

Supported tables have at least two rows and columns, a header row marked as headings or bold text, and no merged cells. Layout tables, nested tables and tables without a recognisable header retain ordinary mail navigation. For these, you can use normal text reading; the separate M-x emacsvox-eww-table-data view also remains available for simple tables when the EWW integration is loaded. A message already displayed before HTML table support was loaded needs a refresh before it has cell navigation.
