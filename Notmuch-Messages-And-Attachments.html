10.4 Read a thread and its MIME parts ¶

Opening a thread selects its newest unread message among the open messages matching the search. If there is none, Notmuch’s initial selection is retained. Emacsvox speaks the selected message’s summary and first visible body line, skipping hidden alternative bodies. When no body text is visible, point falls back to a leaf MIME-part button where possible. That button announces a bounded filename, content type, and size.

Line reading speaks a visible sender row even if the preceding message ends with folded quoted text; it does not unfold the quote. In a short graphical window, Down advances through ordinary body text before speaking the next line, even when the current line is only partly visible. Images or text taller than the window retain Emacs’s partial scrolling.

n

Run notmuch-show-next-open-message.

p

Run notmuch-show-previous-open-message.

N

Run notmuch-show-next-message, including closed messages.

P

Run notmuch-show-previous-message, including closed messages.

SPC

Run notmuch-show-advance-and-archive. Within a message, speech reads the newly visible page; at a message transition it reads the new message; at the thread end it reports the actual archive outcome and destination.

DEL

Run notmuch-show-rewind and read the resulting page or message.

RET

Run notmuch-show-toggle-message and cue the resulting visibility.

M-RET

Run notmuch-show-open-or-close-all to open every message and report the state and total, for example “Opened all 5 messages.” C-u M-RET closes every message and reports the corresponding total.

C-c C-p

Run emacsvox-notmuch-speak-show-position for the message ordinal, total, and full configured details. On a MIME-part button it instead reads the complete part description, including its full filename.

TAB

Run notmuch-show-next-button and identify the button or MIME part.

<backtab>

Run notmuch-show-previous-button and identify the button or MIME part.

w

Run notmuch-show-save-attachments. Speech confirms when the command returns, but Notmuch exposes no per-attachment result here. The confirmation therefore cannot distinguish partial skips.

. s

Run notmuch-show-save-part on the current MIME part.

. v

Run notmuch-show-view-part.

. o

Run notmuch-show-interactively-view-part and choose an external action.

. m

Run notmuch-show-choose-mime-of-part.

Viewing, saving, overwriting, or launching a MIME part is an explicit Notmuch operation. Navigation and detail inspection never open an attachment or an external viewer by themselves.
