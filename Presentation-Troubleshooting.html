6.11 Troubleshooting And Recovery ¶

Use the symptom to choose the shortest diagnostic route:

SymptomFirst action
The current object sounds wrong or too verbosePress C-e E and inspect the strongest matching rule.
Something heard earlier was wrongOpen Recent Aural Feedback and explain its recorded presentation.
A broad optional behavior is unwantedInspect Presentation Options and preview or disable the matching option.
One narrow exception is unwantedOpen Your feedback rules, preview it, then disable or remove it.
A named voice uses the wrong engine or physical voiceInspect its physical choices in the voice editor, then engine health in Voice Workbench.
A cue is missing or inappropriateValidate and audition the active Sound Pack, then inspect earcon overrides.
A saved setup no longer appears activeCheck whether the selected Presentation Profile is active or diverged.
Voice changes disappear only in some buffersCompare Voice Lock and explicit face-presentation state.

Open Aural Doctor from Aural Home or press D there. The doctor checks live bindings, loaded source or byte-code, the compatibility baseline, options, profiles, personal data, sound resources, spatial fallback, and the speech backend. It does not start the speech server or change settings automatically. When one row offers a reviewed safe repair, press r on that row to run it.

Press ? in any Aural interface for its complete current keys. If speech itself is absent rather than merely presented incorrectly, follow Backend Diagnostics And Responsibilities; presentation diagnostics assume that a speech route can run.

If an adjustment appears to do nothing, check in this order:

  1. Is the palette containing the edit active? Saving to the collection alone does not select it. A retained draft is not a saved voice.
  2. Does the item actually use that named voice? Explain it with C-e E.
  3. Does the physical choice that played have an individual adjustment masking the shared one? Inspect Fallbacks and the last sample’s result.
  4. Does a matching contextual rule replace that field? In the voice editor, inspect Effective sound / Where settings came from.
  5. Does the engine support the requested adjustment? Check the reported unsupported fields and compare samples on an available supported voice.

If speech uses another engine, first check explicit choices in the named voice: they outrank the shared preferred-engine setting. Then inspect engine availability, disablement, and failure information. A missing custom voice name is a configuration error. Ordinary speech preserves the text using an unstyled voice and records a diagnostic; it does not invent the missing palette entry. Doctor and Explain help locate the unresolved reference.
