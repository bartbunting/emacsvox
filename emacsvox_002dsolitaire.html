15.211 emacsvox-solitaire ¶

Auditory interface to solitaire

  • Emacsvox-Solitaire Commands

15.211.1 Emacsvox-Solitaire Commands ¶

  • emacsvox-solitaire-show-column
  • emacsvox-solitaire-show-row
  • emacsvox-solitaire-speak-coordinates
  • emacsvox-solitaire-speak-row
  • emacsvox-solitaire-speak-stones

15.211.1.1 emacsvox-solitaire-show-column ¶

Command: emacsvox-solitaire-show-column ¶
Present first-class tones for each cell in the current column.

15.211.1.2 emacsvox-solitaire-show-row ¶

Command: emacsvox-solitaire-show-row ¶
Present first-class tones for each cell in the current row.

15.211.1.3 emacsvox-solitaire-speak-coordinates ¶

Command: emacsvox-solitaire-speak-coordinates (&optional icon occasion event) ¶
Present the current cell coordinates in one native transaction.
Optional ICON precedes the content.  OCCASION defaults to ‘inspection’, and
EVENT records an optional semantic event.

(fn &optional ICON OCCASION EVENT)

15.211.1.4 emacsvox-solitaire-speak-row ¶

Command: emacsvox-solitaire-speak-row ¶
Speak current row.

15.211.1.5 emacsvox-solitaire-speak-stones ¶

Command: emacsvox-solitaire-speak-stones ¶
Speak number of stones remaining.
