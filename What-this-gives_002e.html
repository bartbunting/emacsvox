6.3 Adjust Voice Lock In Small Steps ¶

Start with the object that sounds wrong or is difficult to distinguish:

  1. Press C-e E at that object and read the explanation before changing a setting.
  2. Toggle Voice Lock only in the current buffer with C-e d v. If the distinction remains, it comes from another presentation rule or action.
  3. Open Aural Home with C-e H. Use its presentation tools and Voice Workbench to preview changes before saving them. You do not need to edit a generated voice symbol.
  4. Revisit the original buffer and compare the same object. Keeping the test case and the scope small makes it easier to understand the result.

Advanced legacy configurations can still customize a named voice’s -settings option, such as voice-monotone-settings. Customize the settings option rather than voice-monotone itself, because the settings update every generated voice that depends on that style. Use this compatibility route only when maintaining an existing low-level voice setup; prefer Aural Home for new configuration.

For deliberate style design, emacsvox-wizards-generate-voice-sampler creates a buffer of characteristic combinations, while emacsvox-wizards-voice-sampler applies a selected personality to the current line and speaks it. These sampler commands are advanced auditioning tools, not required for ordinary Voice Lock use.
