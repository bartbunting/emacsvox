8.7.6 Choose And Tune Fallback Voices ¶

Shared settings provide a base for the whole voice. Physical choices are tried in displayed order, subject to availability, engine policy, and synthesis failure. An empty explicit list means Automatic, using shared engine policy. Availability predicts a possibility; the last sample’s result identifies what played.

Palette inheritance supplies the whole entry. Within that entry, each physical choice can either inherit a shared adjustment or supply its own. For example, suppose shared pitch is six, this physical choice specifies four, and a matching contextual rule requests seven. The resulting request is seven because the rule overrides the choice. Without that rule it is four. Selecting Use shared value for the choice then makes it six.

Expand Fallbacks to distinguish rows using shared settings from customised ones. A row’s menu auditions or compares it; comparison follows the same row after reordering, even where two rows use the same physical voice. A newly added row has no original yet: audition it or compare the whole voice. Replacing a customised physical choice asks whether to keep tuning or return to shared.

Customize this voice opens individual tuning. Each field distinguishes shared, custom, and explicit adapter default. RET offers all three, left/right sets numbers, d requests adapter default, and i inherits. Zero remains explicit. Later shared changes affect inherited fields only. More adjustments and effects reveals additional controls. Automatic samples name the value/state and audition that row; Play whole fallback chain tests normal selection. Return to shared settings leaves individual tuning within the same draft and Save operation. Removing a row disables its controls until undo or return to shared settings.

With per-choice support, complete previews retain the chain and each row’s tuning. Last sample playback started on … identifies the engine/voice whose audio started. Accepted audio or spoken Original and Edited labels do not prove a start. Stop, text changes, draft changes, or context changes retire pending previews; retained evidence is labelled Earlier preview. Saving and application status are separate from playback evidence.

Details and last playback evidence explains shared, row, and contextual contributions to the confirmed sample. The context view offers Where the last sample’s settings came from. These explanations use captured settings despite later edits, identify original versus edited, and distinguish inherited values, defaults, zero, and unsupported requests. They describe requested settings, not measured native parameters or sound.

Older servers provide shared-only previews. Customised complete previews need per-choice support; individual auditions are available only if tuning can be represented faithfully, including defaults. Saving remains possible when a preview is unsupported.

  1. Work with engine-specific parameters

    Engine-specific settings opens parameters described by the selected worker within the same voice draft. A worker that can describe but not apply them shows them read-only. Engine-wide and startup controls also remain read-only here, with scope identified by Help.

    Actions precede expandable parameter groups with value, source, and range. RET offers Set value, Follow common settings, Engine voice default, and Parameter help. Units and limits belong to the engine. Help explains default source, relevant common controls, and reported side effects. ? opens and reads parameter Help; q returns to the row. Left/right steps a set numeric value within limits. For inherited or unknown defaults, first choose a value with RET; the editor does not guess current native state.

    i removes an override, d requests engine voice default, and Reset engine-specific settings removes native overrides without altering common adjustments or other choices. u undoes these edits.

    Automatic samples name the parameter/value and share the common editor’s Automatic sample after adjustment preference. Opening, searching, refreshing, and Help do not audition. P previews, B compares, and the normal Save keeps the draft. q returns to common settings. Search controls searches names, identifiers, and Help across folded groups; empty input clears the filter. Adjusted controls only shows overrides. g refreshes without restarting; a busy engine is retried quietly for up to five seconds. Leaving cancels retry. If still busy, finish speech and retry g. Unrecognised saved fields stay visible for explicit removal.

    Explain planned settings describes the captured draft without speech playback. Where supported, last-playback details also explain applied sample settings. Planned, applied, and engine-read-back values are labelled separately. An expired sample plan cannot be reconstructed by these queries.
