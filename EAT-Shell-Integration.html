12.6 Shell Integration And Command Status ¶

EAT’s Bash or Zsh integration supplies prompt annotation, directory tracking, and per-command running/success/failure status. For Bash, EAT documents: 

[ -n "$EAT_SHELL_INTEGRATION_DIR" ] && \
  source "$EAT_SHELL_INTEGRATION_DIR/bash"

For Zsh, use its script instead: 

[ -n "$EAT_SHELL_INTEGRATION_DIR" ] && \
  source "$EAT_SHELL_INTEGRATION_DIR/zsh"

With integration and eat-enable-shell-prompt-annotation enabled, Emacsvox retains running, successful, and failed command status. A failure is eligible for automatic feedback at every verbosity, subject to foreground autospeak. Success is automatic only at verbose level after observed command activity; the initial successful prompt is not announced as a completed command. Running state stays silent. C-e q t requests the retained current state.

Status is not guessed from prompt characters. A remote shell or router usually does not provide this per-command integration. Its output and completion can still be accessible while individual exit status remains unavailable.
