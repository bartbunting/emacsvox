8.12 Save, Switch, And Share Your Setup ¶

A Presentation Profile records enabled options and their order, sound pack, voice palette, and portable spatial settings. It switches a coordinated setup for focused work, leisure reading, or different audio environments. It is not an Emacs startup configuration profile or a backup of every setting.

C-e H p p opens profiles. The parent C-e H p also links palettes and unfinished drafts; each editor retains its own Save/Apply actions. Palette w exports portable voices, W backs up full local choices, and i imports an independent palette without activation. See Export, Back Up, and Import Palettes.

  1. Configure the live options, sound pack, voice palette, and spatial choices.
  2. Open C-e H p p and inspect the fields to be captured.
  3. N saves the live selection as a new named profile.
  4. Later, a applies the selected profile’s saved values.
  5. To update it from deliberately changed live settings, use w. To discard live differences instead, apply with a and review confirmation.

Only one profile is selected at a time. Active means its saved values match the live configuration. Diverged means it is still selected, but one or more live values now differ from its saved values. That status is not a warning about an unsaved editor draft.

Applying a profile also saves its selection for future sessions. This differs from activating an individual palette, which selects it only for this session.

Profiles reference palettes and sound packs by name, not private copies. Editing a shared palette affects every profile using it. Profiles exclude engine policy, speech rate, notification output, rules themselves, buffer-local Voice Lock, and current-buffer rules. Those remain in their owning settings or rule stores.
