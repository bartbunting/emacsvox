13.2 Character And Line Input Modes ¶

Term starts in character mode. Choose according to who should receive the keys:

Character mode

Most keys are sent immediately to the terminal program. This suits full-screen or key-driven applications. C-c C-j enters line mode. Normal Emacs prefixes may belong to the child, so use C-c C-h m for mode help and C-c M-x to run an Emacs command.

Line mode

Ordinary Emacs editing commands edit pending input; RET sends it to the program. Emacs Help keys such as C-h m work directly. C-c C-k returns to character mode.

An interactive switch announces Terminal line mode or Terminal character mode. In either mode, C-t introduces Term’s Emacsvox review commands. Send a literal C-t to the child in character mode with C-t C-t.

Use the input-mode escape before trying ordinary Emacs settings or Help keys that the child might otherwise receive. In line mode, C-e H opens the Emacsvox settings menu. Its general settings do not replace Term’s own buffer-local automatic-speech control below. Likewise, q closes an Emacsvox menu or dedicated review only while that interface owns the keys; it is not a general command to leave a running terminal application.
