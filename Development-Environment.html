9.8 Development Environment ¶

Compilation, diagnostics, project navigation, version control, debuggers, and language servers can share the Emacs workspace. Configure each through its own manual and verify its operation before combining it with other components. Emacsvox supplies speech to many of them; their underlying operations remain owned by those tools. Agent Shell provides the separate guide to AI-agent sessions and their permission, feedback, and review controls.

  • Magit

9.8.1 Magit ¶

Magit navigation speaks the section or line you reach. Empty and whitespace-only lines use the normal line tones. Commit hashes are silent by default; changing the voice assigned to magit-hash affects navigation and explicit reading consistently. Moving the section highlight preserves that choice.

After successful staging or unstaging in a Magit view, speech reads where point lands after the refresh. Failures remain explicit. Staging and unstaging from an ordinary file buffer still confirm their outcome. Branch checkout, branch and remote renaming, remote removal, and stash creation announce results. Repository-list fetching reports partial failures. Background completion uses the notification stream; entering status and navigating use the main stream.

Visibility commands describe collapsed, expanded, or partly expanded sections. Copying a heading without a value reports that there is nothing to copy rather than presenting an old kill-ring entry as a new copy.

Magit uses Transient menus for Push, Fetch, Commit, Branch, and other actions. Opening one speaks a short introduction and navigation guidance. Its automatic shortcut list remains visible without being read on the notification stream.

Up/down browses items and left/right moves between sections. The shared navigation preferences apply to Magit as well as Emacsvox menus: wrapping within a section is the default, and continuous navigation or stopping at section edges can be selected. Announcement order can be item first, section first, or dependent on the movement. Detailed command descriptions are enabled by default; value adjustments still give brief feedback. Configure these choices through C-e H s n, as described in Getting started with settings menus.

An item announcement identifies its key, relevant value, and description; capital keys are named explicitly. Section announcements include the heading and position according to the selected policy. Do not expect the same section-name repetition after changing that policy.

Use C-j or M-RET to activate a selected Magit item, or type its shortcut. ? followed by the shortcut opens Help. C-g closes the current menu or leaves its help mode. Unlike Emacsvox’s own settings menus, q is not a universal quit key in Transient applications. An unavailable key gives brief recovery guidance on the main stream.

Browsing only selects an item. Activating an action can perform a Git operation, while activating a switch changes an argument for the next action. Listen to the description before activation.
