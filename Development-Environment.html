8.7 Development Environment ¶

Emacs can combine compilation, diagnostics, project navigation, version control, debuggers, and language servers into a development environment. Emacsvox supplies speech feedback to many of those components, but their own manuals remain authoritative for setup and operation. Verify each component individually with its mode help before combining it into a larger workflow.

  • Magit

8.7.1 Magit ¶

Magit navigation speaks the reached section or line. Empty and whitespace-only lines use the normal line tones. Commit hashes are silent by default; changing the voice assigned to the magit-hash face changes this consistently for both navigation and explicit reading. Moving the section highlight preserves that choice.

Staging and unstaging report their outcome after Git finishes, including failures. Branch checkout, branch and remote renaming, remote removal, and stash creation also announce their results. Repository-list fetching reports partial failures when some repositories fail. Background process completion uses the notification lane, while entering status and navigating use the main speech lane.

Section visibility commands describe the resulting collapsed, expanded, or partly expanded state. Copying a heading without a value says there is nothing to copy; it does not repeat an older kill-ring entry as a new copy.
