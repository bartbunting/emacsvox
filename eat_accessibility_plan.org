#+title: Emacsvox EAT Accessibility Implementation Plan
#+date: 2026-08-23
#+options: toc:2 num:nil

* Objective

Resolve the EAT correctness, lifecycle, accessibility, performance, privacy, and
speech-interference issues that can be addressed inside Emacsvox without
requiring major EAT changes.

The evidence baseline and design rationale are in
[[file:eat_review_report.org][eat_review_report.org]].  Work is delivered as
small commits.  Source, tests, documentation, and compiled-code verification are
kept distinct so each behavioral change remains reviewable.

* Constraints

- Preserve all pre-existing tracked and untracked work.
- Do not modify the user's Emacs configuration or existing live terminal
  sessions.
- Use the Emacs selected by ~local.mk~.
- Run ~make check-emacs~ and ~make bytecode-check~ before compiler diagnosis.
- Run ~make bytecode~ after ordinary Lisp changes and verify in a fresh Emacs.
- Use ~make bytecode-rebuild~ after macro/public-interface changes, branch
  switches, or pulls.
- Do not introduce dependencies or rely on unstable EAT internals without an
  explicit decision.
- Pause for a user decision before a broad refactor, public API change, or
  materially different user-facing default.

* Decision log

| Date | Decision | Reason |
|------+----------+--------|
| 2026-08-23 | Use current public EAT snapshots and small optional adapters; do not make private terminal structs architectural. | Upstream mainline is quiet and the public getters cover a conservative implementation. |
| 2026-08-23 | Preserve silent-by-default background behavior. | It is the safer privacy and speech-interference default. |
| 2026-08-23 | Separate the nil-cursor fix from output/completion redesign. | Lowest-risk confirmed correctness fix with an unambiguous regression oracle. |
| 2026-08-23 | Prefer deterministic local router/TUI fixtures over external sessions. | Reproducible, safe, and independent of device/network state. |
| 2026-08-23 | Report an unanchored completion list as an “at least N visible” lower bound. | Public visible-screen state cannot recover candidates already scrolled away in one EAT output batch; reading arbitrary scrollback would retain unrelated private content and still would not provide structured item boundaries. |
| 2026-08-23 | Use existing registered semantic facts for EAT state changes. | Invented operation or attribute values fail Emacsvox's native fact validator; spoken content can carry the more specific human description without broadening the public vocabulary. |
| 2026-08-23 | Wrap EAT's public terminal bell parameter and preserve its callback. | This avoids advice on private EAT functions, leaves every configured ~ding~ invocation intact, and permits Emacsvox to deduplicate only its added speech. |
| 2026-08-23 | Use one buffer-local ~terse~ / ~normal~ / ~verbose~ terminal policy, defaulting to ~normal~; only ~verbose~ automatically announces title and directory changes. | A unified policy is easier to understand and extend than separate switches. The default preserves established bounded output while keeping potentially sensitive host/path metadata opt-in; every level retains bounded metadata for explicit review. |
| 2026-08-23 | Harden the explicit ~eat-send-password~ path; do not infer no-echo state from terminal repaint. | EAT exposes no public terminal-echo state, and silence is not proof of a password prompt. The explicit command uses Emacs's lossage-safe ~read-passwd~ path and gives Emacsvox a reliable privacy boundary without private EAT internals or content inspection. |
| 2026-08-23 | Background monitoring uses a cue only; speak its unread burst count only after returning to that terminal. | This user-selected policy provides awareness without exposing terminal identity/content or inserting background speech. Quiescence, a five-second cue limit, and minibuffer suppression prevent refresh floods and input interference. |
| 2026-08-23 | Normalize semantic style traits from EAT's rendered public buffer properties and version the signature. | Public properties expose the useful SGR state without private terminal structs. Dropping the default terminal font removes noise; retaining raw normalized faces beside stable traits preserves evidence. Inverse-like styling remains evidence, not proof of focus. |
| 2026-08-23 | Redact concealed cells at the snapshot boundary with same-length blanks. | EAT correctly retains the underlying characters in its terminal buffer, but accessibility snapshots must neither retain nor speak visually concealed content. Same-length redaction preserves public cursor/style offsets and newlines while making completion and diff classifiers fail safely. |
