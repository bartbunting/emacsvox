12.5 Verbosity And Background Monitoring ¶

emacsvox-eat-verbosity is buffer-local:

terse

Retain routine output and metadata for explicit review without speaking them automatically. Actionable failures and content-free lifecycle feedback remain available.

normal

The default: bounded command output, progress/status, completion, and actionable failures.

verbose

Also give bounded title and directory changes and successful shell-command status when EAT shell integration supplies it.

Background monitoring starts off. With C-e q m enabled, an unselected terminal gives only a rate-limited content-free cue. Returning reports the unread burst count, never the terminal’s identity or output. Cursor movement, style changes, repaint, resize, and process-generation changes do not count. Unlike Shell/comint background reading, EAT monitoring neither requires foreground autospeak nor reads background content.

  • Adjust and save focused terminal settings

12.5.1 Adjust and save focused terminal settings ¶

Use C-e S or C-e H j c from EAT or its frozen review. C-e H j a opens the integration chooser, and C-e H / finds individual controls.

  • s toggles automatic foreground speech.
  • b toggles background cues and unread counts independently.
  • p chooses ready-prompt cue, text, or silence; recognition still requires shell integration and automatic delivery obeys foreground autospeak.
  • d chooses terse, normal, or verbose feedback.

Arrows announce values and RET activates a control. Choice lists start on the current value; browsing does not apply a choice, RET applies and returns, and q cancels. Confirmations interrupt older main speech. Changes belong to the captured terminal, including embedded Eshell EAT; from frozen review they belong to its source terminal.

q returns to the originating menu entry. From direct C-e S, it closes the menu and announces the restored buffer and mode with a close cue. w saves the four displayed values as defaults through Customize. Terminals with local overrides keep them; others inherit the new defaults. Adjustment alone does not save. A opens advanced EAT settings and q there returns to the focused menu.
