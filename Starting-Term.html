12.1 Starting Term ¶

Run M-x term RET. At the ‘Run program:’ prompt, accept the proposed shell or enter another executable and press RET. Emacsvox currently makes the selected Term window fill the frame when term or ansi-term starts. This changes only the window layout: it does not kill the buffers that were displayed in the other windows.

Term owns terminal emulation and the child program owns its prompts, input, and completion. Emacsvox observes the rendered Term buffer and adds speech feedback and review commands. See Term Mode in The GNU Emacs Manual for the emulator itself and emacsvox-eterm in Emacsvox Reference Manual for the complete Emacsvox API inventory.
