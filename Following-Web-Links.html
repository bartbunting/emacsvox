9.5.3 Follow a link and return to the article ¶

Use lowercase f to reach the next link and lowercase b for the previous one. Emacsvox presents link navigation; C-e l reads its surrounding line. The link’s label is not necessarily its destination address.

On a link, k copies its address to Emacs’s kill ring, the text store used by C-y. To inspect that address as text, press C-x b, enter an unused buffer name such as evox-web-address, and press RET. If that name already contains work, choose another. Run M-x text-mode RET, press C-y to insert the address, then C-e l to read it. Return to the browser by name with C-x b. This temporary buffer need not be saved. Do not paste into an important document or a web form merely to inspect a URL. Between copying and pasting, avoid C-e a and C-e f: repeating a message or reading a filename also adds text to the kill ring and can replace the address as the next paste. Check the pasted text; Choose text copied earlier explains retrieving an older entry.

To copy the page’s own address regardless of point, use M-x eww-copy-page-url RET instead. Emacsvox’s k is context-sensitive and means the link address when on a link.

Press RET on the intended link to follow it. After the new page loads, press lowercase l to go back in that EWW buffer’s history and r to go forward again. Emacsvox announces URL navigation through the page header. Check your position with line reading; if necessary, search for a distinctive phrase from the article. History is limited and a page can change, so do not assume the exact passage is always restored.

To follow a link in a separate buffer, use M-RET. Return to the original page with C-x b; that is a buffer change rather than a history step in the new buffer. Use q in an ordinary EWW page to leave its view. Uppercase Q is Emacsvox’s buffer-killing command and is not required for this task.

To keep a website for a future session, run M-x eww-add-bookmark RET on the wanted page. M-x eww-list-bookmarks RET opens the saved list; select a bookmark and press RET to visit it. These are website bookmarks, not the Emacsvox ebook-position marks on m, and they do not promise to preserve an exact reading position on a changing page.
