8 Applications And Integrations ¶

Emacsvox prepares speech support for many Emacs modes as their libraries are loaded. Start the application normally; when its buffer appears, use C-h m for the active modes and their commands, C-h b for the effective bindings, and C-h k followed by a key to identify one binding. The generated Emacsvox Commands And Options in Emacsvox Reference Manual records the public Emacsvox commands and options.

This chapter is a curated starting point, not a promise that every module in the generated reference has a maintained task guide. Emacs itself or a third-party package provides the application’s general operation; Emacsvox adds the speech feedback. Consult both sets of help when diagnosing a problem.

Earlier Emacspeak surveys, including their W3, Dismal, and scanner/OCR setup, are preserved as historical material in Historical Application Survey in Emacspeak Heritage. They are not current setup instructions.
