9 Applications And Integrations ¶

Start an application with its normal Emacs command. Emacsvox prepares speech support as the relevant libraries load, then presents movement, results, and state changes through that application’s structure. Emacs or the third-party package still owns its editing, files, network operations, and other actions.

Use C-h m to learn the active mode, C-h b to inspect its effective keys, and C-h k to explain one binding. For Emacsvox’s feedback controls, C-e S opens the current integration’s focused settings when available, otherwise general buffer settings. C-e H j also provides integration settings and a chooser. These controls adjust speech; they do not replace the application’s own setup or preferences. Using Online Help explains menu Help and search.

This chapter is a guide to maintained workflows, not a claim that every module has a complete task guide. The generated Emacsvox Commands And Options in the Emacsvox Reference Manual records public commands and options. Consult both that reference and the application’s manual when diagnosing a problem.

The everyday guides below cover opening and copying files, writing and reviewing notes, and reading web pages. They use existing speech settings. Start with Answer a prompt and return to your work if filename entry, completion or switching from the manual to a working buffer is unfamiliar.

Earlier surveys of W3, Dismal, and scanner/OCR setup remain in the Historical Application Survey in Emacspeak Heritage. They describe their original period and are not current installation instructions.
