11 Emacs Packages. ¶

Emacs — The extensible, self-documenting editor, derives its functionality from its powerful extension mechanism. This extension mechanism is used to implement many user-level applications such as mail readers, web browsers, software development environments and so on. This chapter gives directions on how to locate the right Emacs package for addressing specific tasks. The chapter is organized into logical sections that each pertain to a specific class of tasks; in individual subsections within a section give a brief overview of particular Emacs packages that have been speech-enabled.

Several application essays in this chapter are inherited historical surveys. They are labelled where their named software is no longer current. Use the generated module reference and each live mode’s C-h m output for the authoritative current commands and bindings.

For the current speech-enabled module inventory, use the generated See Emacsvox Commands And Options. Emacsvox 60 requires Emacs 31 or newer, whose built-in package manager can install and update external packages. The original Emacspeak application list at http://emacspeak.sf.net/applications.html is retained only as historical background.
