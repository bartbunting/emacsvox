Emacsvox ¶

Welcome to the Emacsvox user manual. Begin with the introduction, follow the installation path until Emacsvox speaks, and then try the Guided Tutorial for step-by-step practice or Basic Usage for a concise first session. Platform and compatibility detail is available in Speech Backends when you need it. Exact commands, options, and keymaps are in the separate Emacsvox Reference Manual in Emacsvox Reference Manual. Selected historical Emacspeak material is in the separate Emacspeak Heritage in Emacspeak Heritage manual and is not current setup guidance. For rapidly evolving development and Aural Presentation rule-authoring details, also consult README.org and etc/aural-presentation-reference.org in the source tree.
