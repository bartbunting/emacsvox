Emacsvox ¶

This user manual contains current Emacsvox operating guidance. Begin with Getting Started, then continue to Speech Backends and Basic Usage. Exact commands, options, and keymaps are in the separate Emacsvox Reference Manual in Emacsvox Reference Manual. Selected historical Emacspeak material is in the separate Emacspeak Heritage in Emacspeak Heritage manual and is not current setup guidance. For rapidly evolving Omnivox and Aural Presentation details, also consult Readme.org and etc/aural-presentation-reference.org in the source tree.
