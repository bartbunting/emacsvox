8.10.5 Adjust Spatial Presentation ¶

Open C-e H D s to inspect reported speech/cue capabilities, then return to the menu. C-e H o n opens Notifications and spatial output. Enable presentation, speech, and cues independently. Output follows capabilities or can be declared mono. Separation ranges from zero (centred) to one (full); direction can be normal, reversed, or centred for some/all requests.

These spatial controls apply immediately and are global. Shift-left/right adjusts selected separation by 0.1; RET enters an exact value. SPC requests left then right cue previews; mono or limited capabilities may centre them. x stops. S saves spatial and routing defaults without restarting speech, separately from output-volume saving.

For a gentler layout, note the current settings, select maximum separation, and enter 0.3. Repeat feedback that requests spatial placement. Stereo headphones help compare it. If everything stays centred, Explain the source to check its placement request and inspect backend capability. A sample without a placement request cannot demonstrate separation.

For comparison, select mono and repeat the action; content remains audible. Restore the original values afterward. Save deliberately with S or capture spatial choices in a Presentation Profile. A voice’s Pan effect and notification-device routing are separate from presentation placement.
