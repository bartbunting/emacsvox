6.8.4 Adjust Spatial Presentation ¶

From Home, open Spatial capabilities under Troubleshooting to inspect what the current backend reports for speech and cues. Then open Spatial settings under Sounds and output. Speech and cues have separate enable controls. Output can follow the backend capability or be declared mono. Maximum separation ranges from zero (centered) to one (full separation); direction can stay normal, reverse left and right, or center some or all requests.

To try a gentler layout, note the existing maximum separation, set it to 0.3 with Customize’s Apply action, and repeat feedback that already requests spatial placement. Stereo headphones make left/right differences easier to compare. If all feedback remains centered, use Explain to check that the presentation requests placement and inspect the reported capability. A sample with no spatial request cannot demonstrate this setting.

For a centered comparison, temporarily select Mono output, apply, and repeat the same action. Content should remain audible. Restore the values you noted when finished. Use Customize’s save action or capture the spatial choices in a Presentation Profile to retain an intentional change across restarts. These controls govern presentation placement; a voice’s explicit Pan effect and notification-device routing are separate settings.
