13.5 Help And Recovery ¶

For visible but silent output, inspect emacsvox-eterm-autospeak in the current buffer and ensure that buffer is displayed. Toggle with C-t C-q when necessary, then test new output. An automatic-speech setting does not prove that the program has produced a new readable screen change.

If an Emacs command goes to the child, check the input mode. In character mode use C-c C-h m, C-c M-x, or switch to line mode with C-c C-j. If dedicated review owns the keys, q returns to character mode first.

When review has moved away from current output, C-t . resynchronises the pointer. Leave dedicated review with q before using the normal prefix. For a full-screen redraw that Term cannot present reliably, try the workflow in EAT Terminal Access and use that emulator’s explicit review commands.
