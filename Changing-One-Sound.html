8.10.3 Walkthrough: Silence One Cue ¶

  1. Repeat the action producing the cue, then open C-e H f h. Select the record and RET to explain it. Identify cue name and before/after phase.
  2. Return to the list and press C for Change this feedback. Select the relevant part if needed, then c, Suppress one component, and the cue.
  3. Compare O~/~P: speech and other components should remain. Inspect criteria with m, then choose This Emacs session through l.
  4. Apply with a and repeat the source action. Matching feedback should omit that cue; other identities or unmatched contexts remain unchanged.
  5. Open C-e H r o, find the session rule, and disable with t or delete with d. It also expires when Emacs exits.

To add a missing cue, choose Add a sound, Before content or After content, then a registered cue. Preview and review criteria/lifetime. Adding and later removing use the same rule workflow.
