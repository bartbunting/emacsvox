6.8.2 Walkthrough: Silence One Cue ¶

  1. Repeat the action that produces the unwanted cue. Open C-e H H, select that recorded feedback, and press RET to explain it. Find the cue name and whether it occurs before or after content.
  2. Return to the feedback list and press C for Change this feedback. If the record has several parts, select the part containing that cue. Press c, choose Suppress one component, and select the exact cue.
  3. Compare O and P. The proposed version should keep the speech and other components while omitting that cue. Review What should match with m, then press l and choose This Emacs session for this experiment.
  4. Press a and repeat the original action. The selected cue should be absent for matching feedback. Other cues with different identities or matching criteria should still sound.
  5. To restore it, open Home’s Your feedback rules, find the new session rule, and disable it with t or remove it with d. The session rule also expires when Emacs exits.

To add a cue to feedback that has none, use Add a sound instead. Choose Before content or After content, select a registered cue, preview, then review matching and lifetime. A cue addition and its later removal use the same rule-management workflow.
