6.5 Choose And Manage Voice Palettes ¶

A named voice gives a reusable name, such as bolden or annotate, to a way of speaking. Some detailed views call it a logical voice. A voice palette is a collection of these named entries. Each entry includes its shared adjustments, ordered physical voice choices, and any adjustments for individual choices.

A physical voice is a voice supplied by an installed speech engine. The palette describes the intended choices; availability on your machine and shared engine preferences determine which can be used. A presentation rule chooses when to use a named voice. Editing that voice changes every use that resolves to the entry; changing a rule changes which items use it.

Use this section to manage the collection. For pitch, physical choices, and other voice settings, see Edit a Named Voice. To hear installed voices or change engine preference, see Installed Voices and Engines.

Use the Voice Palettes manager to choose a palette or manage its named voices. Press RET on a palette to browse its voices, use P to audition the palette sequence before editing, and use a in the palette manager to activate a selected palette. Built-in palettes remain intact; editing can open an unsaved personal child in the common editor.

Opening the manager announces its selected palette. Entering a palette announces its name, voice count, selected voice and main keys.

The Kind column distinguishes personal palettes, built-in palettes and the standard default. Parent names the palette used for inherited entries. The read-only acss-default palette is the common root: a chain such as a -> b -> c -> acss-default is supported. It supplies the standard named personalities declared by Emacsvox and loaded integrations; it is not a fixed list of every custom voice you may create. Only the root has no parent.

Inheritance takes the nearest complete entry: its style, physical choice order and each choice’s adjustments stay together. It does not combine pieces of the same voice from several parents. The voice list’s Source column names the palette supplying that entry. Press O to open its source, or u for Where Used. Where Used shows known loaded references, declared aliases and affected descendants; it cannot inspect configuration that has not been loaded. Editing an entry shared by descendants asks you to review the affected palettes and known uses.

An alias is a declared alternative spelling for a named voice, such as voice-bolden for bolden. It uses the same entry. Aliases are maintained by integrations, not edited as separate voices in the palette manager. Use Copy Voice when you want a separately adjustable voice.

Press N in the voice list for New Voice or c for Copy Voice. Both open an unsaved draft in the common editor. Copy retains the complete effective voice, including fallback order and individual adjustments. Editing or copying a built-in voice asks for a personal child palette; saving adds only the requested direct entry to that child. Opening or previewing the draft does not save it.

Press R to Reset a personal definition to its inherited entry. The confirmation names the source that will become effective and rejects a source changed during confirmation. Reset preserves other saved settings. Use d to Delete a direct custom voice that has no inherited replacement. Built-in and inherited entries cannot be deleted here. If deletion would leave a known reference without a voice, remap that use first. Save or discard unfinished voice edits before deleting. Press o to return to the palette manager.

In the palette manager, New Palette with N creates a child of the chosen parent. Copy Palette with c instead saves an independent copy of all effective entries with acss-default as its parent. Its local physical choices belong to the new palette. Use the summary and parent action, E, to review or change a personal palette’s parent; the manager rejects inheritance cycles.

To delete a whole personal palette, select it in the manager and press d. Children and known references, including saved profiles, must be changed first, and unfinished voice edits must be completed or discarded. Deleting an active palette returns to the standard baseline.

Activation with a lasts for this session. Press f to follow the standard baseline palette again. This clears the session’s explicit palette selection; it does not delete your saved palette or change the startup choice. Use at Startup, U, changes the palette in the selected saved Presentation Profile while preserving its other saved fields. It does not apply that profile to the current session. If no startup profile exists, the action asks you to review a new profile captured from the current setup. It checks voice references in saved rules and the profile’s saved options; session and buffer rules do not affect this startup check. An already open Profiles view refreshes to show the saved choice.
