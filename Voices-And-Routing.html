8.6 Choose And Manage Voice Palettes ¶

A named voice, also called a logical voice in detailed views, gives a reusable name such as bolden or annotate to a way of speaking. A voice palette contains these entries. Each includes shared adjustments, ordered physical choices, and adjustments for individual choices.

A physical voice comes from an installed speech engine. The palette expresses intended choices; availability and shared engine preferences determine which can be used. A presentation rule determines when to use a named voice. Editing that entry changes every use resolving to it; changing a rule changes which items select it.

This section manages the collection. Edit a Named Voice covers its physical choices and adjustments; Installed Voices and Engines covers browsing and engine preferences.

Open Voice Palettes with C-e H v p. RET on a palette browses its voices, P auditions its sequence, and a activates it. Built-in palettes remain intact; editing can open an unsaved personal child in the common editor.

Upgrading personal palettes. This version accepts schema 3 only. Before upgrading older personal palettes, back up palette/routing data and arrange a reviewed conversion of entries and physical choices. Opening or previewing does not convert them. Preserve names and profile references, with each personal parent chain ending at acss-default. Shared per-voice routing, migration, and preset screens have been removed; use the common editor for named-voice choices and adjustments. Shared engine preference remains separate.

Opening the manager announces its selected palette; entering a palette announces its name, voice count, selected voice, and main keys. Kind distinguishes personal, built-in, and standard-default palettes. Parent names the inherited source. Read-only acss-default is the root: chains such as a -> b -> c -> acss-default are supported. It provides personalities from Emacsvox and loaded integrations, not a fixed list of all custom names. Only the root has no parent.

A palette inherits the nearest complete definition of a named voice. Its style, ordered physical choices and individual tuning come from that one entry; they are not assembled from several parents. The Source column names the supplying palette, and capital O opens it.

Press u for Where Used before editing a shared entry. This lists known loaded references, aliases and affected descendant palettes. It cannot inspect configuration that has not been loaded. Editing a shared entry asks you to review those known uses and descendants.

An alias, such as voice-bolden for bolden, is a declared alternative spelling of the same entry. Integrations maintain aliases; the manager does not edit them as separate voices. Use Copy Voice for an independently adjustable entry.

N in a voice list creates New Voice and c copies one into an unsaved editor draft. Copy preserves the full effective entry, fallback order, and individual tuning. Editing or copying a built-in voice requests a personal child palette; saving adds only the requested direct entry. Opening or previewing writes nothing.

R resets a personal definition to its inherited entry. Confirmation names the source that will take over and rejects a source changed during confirmation. Other saved settings remain. d deletes a direct custom voice with no inherited replacement; built-in and inherited entries cannot be deleted. Remap known references first if deletion would leave them unresolved. Finish or discard voice drafts before deletion. o returns to the palette manager.

New Palette, N in the manager, creates a child of the chosen parent. Copy Palette, c, saves all effective entries independently under acss-default; local physical choices belong to the new palette. The summary and parent action E inspect or change a personal parent; inheritance cycles are rejected.

To delete a personal palette, select it and press d. Change children and known references, including saved profiles, and finish/discard its voice drafts first. Deleting an active palette returns to the standard baseline.

In Voice Palettes, a activates the selected palette for this session. To return to following the standard baseline, press f. That clears an explicit session selection without deleting palette data or changing startup.

Capital U, Use at Startup, changes the palette named by the selected saved Presentation Profile and preserves that profile’s other fields. It does not apply the profile now. With no startup profile, the operation proposes one captured from the current setup; review it before saving. Its checks cover saved rules and profile options, not session or buffer rules. An open Profiles view refreshes to show the saved choice.
