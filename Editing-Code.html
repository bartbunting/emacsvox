8.6 Editing Code ¶

Programming modes own language-aware movement, indentation, compilation, and navigation. Emacsvox speaks those operations and uses voice-lock to distinguish faces such as comments, strings, warnings, and language constructs. Use C-h m in the source buffer for the language mode, and search the generated reference for an integration named after that mode.
