8.3 Browsing Structure ¶

Use the structure exposed by the active Emacs mode rather than treating every buffer as plain text. Info provides node and menu navigation, Outline provides heading and visibility commands, and EWW exposes HTML headings, links, lists, tables, and other document elements. Begin with C-h m in the buffer; see Find Help While You Work for the common discovery commands and Web Browsing With EWW for the maintained Web route.
