9.4 Browsing Structure ¶

Use the active mode’s structure when it matches the task: Info has nodes and menus, Outline has headings and visibility, and EWW exposes HTML headings, links, lists, tables, and other document elements. The following sections explain Emacsvox’s reading of headings, tables, and application lists. These reading controls are distinct from commands that edit the underlying content.

  • Reading Org headings
  • Reading Markdown and Org tables
  • Reading application lists
  • Browsing CSV data

9.4.1 Reading Org headings ¶

Reading a whole Org heading omits its leading stars at punctuation levels some and none. Heading voices and the optional heading-level announcement still identify the structure. At all punctuation, the stars are counted, for example, “3 star” before a level-three heading. An empty heading is spoken as “Empty heading” when its stars are omitted.

Word reading and partial-line reading count the stars actually selected. Starting at the second star of a level-three heading therefore says “2 star”. Word movement includes the star count when it reaches the first heading word, in either direction, without changing the usual cursor position. Moving through the remaining title words does not repeat that count or heading-level announcement. Character reading and spelling retain the individual stars. Collapsed headings have a collapse cue at every level; the large-movement cue belongs to Org structure navigation.

Counts preserve the configured character name without adding a plural ending. At all punctuation, the speech server names *, so an active Omnivox pronunciation of “asterisk” produces “3 asterisk”. Saved punctuation-editor changes take effect after restarting speech. Explicit word and partial-line reads at some or none use tts-character-to-speech-table, the Emacs table also used for character reading.
