8.3 Browsing Structure ¶

Use the structure exposed by the active Emacs mode rather than treating every buffer as plain text. Info provides node and menu navigation, Outline provides heading and visibility commands, and EWW exposes HTML headings, links, lists, tables, and other document elements. Begin with C-h m in the buffer; see Using Online Help for the common discovery commands and Web Browsing for the maintained Web route.

  • Reading Markdown and Org tables
  • Browsing CSV data

8.3.1 Reading Markdown and Org tables ¶

In a Markdown or Org table, press a Control-Meta arrow to enter table reading and move immediately. Left/Right move by cell; Up/Down move by logical row. The first movement announces table reading and the destination in one spoken result. Outside supported tables, these arrows keep their existing bindings, including in code examples.

You can still press the speech prefix followed by C-t C-r to enter without moving. With the default prefix, this is C-e C-t C-r. This entry announces the dimensions and current cell. Press q or the same prefix command to restore ordinary editing keys.

Use the speech prefix followed by C-t ] or C-t [ to find and enter the next or previous table from prose. Inside table reading, t and T do the same. Code examples are skipped.

While table reading is active:

  • Up/Down and Control-Meta-Up/Down move by logical row, retain the column, and read the complete destination row.
  • Control-Meta-Left/Right move between cells. Plain Left/Right retain character movement. Tab and Shift-Tab move between cells without editing; Return or Space reads the current cell.
  • r reads the row; c reads the column. . announces coordinates; = gives dimensions.
  • a changes column titles, row titles, or data/title order for this buffer. The customization group emacsvox-table-reader sets defaults.
  • w or k k copies the cell; k r copies the row with tabs between cells; k c copies the column with newlines between cells.
  • Meta-Up/Down leave directly for preceding/following prose. Up/Down also leave when movement crosses a vertical table edge. If there is no content beyond that edge, point stays in the table.

A horizontal edge or a missing cell in a shorter row leaves point unchanged and announces the boundary. Separators are skipped. A separator immediately after the first row identifies column titles; otherwise the first row is data. Coordinates distinguish the header from one-based data rows. Empty cells are spoken as “blank.” Wrapping never shortens a logical cell’s speech or copy.

Reading commands preserve document text: they do not align tables, create rows, or evaluate Org formulas. Copies use cell values, with ordinary links represented by their labels and inline code by its literal text. Use the host mode to copy exact markup or formulas. This reader covers simple pipe tables; HTML spans, nested tables, and spreadsheet-specific structures have separate interfaces.

Leaving the table restores ordinary mode keys. Other editing commands retain their normal meaning; an edit ends the reading context. Org’s existing table editing feedback and Markdown’s markup-stripping speech option remain independent of this reader. Agent Shell uses the same logical reading operations with its existing automatic table entry, commands and preferences; see Agent Shell.

8.3.2 Browsing CSV data ¶

Use emacsvox-table-find-csv-file to open a CSV file in the table browser, or emacsvox-table-view-csv-buffer to browse the current buffer’s CSV data. Quoted commas, doubled quotation marks, and multiline fields remain single logical cells. Blank records outside quoted fields are skipped; empty fields remain cells. Empty input or malformed quoting produces an error before a table view is created.

Browsing preserves the source text. If the file is already open, its buffer and unsaved edits remain available, and the view uses those current contents. The browser uses the shared table controls immediately; there is no separate reading-mode toggle:

  • Up/Down and C-M-Up/Down move by logical row and read the whole row.
  • C-M-Left/Right and Tab/Shift-Tab move by cell. Plain Left/Right and C-b/C-f move by character; C-p/C-n move by logical row.
  • Return or Space reads the cell; r reads the row and c reads the column.
  • . gives coordinates and = gives dimensions. The first row supplies column titles and is announced separately from the data rows.
  • w or k k copies the cell, k r copies the row with tabs between cells, and k c copies the column with newlines between cells. K copies the whole table to the table clipboard for emacsvox-table-paste-from-clipboard.
  • a changes column titles, row titles, or data order for the view, using the shared reader preferences. q closes the view.

These replace the old browser cell-arrow, header-reading, automatic-speech, and single-key table-copy bindings. The old local aliases b, n, p, A, B, E, and T are removed. The speech-prefix table commands remain available.

Search with s, R (row), C (column), or h (headers); # sorts on the current column. M-< and M-> jump to the top and bottom. At a table edge, movement reports the boundary and leaves point in place.

Filters remain on f (row) and g (column); a prefix argument requests a new filter. Filter indexes and the j jump prompt retain zero-based model coordinates, including the header row, even though spoken coordinates count data rows and columns from one. For example, a row filter (0 "value" 2) reads the first column, the word “value”, and the third column. M-l and M-s load and save filters. Filters are explicit inspections; shared row movement always reads the whole row. Sorting preserves filters and shared speech preferences. Use C-h m for the full browser key map.
