9.4 Browsing Structure ¶

Use the active mode’s structure when it matches the task: Info has nodes and menus, Outline has headings and visibility, and EWW exposes HTML headings, links, lists, tables, and other document elements. The following sections explain Emacsvox’s reading of headings, tables, and application lists. These reading controls are distinct from commands that edit the underlying content.

  • Reading Org headings
  • Use managed Muggles
  • Reading Markdown and Org tables
  • Reading application lists
  • Choose table reading preferences
  • Browsing CSV data

9.4.1 Reading Org headings ¶

Reading a whole Org heading omits its leading stars at punctuation levels some and none. Heading voices and the optional heading-level announcement still identify the structure. At all punctuation, the stars are counted, for example, “3 star” before a level-three heading. An empty heading is spoken as “Empty heading” when its stars are omitted.

Word reading and partial-line reading count the stars actually selected. Starting at the second star of a level-three heading therefore says “2 star”. Word movement includes the star count when it reaches the first heading word, in either direction, without changing the usual cursor position. Moving through the remaining title words does not repeat that count or heading-level announcement. Character reading and spelling retain the individual stars. Collapsed headings have a collapse cue at every level; the large-movement cue starts alongside heading speech during Org structure navigation, such as C-c C-n and C-c C-p. Hold Control for the final key too. Ordinary line movement with arrows or C-n~/~C-p does not request that movement cue. To change its timing, capture the navigation in Recent Feedback and use Change sound timing.

Counts preserve the configured character name without adding a plural ending. At all punctuation, the speech server names *, so an active Omnivox pronunciation of “asterisk” produces “3 asterisk”. Saved punctuation-editor changes take effect after restarting speech. Explicit word and partial-line reads at some or none use tts-character-to-speech-table, the Emacs table also used for character reading.

9.4.2 Use managed Muggles ¶

A Muggle is a temporary menu of related commands, implemented with Hydra. The managed list offers Org heading navigation, Org table editing, Text navigation, Outline navigation, View navigation, Repeatable yank, Info summary and Smartparens. All require the Hydra package. Enable installs a menu’s entry keys when available; Run enters it and can move point or perform editing.

Press C-e H m to browse managed Muggles, or run M-x emacsvox-muggles-browse RET. Select a row, then use e to enable its entry keys or d to disable them for this session. W saves explicit session choices through Customize. Settings and action search also find the Muggles entry. Opening or browsing the list does not load or activate a Muggle. The individual menus are described below, followed by the manager’s conflict, saving and restoration rules.

Org heading navigation lets you repeat movement and section reading with single keys in an Org buffer. Start it directly with M-x emacsvox-muggles-org-nav/body RET. Entry announces the menu without moving point or changing the document.

Use n and p to move between visible headings and speak their sections. SPC speaks the current section from point. f and b move between headings at the same level, and u moves to the parent. g opens Org’s heading chooser and leaves the menu. ? reads the available keys; q or C-g exits. Automatic Hydra hints are quiet during this menu; exit restores their previous setting unless it was changed during the visit.

Org table editing starts with M-x emacsvox-muggles-org-table/body RET at an Org table cell. j and k move to the next or previous row; h and l move to the previous or next field. These are native Org editing commands: they may realign the table, recalculate formulas or create a row. SPC reads the field, . gives coordinates, and b, r or c reads the value with both, row or column headers. ? explains the keys and q exits. For movement that preserves the table text, use the shared table reader.

Text navigation starts with M-x emacsvox-muggles-navigate/body RET and immediately attempts to move down one line. n~/~p or j~/~k repeat line movement, f~/~b move by character, and a~/~e reach the line’s beginning or end. v~/~V scroll, <~/~> reach the buffer’s beginning or end, and l recentres. ? reads the keys and q exits. Entry temporarily toggles Hydra hints and exit restores them; pressing s makes an explicit hint choice that is retained after exit. Movement uses the buffer’s existing speech support.

Outline navigation starts with M-x emacsvox-muggles-outliner/body RET in a document with headings recognised by Outline. Entry enables outline-minor-mode and announces the menu without moving point. n~/~p move between visible headings, f~/~b move at the same level, and u moves to the parent. d hides a subtree and a shows all text. Heading movement and folding use the Outline speech support described under Structured editing. ? explains the keys. Use z or C-g to leave; q hides sublevels. Exit and Disable retain Outline minor mode and completed folds. Use the ordinary Outline commands to change visibility afterwards.

View navigation starts with M-x emacsvox-muggles-view/body RET. It offers View commands without enabling View mode or making the buffer read-only. j~/~k move by line, h~/~l by character, and SPC~/~DEL scroll by page. / searches forward and n~/~p repeat the last search forward or backward. c reads the character and w the word; movement retains existing speech support. ? explains further actions, including copying and registers; q or C-g exits. Entry temporarily toggles Hydra hints. Exit restores the previous value unless you choose hints explicitly with s.

Repeatable yank starts with M-x emacsvox-muggles-yank-pop/body RET without pasting. C-y pastes from the kill ring; M-y replaces the previous yank. y~/~Y cycle forward or backward. Native yank prefix arguments and undo remain available. i or s opens an Ido chooser and leaves the menu; cancelling that chooser preserves the previous yank. l opens the optional browse-kill-ring package, or explains when it is unavailable. ? explains the keys; C-g leaves. Temporary quiet hints are restored on exit.

Info summary starts with M-x emacsvox-muggles-info-summary/body RET in an Info buffer. Choose n~/~p for the next or previous node, u for the parent, m for a menu item or i for the index. Most actions leave the Muggle after running. ? invokes the ordinary Info summary and h opens Info help. C-g cancels the menu; q closes the Info window.

Smartparens starts with M-x emacsvox-muggles-smartparens/body RET after you enable M-x smartparens-mode RET in the source buffer. It requires the Smartparens package. f~/~b move by expression; <right>~/~<left> slurp or barf forward, and C-<right>~/~C-<left> do so backward. ( wraps with parentheses, R splices an expression, and k kills it. ? explains the remaining keys; C-g leaves. Exit and Disable retain Smartparens mode and completed edits. Temporary quiet hints are restored on exit.

In the Muggles manager, up/down selects a row and reads its purpose, current choice, configured override and availability. Left/right inspects columns; SPC reads the full row. RET or ? explains the selected Muggle and its actions. Returning from Help with q restores the row and column. g refreshes the displayed state.

On the selected row, e requests its entry key for this session: C-c C-SPC in Org for heading navigation, C-c t in Org for table editing, or global s-n for text navigation, C-. o for Outline, C-. v for View and C-c , for Smartparens. Repeatable yank manages global C-y and M-y together; Info summary manages ? in Info buffers. s-n means Super-n. The two C-. sequences require an existing prefix map; the manager leaves an unbound or conflicting prefix untouched. Use Run or the direct M-x command when a key is blocked. Org and Info entries wait for their corresponding application to load. The availability column names conflicts and missing dependencies.

Explicit Enable may replace the standard C-y yank and M-y yank-pop bindings, or Info’s standard ? Info-summary. A personal binding blocks replacement; either blocked yank key prevents activation of the pair. These ordinary commands remain available through M-x. Loading a legacy collection alone does not replace these standard bindings. Other personal or package bindings are preserved.

d restores adopted standard bindings, removes other managed entry keys and closes this Muggle if active. It preserves completed actions, independently configured bindings and personal replacements made after Enable. Global keys remain subject to local and minor-mode bindings. These choices apply throughout the session, rather than to one buffer.

Enable and Disable retain the selected row and show the choice as not saved. W saves all explicit session Muggle choices through Customize; the emacsvox-muggles customisation group contains the configured overrides. An absent override follows a legacy collection request, otherwise disabled; explicit Disabled takes precedence over a legacy request. Session choices take precedence until saved or changed. q closes the list and keeps session choices; when opened through settings, it returns to the same menu item.

To try a Muggle, open the list from the intended source and press r on its row. This leaves the list and enters that menu at the captured position, even when the managed key is disabled or blocked. It does not enable keys or save settings. Org heading navigation requires an Org buffer; Org table editing also requires a table at the captured position. Info requires an Info buffer, and Smartparens requires its mode already enabled. A closed buffer, changed source item or unsuitable context requires reopening from the intended location. Run is an explicit action; browsing and Help never perform it. Once the menu starts, C-g leaves any managed menu. Outline also exits on z; Org and Text/View navigation exit on q. In Info summary, q closes the Info window.

The named commands emacsvox-muggles-enable, emacsvox-muggles-disable, emacsvox-muggles-status and emacsvox-muggles-save offer the same management operations without the list. Each menu’s direct M-x command also remains available while disabled. Loading extra-muggles requests Org heading, Outline and View navigation, Info summary and Smartparens; loading emacsvox-muggles requests Org table editing, Text navigation and Repeatable yank. The standard-binding adoption rule still requires an explicit Enabled choice for yank and Info on their usual keys. These managed requests respect explicit Disabled choices and protect conflicting bindings. Unconverted collection members retain their legacy keys.
