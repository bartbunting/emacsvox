8.10.1 Terminal Applications ¶

For a new full-terminal workflow, use Speech Access To EAT. When a built-in terminal with no additional package is preferable, use Term Terminal Access. For ordinary line-oriented shell commands, M-x shell is usually the simplest route.

8.10.2 Forms Mode ¶

The built-in Forms library presents records from a structured text file one at a time. Emacsvox speaks field values, record movement, searches, and status changes while Forms mode is active. Forms requires a format specification; see Forms Mode in The GNU Emacs Manual for setup and operation, and emacsvox-forms in Emacsvox Reference Manual for the speech integration.

8.10.3 Experimental OCR Front End ¶

Module emacsvox-ocr is an experimental legacy front end, not a supported initial-user route. Its scanner, image-processing, and OCR-engine workflow has not yet received a current integration review. Do not rely on setup commands, program paths, or defaults in the historical survey. If you evaluate the module, inspect its live command and option help first; the generated emacsvox-ocr in Emacsvox Reference Manual is an API inventory, not a validated deployment guide. Report the exact platform, scanner backend, OCR engine, and Emacsvox revision when requesting help.
