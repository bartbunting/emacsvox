5.8 Adjust Speech While You Work ¶

Use C-e H s for rate, punctuation, indentation, capitalisation, and typing feedback. It starts with the captured buffer’s settings; g switches scope, and C-u C-e H starts the menu with global defaults. Individual controls retain their documented exceptions, such as global volume or phonetic delay.

Changing a global default is not necessarily saving it for restart. A menu’s Save action records only its documented values, and local or mode settings can still override defaults. Choose What Persists explains those distinctions. The direct keys below are alternatives to menu navigation; use C-h k to check a command’s global prefix form before using it.
