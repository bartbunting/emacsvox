3.6 Speech System Commands ¶

Start with the controls in this section when speech is too fast, too detailed, or inappropriate for the current task. Most settings apply only to the current buffer. Press C-u before a command when its help says that a prefix argument changes the default for all buffers.

The generated Emacsvox Keymaps in Emacsvox Reference Manual contains the complete speech keymap, including specialist server and text-chunking controls.
