15.174 emacsvox-nov ¶

NOV == Yet Another EPub Reader Package nov.el is an alternative to Emacsvox’s built-in EPub reader. This module speech-enables nov.el In addition, opening an epub using nov results in directory-specific settings being loaded from file emacsvox-speak-directory-settings — That file can set book-specific settings such as speech-rate and punctuation-mode among others.
