8.2 Structured Editing And Templates ¶

Emacsvox has maintained integrations for the built-in Outline and Tempo libraries. In Outline mode, heading navigation speaks the reached heading and visibility commands announce what was hidden or exposed. Start a dedicated outline with M-x outline-mode, or enable outline-minor-mode in a suitable document. See emacsvox-outline in Emacsvox Reference Manual for the Emacsvox integration and Outline Mode in The GNU Emacs Manual for the underlying editor.

Tempo supplies template fields for modes and packages that use it. Emacsvox speaks inserted text and the line reached when moving between template marks. The package that supplied a template also provides its insertion commands; use that package’s mode help, together with emacsvox-tempo in Emacsvox Reference Manual.
